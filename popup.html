What

Websites and platforms are set in the browser extension; Mac Vault only controls apps.

Add the apps you want this group to block. Use the plus button to search installed apps.

Hide the supported parts of a page that you choose. You can combine these controls.

Filter content using its Classifier tags. One rule per line: "Gaming" matches that tag; "Gaming @3" sets a minimum confidence; "Gaming + Drama" requires both; "!Tutorial" makes an exception.

Use one Discord server ID or channel ID per line. Both kinds may be mixed in the same list. Plain snowflake IDs and links of the form discord.com/channels/<serverId> or discord.com/channels/<serverId>/<channelId> are accepted; channel links keep the channel ID as the entry.

Blocks the Discord DMs home screen (/channels/@me) when enabled.
