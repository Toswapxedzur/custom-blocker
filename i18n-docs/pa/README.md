# ਵਾਲਟ ਐਕਸਟੈਂਸ਼ਨ

ਵਾਲਟ ਐਕਸਟੈਂਸ਼ਨ Chromium ਬ੍ਰਾਊਜ਼ਰਾਂ ਲਈ ਇੱਕ ਮੈਨੀਫੈਸਟ V3 ਫੋਕਸ ਟੂਲ ਹੈ। ਇਸਦਾ ਮੌਜੂਦਾ ਸੰਪਾਦਕ ਵੈਬਸਾਈਟ ਬਲਾਕ ਸਮੂਹਾਂ, ਸਮਰਥਿਤ-ਪਲੇਟਫਾਰਮ ਸਮੂਹਾਂ, ਕਸਟਮ JavaScript ਸਮੂਹ, ਸਮਾਂ-ਸਾਰਣੀ, ਫ੍ਰੀਜ਼ ਅਤੇ ਸਨੂਜ਼ ਨਿਯੰਤਰਣ, ਅਤੇ ਵਿਕਲਪਿਕ ਵੈਬ-ਐਪ ਬ੍ਰਿਜ ਲਿੰਕਾਂ ਦਾ ਪ੍ਰਬੰਧਨ ਕਰਦਾ ਹੈ।

ਸਰੋਤ ਕੋਡ ਉਤਪਾਦ ਇਕਰਾਰਨਾਮਾ ਹੈ। [manual/en.md](manual/en.md) 'ਤੇ ਇੰਗਲਿਸ਼ ਇਨ-ਐਪ ਮੈਨੂਅਲ ਭੇਜੇ ਗਏ ਨਿਯੰਤਰਣਾਂ ਦੀ ਵਿਆਖਿਆ ਕਰਦਾ ਹੈ; ਇਹ ਪਿਛਲੇ ਕਾਪੀ ਕੀਤੇ ਅਤੇ ਮਸ਼ੀਨ-ਅਨੁਵਾਦ ਕੀਤੇ ਮੈਨੂਅਲ ਨੂੰ ਬਦਲ ਦਿੰਦਾ ਹੈ।

## ਮੌਜੂਦਾ ਸਮਰੱਥਾਵਾਂ

- ਬਲਾਕਲਿਸਟ ਜਾਂ ਅਨੁਮਤੀ ਸੂਚੀ ਵਾਲੇ ਵਿਵਹਾਰ, ਵਿਕਲਪਿਕ ਰੀਡਾਇਰੈਕਟ, ਤੁਰੰਤ ਬਲੌਕਿੰਗ, ਸਮਾਂ ਭੱਤਾ, ਜਾਂ ਕਾਉਂਟਡਾਊਨ ਵਾਲੇ ਡਿਫੌਲਟ ਵੈੱਬਸਾਈਟ ਸਮੂਹ।
- YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord, ਅਤੇ Twitter / X ਲਈ ਸਮਰਪਿਤ ਸਮੂਹ।
- ਪਲੇਟਫਾਰਮ-ਵਿਸ਼ੇਸ਼ ਫਿਲਟਰ ਅਤੇ ਵਿਕਲਪਿਕ ਓਹਲੇ-ਤੱਤ ਨਿਯੰਤਰਣ ਜਿੱਥੇ ਮੌਜੂਦਾ ਪਲੇਟਫਾਰਮ ਪ੍ਰੋਫਾਈਲ ਉਹਨਾਂ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ।
- ਸੰਟੈਕਸ ਜਾਂਚ, ਟੈਂਪਲੇਟਸ, ਰਨ ਨਿਯੰਤਰਣ, ਇੱਕ ਨਿਯੰਤਰਿਤ ਰਨਟਾਈਮ, ਅਤੇ ਇੱਕ ਲੌਗ ਫੀਡ ਦੇ ਨਾਲ ਕਸਟਮ JavaScript ਸਮੂਹ।
- ਪ੍ਰਤੀ-ਸਮੂਹ ਸਮਾਂ-ਸਾਰਣੀ, ਫ੍ਰੀਜ਼ ਮੋਡ, ਸਨੂਜ਼ ਨਿਯੰਤਰਣ, ਆਯਾਤ/ਨਿਰਯਾਤ, ਅਤੇ ਆਟੋਮੈਟਿਕ ਸੇਵ।
- ਸਮਰਥਿਤ ਕਸਟਮ-ਨਿਯਮ ਟੈਕਸਟ, CSV, ਅਤੇ JSON ਓਪਰੇਸ਼ਨਾਂ ਲਈ ਵਿਕਲਪਿਕ ਸਥਾਨਕ-ਫੋਲਡਰ ਪਹੁੰਚ।
- ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਲਿੰਕ ਕੀਤੇ ਸਮੂਹਾਂ ਲਈ ਇੱਕ ਮੂਲ ਵਾਲਟ ਬ੍ਰਿਜ ਹੱਬ ਨਾਲ ਵਿਕਲਪਿਕ ਕਨੈਕਸ਼ਨ।

## ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਚਲਾਓ

1. ਇੱਕ Chromium ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ `chrome://extensions` ਖੋਲ੍ਹੋ।
2. **ਵਿਕਾਸਕਾਰ ਮੋਡ** ਨੂੰ ਸਮਰੱਥ ਬਣਾਓ।
3. **ਲੋਡ ਅਨਪੈਕ** ਚੁਣੋ ਅਤੇ ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਫੋਲਡਰ ਨੂੰ ਚੁਣੋ।
4. ਵਾਲਟ ਐਕਸਟੈਂਸ਼ਨ ਖੋਲ੍ਹੋ ਅਤੇ ਇੱਕ ਸਮੂਹ ਬਣਾਓ।

ਮੈਨੀਫੈਸਟ ਨੂੰ ਇਸਦੇ ਮੌਜੂਦਾ ਔਫਸਕ੍ਰੀਨ ਅਤੇ ਨਿਯਮ API ਲਈ Chrome 116 ਜਾਂ ਬਾਅਦ ਵਾਲੇ ਦੀ ਲੋੜ ਹੈ।

## ਵਿਕਾਸ ਜਾਂਚ

ਇਸ ਫੋਲਡਰ ਤੋਂ ਐਕਸਟੈਂਸ਼ਨ ਟੈਸਟ ਸੂਟ ਚਲਾਓ:

```bash
./tests/run.sh
```

ਸੂਟ ਸਹਾਇਕ ਵਿਵਹਾਰ, ਪਲੇਟਫਾਰਮ ਪ੍ਰੋਫਾਈਲਾਂ, ਮਾਰਕਡਾਊਨ ਰੈਂਡਰਿੰਗ, ਅਤੇ ਅਨੁਵਾਦ ਕੈਟਾਲਾਗ ਆਡਿਟ ਦਾ ਅਭਿਆਸ ਕਰਦਾ ਹੈ।

## ਸਥਾਨਕ ਮੈਨੂਅਲ ਅਤੇ ਅਨੁਵਾਦ

ਅੰਗਰੇਜ਼ੀ ਦਸਤਾਵੇਜ਼ ਪ੍ਰਮਾਣਿਕ ਸਰੋਤ ਬਣੇ ਹੋਏ ਹਨ। ਐਕਸਟੈਂਸ਼ਨ `manual/en.md` ਦੇ ਨਾਲ ਇਸ ਦੇ ਲੋਕਲਾਈਜ਼ਡ ਮੈਨੂਅਲ ਭੇਜਦਾ ਹੈ, ਅਤੇ `i18n-docs/<locale>/` ਦੇ ਹੇਠਾਂ ਰਹਿੰਦੇ ਹੋਰ ਸਾਂਭ-ਸੰਭਾਲ ਦਸਤਾਵੇਜ਼ਾਂ ਦੀਆਂ ਸਥਾਨਕ ਕਾਪੀਆਂ।

`translation/*.json` ਵਿੱਚ UI ਕੈਟਾਲਾਗ ਹਰ ਸਮਰਥਿਤ ਲੋਕੇਲ ਲਈ ਸੰਪੂਰਨ ਹਨ। ਇਸ ਨਾਲ ਕੈਟਾਲਾਗ ਅਤੇ ਸਥਾਨਕ ਦਸਤਾਵੇਜ਼ਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## ਸਕੋਪ

ਵਾਲਟ ਐਕਸਟੈਂਸ਼ਨ ਸਿਰਫ਼ ਬ੍ਰਾਊਜ਼ਰ ਪ੍ਰੋਫਾਈਲ 'ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ ਜਿੱਥੇ ਇਹ ਸਥਾਪਤ ਹੈ ਅਤੇ ਪੰਨਿਆਂ 'ਤੇ ਬ੍ਰਾਊਜ਼ਰ ਇਸਨੂੰ ਪਹੁੰਚ ਦਿੰਦਾ ਹੈ। ਇਹ ਮੂਲ ਐਪਸ ਨੂੰ ਸਥਾਪਿਤ ਨਹੀਂ ਕਰਦਾ, ਸਿਸਟਮ ਅਨੁਮਤੀਆਂ ਨੂੰ ਬਦਲਦਾ ਹੈ, ਜਾਂ ਸਮੂਹਾਂ ਨੂੰ ਸਮਕਾਲੀ ਨਹੀਂ ਕਰਦਾ ਹੈ ਜਦੋਂ ਤੱਕ ਉਪਭੋਗਤਾ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਇੱਕ ਬ੍ਰਿਜ ਨੂੰ ਜੋੜਦਾ ਹੈ ਅਤੇ ਮੇਲ ਖਾਂਦੇ ਸਮੂਹਾਂ ਨੂੰ ਲਿੰਕ ਨਹੀਂ ਕਰਦਾ ਹੈ।
