# वॉल्ट एक्सटेंशन

वॉल्ट एक्सटेंशन क्रोमियम ब्राउज़र के लिए एक मैनिफ़ेस्ट V3 फ़ोकस टूल है। इसका वर्तमान संपादक वेबसाइट ब्लॉक समूहों, समर्थित-प्लेटफ़ॉर्म समूहों, कस्टम जावास्क्रिप्ट समूहों, शेड्यूल, फ़्रीज़ और स्नूज़ नियंत्रण और वैकल्पिक वेब-ऐप ब्रिज लिंक का प्रबंधन करता है।

स्रोत कोड उत्पाद अनुबंध है. [manual/en.md](manual/en.md) पर अंग्रेजी इन-ऐप मैनुअल शिप किए गए नियंत्रणों की व्याख्या करता है; यह पिछले कॉपी किए गए और मशीन-अनुवादित मैनुअल को प्रतिस्थापित करता है।

## वर्तमान क्षमताएँ

- ब्लॉकलिस्ट या अनुमति सूची व्यवहार, वैकल्पिक रीडायरेक्ट, तत्काल ब्लॉकिंग, समय भत्ता या उलटी गिनती के साथ डिफ़ॉल्ट वेबसाइट समूह।
- यूट्यूब, टिकटॉक, फेसबुक, इंस्टाग्राम, ट्विच, रेडिट, डिस्कॉर्ड और ट्विटर/एक्स के लिए समर्पित समूह।
- प्लेटफ़ॉर्म-विशिष्ट फ़िल्टर और वैकल्पिक छिपा-तत्व नियंत्रण जहां वर्तमान प्लेटफ़ॉर्म प्रोफ़ाइल उनका समर्थन करती है।
- सिंटैक्स जांच, टेम्प्लेट, रन नियंत्रण, नियंत्रित रनटाइम और लॉग फ़ीड के साथ कस्टम जावास्क्रिप्ट समूह।
- प्रति-समूह शेड्यूल, फ़्रीज़ मोड, स्नूज़ नियंत्रण, आयात/निर्यात और स्वचालित सेव।
- समर्थित कस्टम-नियम टेक्स्ट, CSV और JSON संचालन के लिए वैकल्पिक स्थानीय-फ़ोल्डर पहुंच।
- स्पष्ट रूप से जुड़े समूहों के लिए मूल वॉल्ट ब्रिज हब से वैकल्पिक कनेक्शन।

## स्थानीय स्तर पर चलाएँ

1. क्रोमियम ब्राउज़र में `chrome://extensions` खोलें।
2. **डेवलपर मोड** सक्षम करें।
3. **लोड अनपैक्ड** चुनें और इस रिपॉजिटरी फ़ोल्डर को चुनें।
4. वॉल्ट एक्सटेंशन खोलें और एक ग्रुप बनाएं।

मेनिफेस्ट को अपने वर्तमान ऑफस्क्रीन और नियम एपीआई के लिए क्रोम 116 या बाद के संस्करण की आवश्यकता है।

## विकास की जाँच

इस फ़ोल्डर से एक्सटेंशन टेस्ट सूट चलाएँ:

```bash
./tests/run.sh
```

सुइट सहायक व्यवहार, प्लेटफ़ॉर्म प्रोफाइल, मार्कडाउन रेंडरिंग और अनुवाद कैटलॉग ऑडिट का अभ्यास करता है।

## स्थानीयकृत मैनुअल और अनुवाद

अंग्रेजी दस्तावेज़ विहित स्रोत बने हुए हैं। एक्सटेंशन अपने स्थानीयकृत मैनुअल को `manual/en.md` के पास भेजता है, और अन्य बनाए गए दस्तावेज़ों की स्थानीयकृत प्रतियां `i18n-docs/<locale>/` के अंतर्गत रहती हैं।

`translation/*.json` में यूआई कैटलॉग प्रत्येक समर्थित लोकेल के लिए पूर्ण हैं। कैटलॉग और स्थानीयकृत दस्तावेज़ों को इसके साथ सत्यापित करें:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## दायरा

वॉल्ट एक्सटेंशन केवल उस ब्राउज़र प्रोफ़ाइल में कार्य करता है जहां यह स्थापित है और उन पेजों पर जहां ब्राउज़र इसे पहुंच प्रदान करता है। यह मूल ऐप्स इंस्टॉल नहीं करता है, सिस्टम अनुमतियाँ नहीं बदलता है, या समूहों को सिंक्रनाइज़ नहीं करता है जब तक कि उपयोगकर्ता स्पष्ट रूप से एक ब्रिज कनेक्ट नहीं करता है और मेल खाने वाले समूहों को लिंक नहीं करता है।
