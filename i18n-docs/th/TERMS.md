# ข้อกำหนดและการใช้งาน - ตัวบล็อกเว็บแบบกำหนดเอง

_อัพเดตล่าสุด: 2026-06-27_

ข้อกำหนดเหล่านี้ครอบคลุมถึงวิธีที่คุณสามารถใช้ **Custom Web Blocker** — เบราว์เซอร์
ส่วนขยาย, แอพ macOS / iOS และเว็บไซต์ โดยการติดตั้งหรือใช้งานใดๆ
ส่วนหนึ่งของโครงการที่คุณเห็นด้วยกับสิ่งที่อยู่ด้านล่าง เวอร์ชันสั้น: ฟรี
เป็นโอเพ่นซอร์ส ใช้งานได้อย่างอิสระ และไม่มีการรับประกัน

##สินค้าแถมฟรี

- ทุกฟีเจอร์ใช้งานได้ฟรี ไม่มีการซื้อ การสมัครสมาชิก หรือการชำระเงิน
  ระดับ — ตอนนี้หรือหลังจากนั้น
- วิธีเดียวที่โครงการจะใช้เงินได้คือสมัครใจและเป็นทางเลือก
  การบริจาค ไม่มีสิ่งใดถูกกั้นไว้ข้างหลัง

## ข้อมูลของคุณ

- ตามค่าเริ่มต้น ไม่มีอะไรเกี่ยวกับการท่องเว็บของคุณออกจากอุปกรณ์ของคุณ
- เราจะไม่เปิดเผยข้อมูลของคุณกับบุคคลที่สามหรือสร้างรายได้จาก
  มัน. ดูนโยบายความเป็นส่วนตัวสำหรับรายละเอียดทั้งหมด
- ข้อยกเว้นทางเลือกเดียวคือการเลือกใช้การจัดหมวดหมู่รหัสช่อง ซึ่ง
  แชร์รหัสช่องที่ไม่เปิดเผยตัวตน (ไม่ต้องใส่ชื่อหรือประวัติการดู) เพื่อช่วยติดป้ายกำกับ
  ผู้สร้างสำหรับทุกคน มันปิดอยู่เว้นแต่คุณจะเปิดมัน

## บัญชี

- บัญชีเป็น **ทางเลือก** การดาวน์โหลดและการบล็อกทุกฟีเจอร์ใช้งานได้
  โดยไม่ต้องลงชื่อเข้าใช้
- บัญชีจะเพิ่มเฉพาะการซิงค์ข้ามอุปกรณ์และชื่อที่แสดงเท่านั้น
- คุณมีหน้าที่รับผิดชอบในการรักษารหัสผ่านของคุณให้ปลอดภัย คุณสามารถเปลี่ยนของคุณ
  ชื่อที่แสดงหรือ **ลบบัญชีของคุณอย่างถาวร** ได้ตลอดเวลาจาก
  แผงบัญชี การลบจะเป็นการลบบัญชี เซสชัน และรหัสที่รอดำเนินการของคุณ

## การใช้งานที่ยอมรับได้

- ใช้ซอฟต์แวร์เพื่อวัตถุประสงค์ทางกฎหมาย มุ่งเน้นส่วนบุคคล และเพิ่มประสิทธิภาพการทำงาน
- อย่าใช้มันเพื่อทำร้ายผู้อื่น หลีกเลี่ยงความปลอดภัยที่คุณไม่ได้เป็นเจ้าของ หรือละเมิด
  ข้อกำหนดของเว็บไซต์และแพลตฟอร์มที่คุณเยี่ยมชม
- กฎการบล็อกทำงานภายในเบราว์เซอร์/อุปกรณ์ของคุณภายใต้ของคุณ
  ควบคุม; คุณต้องรับผิดชอบต่อกฎที่คุณสร้างขึ้น

## โอเพ่นซอร์สและใบอนุญาต

- แหล่งที่มาทั้งหมดเปิดเผยต่อสาธารณะ ดังนั้นคุณจึงสามารถตรวจสอบการอ้างสิทธิ์ทุกรายการได้ที่นี่ด้วยตัวเอง
- มีให้ **ตามสภาพ** โดยไม่มีการรับประกันใดๆ ให้สูงสุด
  ตามขอบเขตที่กฎหมายอนุญาต ผู้เขียนจะไม่รับผิดชอบต่อความเสียหายใดๆ ที่เกิดขึ้น
  จากการใช้งาน

## การเปลี่ยนแปลง

- ข้อกำหนดเหล่านี้อาจมีการปรับปรุงเมื่อมีการพัฒนาโครงการ การเปลี่ยนแปลงวัสดุจะเป็น
  สะท้อนให้เห็นที่นี่พร้อมกับวันที่ "อัปเดตล่าสุด" ใหม่

> นี่เป็นโครงการโอเพ่นซอร์สส่วนตัวโดยนักเรียนมัธยมปลาย — ไม่ใช่
> บริษัท ข้อกำหนดเหล่านี้เขียนด้วยภาษาธรรมดาและด้วยความสุจริตใจ
