# นโยบายความเป็นส่วนตัว — ตัวบล็อกเว็บแบบกำหนดเอง

_อัปเดตล่าสุด: 2026-08-04_

หน้านี้อธิบายอย่างชัดเจนว่าส่วนขยายเบราว์เซอร์ **ตัวบล็อกเว็บแบบกำหนดเอง** เก็บรวบรวมข้อมูลใดบ้าง ข้อมูลนั้นไปที่ใด และเหตุใดจึงขอสิทธิ์เบราว์เซอร์แต่ละรายการ กล่าวโดยย่อ: เราไม่บันทึกกฎหรือข้อมูลการท่องเว็บส่วนตัวของคุณ การเก็บรวบรวมและการจัดหมวดหมู่ของ Vault Classifier ซึ่งเป็นทางเลือกยังคงอยู่ในการควบคุมของคุณ และใช้บริดจ์ภายในเครื่องที่ผ่านการยืนยันตัวตน การผสานการทำงาน AI ภายในเครื่อง (MCP) แบบทางเลือกที่แยกต่างหากก็ปิดอยู่ตามค่าเริ่มต้นเช่นกัน และเปิดเผยข้อมูลเฉพาะกับผู้ช่วยที่คุณเชื่อมต่อและอนุมัติด้วยตนเองเท่านั้น

## สรุป

- **การกำหนดค่าของคุณยังคงอยู่ในเบราว์เซอร์ของคุณ** กลุ่มการบล็อก กำหนดการ กฎแบบกำหนดเอง บันทึก ตัวจับเวลา และค่ากำหนดจะถูกเก็บไว้เฉพาะในที่จัดเก็บข้อมูลส่วนขยายภายในเครื่องของ Chrome (`chrome.storage.local`) เท่านั้น
- **Vault Classifier ทำงานภายในเครื่องเท่านั้น** หากคุณเปิดใช้งานการผสาน Vault Classifier แบบทางเลือกอย่างชัดแจ้ง หลักฐานที่มองเห็นได้บนการ์ด/หน้า YouTube (เช่น ชื่อเรื่อง คำอธิบายที่มองเห็นได้ แท็กที่แสดง และรหัสผู้สร้าง/วิดีโอสาธารณะ) จะถูกส่งผ่านบริดจ์ Vault ภายในเครื่องที่ผ่านการยืนยันตัวตนไปยัง Vault Classifier บน Mac ของคุณเท่านั้น ข้อมูลนี้จะไม่ถูกส่งไปยังเว็บไซต์ของเรา ผู้ให้บริการโมเดล YouTube Data API หรือเซิร์ฟเวอร์อื่นใด
- **การเก็บรวบรวมเป็นการเลือกเข้าร่วม (opt-in) แยกต่างหาก** Vault Classifier จะขอเมทาดาทา YouTube ที่เรนเดอร์แล้วและไม่มีโฆษณาจากส่วนขยายก็ต่อเมื่อคุณเปิดการเก็บรวบรวม YouTube ในพื้นที่ทำงานข้อมูลการจัดหมวดหมู่ของมันแล้วเท่านั้น เมื่อปิดอยู่ ส่วนขยายจะไม่ส่งชื่อเรื่องหรือเมทาดาทาของผู้สร้างใด ๆ เพื่อการเก็บรวบรวม เมื่อเปิดอยู่ ฟิลด์ภายในเครื่องที่เก็บไว้อาจรวมถึงชื่อเรื่องที่มองเห็นได้ ชื่อ/ตัวระบุผู้สร้าง ประเภทวิดีโอ ความยาว ข้อความจำนวนผู้ติดตาม/ยอดชม/เวลาที่เผยแพร่ที่มองเห็นได้ และ URL แบบมาตรฐาน
- **การผสานการทำงาน AI ภายในเครื่อง (MCP) แบบทางเลือก** หากคุณเปิดใช้งานและเชื่อมต่อผู้ช่วย AI ของคุณเอง ผู้ช่วยนั้นสามารถ — ตามคำสั่งที่ชัดแจ้งของคุณ — อ่านข้อมูลที่เลือก (การกำหนดค่า กิจกรรม เวลาการใช้งาน URL ของแท็บที่ใช้งานอยู่/ที่เปิดอยู่ เนื้อหาหน้าเว็บที่มองเห็นได้บนไซต์ที่คุณกำหนดค่าไว้ และหลักฐานใด ๆ ของ Classifier) ผ่านเซิร์ฟเวอร์ Vault ภายในเครื่องบนอุปกรณ์ของคุณ ฟีเจอร์นี้ปิดอยู่ตามค่าเริ่มต้น ทุกการเชื่อมต่อได้รับการอนุมัติจากคุณ และไม่สามารถอ่านรหัสผ่านและคีย์ API ผ่านฟีเจอร์นี้ได้เลย ดู "การผสานการทำงาน AI ภายในเครื่อง (MCP) แบบทางเลือก" ด้านล่าง
- **ไม่มีการวิเคราะห์ โปรไฟล์โฆษณา การวัดและส่งข้อมูลระยะไกล หรือการรายงานข้อขัดข้อง**
- **ไม่มีการติดตาม** กิจกรรมการท่องเว็บเกินกว่าที่จำเป็นอย่างยิ่งในการบังคับใช้กฎการบล็อกที่คุณกำหนดค่าไว้เอง

## สิ่งที่จัดเก็บไว้ภายในเครื่อง

ส่วนขยายจะจัดเก็บสิ่งต่อไปนี้ไว้ในที่จัดเก็บข้อมูลส่วนขยายภายในเครื่องของเบราว์เซอร์ของคุณ เพื่อให้ทำงานได้ข้ามเซสชัน:

- กลุ่มการบล็อกที่คุณสร้าง: ชื่อ ประเภทกฎ รายการไซต์ที่ถูกบล็อก กำหนดการ การตั้งค่าการเลื่อน (snooze) สถานะการตรึง และ JavaScript ของกฎแบบกำหนดเองใด ๆ ที่คุณเขียน
- สถานะรันไทม์ต่อกลุ่มที่จำเป็นต่อการบังคับใช้ขีดจำกัด (เช่น เหลือกี่นาทีของงบประมาณการอนุญาตแบบเลื่อนเวลาในวันนี้ การเลื่อนจะสิ้นสุดเมื่อใด ช่วงการตรึงแบบเข้มงวดจะสิ้นสุดเมื่อใด)
- ค่ากำหนดของคุณเองที่ตั้งไว้ใน **การตั้งค่า** (อัตราการติ๊ก การหน่วงการบันทึกอัตโนมัติ ระยะเวลาการเลื่อนเริ่มต้น URL สำรองเริ่มต้น สวิตช์โหมดแก้จุดบกพร่อง ภาษาส่วนติดต่อที่เลือก)
- รายการบันทึกกิจกรรมที่แสดงในแผง **บันทึก** ในแอป ซึ่งคุณสามารถล้างได้จากส่วนติดต่อ
- เมื่อคุณเปิดใช้งาน Vault Classifier อย่างชัดแจ้ง แอปภายในเครื่องของมันจะเก็บแคชภายในเครื่องที่มีขอบเขตจำกัดโดยผู้ใช้ ซึ่งประกอบด้วยหลักฐานที่มองเห็นได้ คะแนนภายในเครื่อง การตัดสินใจ และการแก้ไขที่จำเป็นต่อการจัดหมวดหมู่และอธิบายรายการ แคชนี้ยังคงอยู่บน Mac ของคุณ และไม่ได้เป็นส่วนหนึ่งของการรับส่งข้อมูลปกติระหว่างส่วนขยายกับเซิร์ฟเวอร์

การกำหนดค่า สถานะรันไทม์ และบันทึกกิจกรรมของคุณยังคงอยู่บนอุปกรณ์ของคุณ และไม่ได้ถูกบันทึกโดยบริการของเรา ขึ้นอยู่กับรุ่นบิลด์ของเบราว์เซอร์และฟีเจอร์ที่คุณเปิดใช้งาน สิ่งเหล่านี้อาจได้รับการประมวลผลโดยส่วนขยาย แอปคู่หู Safari ภายในเครื่องบนอุปกรณ์ หรือบริดจ์ Vault ภายในเครื่องที่เชื่อมโยงไว้อย่างชัดแจ้ง

## สิ่งที่ไม่ได้เก็บรวบรวมหรือส่งออก

ส่วนนี้อธิบายพฤติกรรมของส่วนขยายด้วยตัวมันเอง ข้อยกเว้นเดียวคือการผสานการทำงาน AI ภายในเครื่อง (MCP) แบบทางเลือกที่คุณสามารถเปิดใช้งานและเชื่อมต่อได้เอง ซึ่งอธิบายไว้ในส่วนถัดไป

- ประวัติการท่องเว็บไม่ได้ถูกบันทึก สรุป หรือส่งออกโดยตัวส่วนขยายเอง มันถูกใช้เพียงเพื่อบังคับใช้กฎที่คุณกำหนดค่าไว้เท่านั้น
- เนื้อหาหน้าเว็บไม่ได้ถูกดึงออก จับภาพหน้าจอ หรือบันทึกโดยตัวส่วนขยายเอง
- หลักฐานของ Vault Classifier ไม่ได้ถูกส่งออกนอกอุปกรณ์โดยส่วนขยาย มันจะถูกประมวลผลโดยบริดจ์ภายในเครื่องที่จับคู่ไว้และแอปเฉพาะเมื่อคุณเปิดใช้งานการผสานนั้นอย่างชัดแจ้งเท่านั้น
- ข้อมูลที่กรอกในแบบฟอร์มและรหัสผ่านไม่เคยถูกอ่านโดยส่วนขยาย รหัสผ่านและคีย์ API ก็ไม่สามารถอ่านผ่านการผสานการทำงาน AI ภายในเครื่อง (MCP) ได้เช่นกัน
- ไม่มีการส่งตัวระบุส่วนขยาย ตัวระบุบัญชี ตัวระบุอุปกรณ์ หรือการกำหนดค่ากฎของคุณเพื่อการบังคับใช้กฎตามปกติ

## การผสานการทำงาน AI ภายในเครื่อง (MCP) แบบทางเลือก

ส่วนขยายสามารถตอบคำขอจาก **เซิร์ฟเวอร์ MCP Vault** ภายในเครื่องได้ตามทางเลือก โดยเซิร์ฟเวอร์นั้นทำงานอยู่ภายในแอปเดสก์ท็อป Vault บนอุปกรณ์ของคุณเอง เพื่อให้คุณสามารถเชื่อมต่อผู้ช่วย AI ของคุณเอง ("ไคลเอนต์ MCP") และให้มันอ่านหรือดำเนินการกับการตั้งค่า Vault ของคุณแทนคุณได้ การผสานนี้ **ปิดอยู่ตามค่าเริ่มต้น** และจะไม่เปลี่ยนแปลงสิ่งใดเว้นแต่คุณจะเปิดใช้งานโดยตั้งใจ

- **คุณเป็นผู้เริ่ม** จะไม่มีการเปิดเผยสิ่งใดจนกว่าคุณจะเปิดใช้งานการผสานและเชื่อมต่อไคลเอนต์ MCP และการเชื่อมต่อของไคลเอนต์แต่ละรายได้รับการอนุมัติจากคุณ การปิดใช้งานจะเพิกถอนการเข้าถึงทันที
- **เซิร์ฟเวอร์อยู่ภายในเครื่อง** ข้อมูลที่ส่วนขยายจัดหาให้จะถูกส่งมอบผ่านบริดจ์บนอุปกรณ์ที่ผ่านการยืนยันตัวตนเดียวกันไปยังเซิร์ฟเวอร์ MCP Vault บน Mac ของคุณ — ไม่ใช่ไปยังเว็บไซต์ของเราหรือเซิร์ฟเวอร์ Vault ใด ๆ ตัวส่วนขยายเองไม่ได้ส่งข้อมูลของคุณไปยังบุคคลที่สาม
- **จากนั้นผู้ช่วยของคุณเป็นผู้ตัดสินใจ** เมื่อไคลเอนต์ MCP ที่เชื่อมต่ออยู่ได้รับข้อมูลตามคำขอของคุณแล้ว สิ่งที่จะเกิดขึ้นกับข้อมูลนั้นเป็นไปตาม **ไคลเอนต์รายนั้น** และข้อกำหนดความเป็นส่วนตัวของมันเอง หากผู้ช่วยที่คุณเลือกอาศัยบริการระยะไกล ผู้ช่วยนั้นอาจส่งข้อมูลของคุณตามคำสั่งของคุณ — เช่นเดียวกับเมื่อคุณวางข้อมูลลงในเครื่องมือ AI ใด ๆ โปรดเลือกไคลเอนต์ที่คุณไว้วางใจ
- **สิ่งที่สามารถถูกเปิดเผยได้** ตามคำสั่งของคุณ ผู้ช่วยที่เชื่อมต่ออยู่สามารถอ่านกลุ่มการบล็อก กำหนดการ กฎแบบกำหนดเอง บันทึกกิจกรรม ตัวนับเวลาการใช้งาน URL ของแท็บที่ใช้งานอยู่หรือแท็บที่เปิดอยู่ เนื้อหาหน้าเว็บที่มองเห็นได้บนไซต์ที่คุณกำหนดค่าไว้ ตลอดจนหลักฐานและการตัดสินใจใด ๆ ของ Vault Classifier การกระทำที่เปลี่ยนสถานะ (การแก้ไขกลุ่ม การเริ่มการเลื่อน การเรียกใช้กฎที่บันทึกไว้ การเรียกให้จัดหมวดหมู่) จะได้รับการยืนยันทีละรายการ
- **ความลับยังคงเป็นความลับ** รหัสผ่าน (เช่น รหัสผ่านการควบคุมโดยผู้ปกครอง) และคีย์ API ของผู้ให้บริการเป็นแบบ **เขียนได้อย่างเดียว** ผ่านการผสานนี้: สามารถตั้งค่าได้ แต่ไม่มีผู้ช่วยใดสามารถอ่านกลับได้
- **เฉพาะ Chromium เท่านั้น** เช่นเดียวกับบริดจ์ Classifier การผสานนี้มีอยู่เฉพาะในเบราว์เซอร์ Chromium ที่มีโฮสต์ภายในเครื่องบนอุปกรณ์เท่านั้น Firefox และ Safari ไม่เปิดเผยมัน

## เหตุใดจึงขอสิทธิ์แต่ละรายการ

| สิทธิ์ | ใช้เพื่ออะไร |
| --- | --- |
| `storage` | บันทึกและโหลดกลุ่มการบล็อก การตั้งค่า และสถานะรันไทม์ของคุณเฉพาะในเบราว์เซอร์ของคุณเท่านั้น |
| `favicon` | แสดงไอคอนไซต์ที่เบราว์เซอร์แคชไว้ข้างกฎใน Chromium สิ่งนี้ไม่ส่งประวัติการท่องเว็บและไม่ส่งคำขอไปยังบริการของเรา |
| `nativeMessaging` | ใน Chromium จะขอหลักฐาน Native Messaging ภายในเครื่องจากอุปกรณ์สำหรับบริดจ์ Vault Classifier ที่ผ่านการยืนยันตัวตน ใน Safari จะส่งต่อคำขอแซนด์บ็อกซ์ของกฎแบบกำหนดเองไปยังแอปคอนเทนเนอร์ภายในเครื่องบนอุปกรณ์ นี่ไม่ใช่การส่งผ่านทางคลาวด์ |
| `alarms` | ปลุก service worker เบื้องหลังตามกำหนดการเพื่อรีเฟรชขีดจำกัดตามเวลาและสถานะกฎเมื่อหน้าต่างการเลื่อน การตรึง หรือกำหนดการสิ้นสุดลง |
| `offscreen` | เรียกใช้ JavaScript ของกฎแบบกำหนดเองในแซนด์บ็อกซ์ในเอกสารนอกหน้าจอ เพื่อไม่ให้มันหลุดออกจากส่วนขยายหรือแตะต้องหน้าเว็บของคุณโดยตรง |
| `tabs` | เปิดตัวแก้ไขเป็นแท็บเต็มเมื่อคุณคลิกไอคอนแถบเครื่องมือ ค้นหา URL ของแท็บที่ใช้งานอยู่เพื่อประเมินกฎของกลุ่ม และโหลดแท็บใหม่หลังจากการเปลี่ยนแปลงกฎที่คุณทำในตัวแก้ไข |
| `webNavigation` | ตรวจจับการเปลี่ยน URL ของ SPA (การนำทางแบบ push-state) เพื่อให้ตัวซ่อนฟีดตามแพลตฟอร์มและกฎที่ขับเคลื่อนด้วยเหตุการณ์สามารถตอบสนองต่อการนำทางภายในหน้าได้ ไม่ใช่เพียงการโหลดทั้งหน้า |
| การเข้าถึงโฮสต์ `<all_urls>` | ใช้กฎการบล็อกและตัวซ่อนฟีดตามแพลตฟอร์มของคุณบนไซต์ที่คุณเลือกจะบล็อก ส่วนขยายจะอ่าน/แก้ไขหน้าเฉพาะที่ URL ที่คุณได้กำหนดค่ากฎไว้อย่างจริงจัง และเพื่อบังคับใช้กฎนั้นเท่านั้น อะแดปเตอร์ Vault Classifier แบบทางเลือกถูกจำกัดไว้ที่ YouTube |

## กฎแบบกำหนดเอง

หากคุณเขียนกฎ JavaScript แบบกำหนดเอง โค้ดนั้น:

- ทำงานในแซนด์บ็อกซ์ในเอกสารนอกหน้าจอ มันไม่สามารถเข้าถึงเครือข่าย หน้าเว็บของคุณ หรือส่วนขยายอื่นได้โดยตรง
- สื่อสารกับสคริปต์เนื้อหาผ่านบริดจ์ข้อความแบบคงที่ที่กำหนดโดย API ตัวช่วยของส่วนขยายเท่านั้น
- ถูกกักกันโดยอัตโนมัติ (ปิดใช้งานพร้อมรายการบันทึก) หากเกินขีดจำกัดในตัวด้าน CPU บันทึก post-message หรือการกลายพันธุ์ DOM

กฎแบบกำหนดเองของคุณถูกจัดเก็บไว้ภายในเครื่องพร้อมกับการตั้งค่าที่เหลือ และไม่เคยถูกส่งออกนอกอุปกรณ์

## สถิติเว็บไซต์

ส่วนนี้เกี่ยวกับ **เว็บไซต์** เว็บไซต์เผยแพร่แผง **สถิติ** เล็ก ๆ และเพื่อเติมข้อมูลลงไป เซิร์ฟเวอร์จะเก็บจำนวนนับแบบรวมไม่กี่รายการ:

- **จำนวนการดาวน์โหลด** — ปุ่มดาวน์โหลดของแต่ละผลิตภัณฑ์ถูกคลิกกี่ครั้ง (macOS, Windows, ส่วนขยายเบราว์เซอร์, Safari)
- **บัญชี** — มีบัญชีอยู่กี่บัญชี
- **กิจกรรมถาม-ตอบ** — จำนวนโพสต์และความคิดเห็นในฟอรัมทั้งหมด

หนึ่งครั้งต่อชั่วโมง เซิร์ฟเวอร์จะบันทึกค่าปัจจุบันของจำนวนนับแบบรวมแต่ละรายการ สแนปช็อตเหล่านี้ไม่มีเหตุการณ์ต่อผู้เยี่ยมชม เส้นทางการคลิก หรือประวัติเซสชันใด ๆ

- **ไม่ระบุตัวตนโดยสมบูรณ์ / ลบล้างการระบุตัวตน** สิ่งเหล่านี้เป็นเพียงยอดรวมสะสมธรรมดา พวกมัน **ไม่** เชื่อมโยงกับชื่อ บัญชี อีเมล ที่อยู่ IP อุปกรณ์ หรือตัวระบุอื่นใดของคุณ — ไม่มีวิธีใดที่จะสืบจำนวนนับกลับไปยังบุคคลได้
- **ไม่เคยเป็นเชิงพาณิชย์** ข้อมูลนี้มีอยู่เพียงเพื่อแสดงแผงสถิติสาธารณะเท่านั้น มัน **ไม่เคยถูกขาย แบ่งปันกับบุคคลที่สาม ใช้เพื่อการโฆษณา หรือใช้เพื่อวัตถุประสงค์เชิงพาณิชย์อื่นใด**

## เด็ก

ส่วนขยายนี้เป็นเครื่องมือเพิ่มประสิทธิภาพการทำงานสำหรับการใช้งานทั่วไป มันไม่ได้มุ่งเป้าไปที่เด็ก ไม่เก็บรวบรวมข้อมูลจากผู้ใดโดยเจตนา และไม่แสดงโฆษณา

## การเปลี่ยนแปลงนโยบายนี้

หากแนวปฏิบัติด้านข้อมูลมีการเปลี่ยนแปลงในเวอร์ชันอนาคต ไฟล์นี้จะได้รับการอัปเดต และการเปลี่ยนแปลงจะถูกสรุปไว้ในหมายเหตุเวอร์ชันของรุ่นนั้น
