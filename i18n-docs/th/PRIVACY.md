# นโยบายความเป็นส่วนตัว — ตัวบล็อกเว็บแบบกำหนดเอง

_อัปเดตล่าสุด: 2026-07-13_

หน้านี้อธิบายอย่างชัดเจนว่าข้อมูลใดของเบราว์เซอร์ **Custom Web Blocker**
ส่วนขยายรวบรวม จะไปอยู่ที่ไหน และเหตุใดการอนุญาตเบราว์เซอร์แต่ละรายการจึงเป็นเช่นนั้น
ร้องขอ กล่าวโดยสรุป เราไม่บันทึกกฎหรือข้อมูลการท่องเว็บส่วนบุคคลของคุณ
กฎตามแท็กอาจค้นหารหัสช่อง YouTube ที่เป็นสาธารณะ แต่คำขอนั้นจะไม่ถูกเก็บ
หรือเชื่อมโยงกับคุณ

## สรุป

- **การตั้งค่าอยู่ในเบราว์เซอร์** กลุ่ม ตารางเวลา กฎ บันทึก ตัวจับเวลา และ
  ค่ากำหนดจะถูกเก็บไว้ใน `chrome.storage.local` เท่านั้น
- **การค้นหาแท็กมีเพียงรหัสช่องสาธารณะ** ไม่ส่ง URL ชื่อวิดีโอ คำค้นหา
  เวลา บัญชี หรือการตั้งค่าส่วนขยาย
- **คำขอค้นหาไม่ถูกบันทึก** API เป็นแบบอ่านอย่างเดียว ไม่เพิ่มช่องที่ไม่รู้จัก
  และไม่ผูกคำขอกับบุคคล
- **ไม่มีการวิเคราะห์ การวัดและส่งข้อมูลทางไกล โฆษณา หรือรายงานข้อขัดข้อง**
- **ไม่มีการติดตาม** กิจกรรมการท่องเว็บที่นอกเหนือไปจากที่จำเป็นอย่างยิ่ง
  เพื่อใช้กฎการบล็อกที่คุณกำหนดค่าเอง

## สิ่งที่เก็บไว้ในเครื่อง

ส่วนขยายจะจัดเก็บข้อมูลต่อไปนี้ไว้ในส่วนขยายท้องถิ่นของเบราว์เซอร์ของคุณ
พื้นที่เก็บข้อมูลเพื่อให้สามารถทำงานข้ามเซสชันได้:

- กลุ่มบล็อกที่คุณสร้าง: ชื่อ ประเภทกฎ รายการ
  ไซต์ที่ถูกบล็อก ตารางเวลา การตั้งค่าการเลื่อน สถานะการหยุด และอื่นๆ
  JavaScript กฎที่กำหนดเองที่คุณเขียน
- สถานะรันไทม์ต่อกลุ่มจำเป็นต้องบังคับใช้ขีดจำกัด (เช่น จำนวน
  นาทีของงบประมาณเผื่อล่าช้าจะยังคงอยู่ในวันนี้ เมื่อการเลื่อนปลุก
  สิ้นสุดลงเมื่อสิ้นสุดระยะเวลาการแช่แข็งที่เข้มงวด)
- การตั้งค่าของคุณเองที่ตั้งไว้ใน **การตั้งค่า** (อัตราเห็บ บันทึกอัตโนมัติ
  debounce, ระยะเวลาการเลื่อนเริ่มต้น, URL สำรองเริ่มต้น, โหมดแก้ไขข้อบกพร่อง
  สลับ ภาษา UI ที่เลือก)
- รายการบันทึกกิจกรรมที่แสดงในแผง **บันทึก** ในแอป ซึ่งคุณสามารถทำได้
  ชัดเจนจาก UI

ข้อมูลนี้อ่านและเขียนโดยสคริปต์ของส่วนขยายเท่านั้น
บนอุปกรณ์ของคุณและภายในโปรไฟล์เบราว์เซอร์ของคุณเองเท่านั้น

## สิ่งที่ไม่ได้รวบรวมหรือส่ง

- ประวัติการเรียกดูจะไม่ถูกบันทึก สรุป หรือส่งต่อ
- เนื้อหาของหน้าไม่ถูกกรอง จับภาพหน้าจอ หรือบันทึก
- การกรอกแบบฟอร์ม รหัสผ่าน และข้อมูลส่วนบุคคลจะไม่ถูกอ่าน
- ไม่มีข้อมูลเกี่ยวกับคุณ อุปกรณ์ของคุณ หรือการใช้งานของคุณถูกส่งไปยัง
  ผู้เขียนส่วนขยายหรือบุคคลที่สาม

## เหตุใดจึงต้องขออนุญาตแต่ละครั้ง

| การอนุญาต | ใช้สำหรับ |
| --- | --- |
| `storage` | บันทึกและโหลดกลุ่มบล็อก การตั้งค่า และสถานะรันไทม์ในเบราว์เซอร์ของคุณเท่านั้น |
| `favicon` | แสดงไอคอนเว็บไซต์ที่แคชไว้ในเบราว์เซอร์ข้างกฎใน Chromium โดยไม่ส่งประวัติการท่องเว็บหรือเรียกบริการของเรา |
| `nativeMessaging` | ใน Chromium จะขอหลักฐาน Native Messaging ภายในอุปกรณ์สำหรับบริดจ์ Vault Classifier ที่ผ่านการยืนยันตัวตน; ใน Safari จะส่งคำขอแซนด์บ็อกซ์ของกฎแบบกำหนดเองไปยังแอปภายในอุปกรณ์ นี่ไม่ใช่การส่งผ่านคลาวด์ |
| `alarms` | ปลุกพนักงานบริการเบื้องหลังตามกำหนดเวลาเพื่อรีเฟรชขีดจำกัดตามเวลา และอัปเดตสถานะกฎเมื่อการเลื่อน การหยุด หรือกำหนดเวลาสิ้นสุดหน้าต่าง |
| `offscreen` | เรียกใช้ JavaScript กฎที่กำหนดเองแบบแซนด์บ็อกซ์ในเอกสารนอกหน้าจอ เพื่อไม่ให้หนีส่วนขยายหรือแตะหน้าเว็บของคุณโดยตรง |
| `tabs` | เปิดตัวแก้ไขเป็นแท็บแบบเต็มเมื่อคุณคลิกไอคอนแถบเครื่องมือ ค้นหา URL ของแท็บที่ใช้งานอยู่เพื่อประเมินกฎของกลุ่ม และโหลดแท็บใหม่หลังจากการเปลี่ยนแปลงกฎที่คุณทำในตัวแก้ไข |
| `webNavigation` | ตรวจจับการเปลี่ยนแปลง URL ของ SPA (การนำทางแบบพุชสเตต) เพื่อให้ตัวซ่อนฟีดต่อแพลตฟอร์มและกฎที่ขับเคลื่อนด้วยเหตุการณ์สามารถตอบสนองต่อการนำทางในหน้าเว็บ ไม่ใช่แค่การโหลดทั้งหน้า |
| `<all_urls>` การเข้าถึงโฮสต์ | ใช้กฎการบล็อกและตัวซ่อนฟีดต่อแพลตฟอร์มกับไซต์ใดก็ตามที่คุณเลือกบล็อก ส่วนขยายจะอ่าน/แก้ไขเพจเฉพาะใน URL ที่คุณได้กำหนดค่ากฎไว้ และเพื่อบังคับใช้กฎนั้นเท่านั้น |

## กฎที่กำหนดเอง

หากคุณเขียนกฎ JavaScript แบบกำหนดเอง โค้ดนั้น:

- ทำงานในเอกสารนอกจอแบบแซนด์บ็อกซ์ ก็ไม่สามารถเข้าถึงโดยตรงได้
  เครือข่าย เพจของคุณ หรือส่วนขยายอื่นๆ
- สื่อสารกับสคริปต์เนื้อหาผ่านบริดจ์ข้อความคงที่เท่านั้น
  กำหนดโดย API ตัวช่วยของส่วนขยาย
- ถูกกักกันโดยอัตโนมัติ (ปิดใช้งานด้วยรายการบันทึก) หากเป็นเช่นนั้น
  เกินขีดจำกัด CPU, บันทึก, โพสต์ข้อความ หรือการเปลี่ยนแปลง DOM ในตัว

กฎที่คุณกำหนดเองจะถูกจัดเก็บไว้ในเครื่องพร้อมกับการตั้งค่าที่เหลือของคุณ
และไม่เคยถูกส่งออกจากอุปกรณ์

## สถิติการบริการเว็บไซต์และแท็กผู้สร้าง

ส่วนนี้กล่าวถึง **เว็บไซต์และบริการแท็กผู้สร้าง** ส่วนขยายสามารถค้นหารหัสช่อง
สาธารณะแบบอ่านอย่างเดียว และคำขอนั้นจะไม่ถูกบันทึก แผง **สถิติ** เก็บเฉพาะ
ยอดรวมที่ไม่เชื่อมโยงกับบุคคล:

- **จำนวนการดาวน์โหลด** — จำนวนครั้งของปุ่มดาวน์โหลดของผลิตภัณฑ์แต่ละรายการ
  คลิกแล้ว (macOS, Windows, ส่วนขยายเบราว์เซอร์, Safari)
- **จำแนกผู้สร้าง** — จำนวนผู้สร้าง YouTube ที่ถูกแท็ก
- **บัญชี** — มีกี่บัญชี
- **กิจกรรมถามตอบ** — จำนวนโพสต์และความคิดเห็นในฟอรั่มทั้งหมด

เซิร์ฟเวอร์จะบันทึกค่าปัจจุบันของแต่ละจำนวนเหล่านี้และทุกๆ ชั่วโมง
ไม่มีอะไรอื่น ไม่มีบันทึกต่อเหตุการณ์ ไม่มีสตรีมการคลิก และไม่มีเซสชัน
ประวัติศาสตร์

- **ไม่ระบุชื่อโดยสมบูรณ์ / ไม่ระบุตัวตน** เหล่านี้เป็นยอดรวมที่รันอยู่ทั่วไป พวกเขา
  **ไม่**เชื่อมโยงกับชื่อ บัญชี อีเมล ที่อยู่ IP อุปกรณ์ หรือใดๆ ของคุณ
  ตัวระบุอื่นๆ — ไม่มีทางที่จะนับถอยหลังให้กับบุคคลได้
- **ไม่เคยใช้ในเชิงพาณิชย์** ข้อมูลนี้มีไว้เพื่อแสดงสถิติสาธารณะเท่านั้น
  แผงหน้าปัด **ไม่เคยขาย แบ่งปันกับบุคคลที่สาม ใช้เพื่อการโฆษณา
  หรือใช้เพื่อวัตถุประสงค์ทางการค้าอื่นใด**
- **การสนับสนุนช่องรหัสเพิ่มเติม** หาก — และเฉพาะในกรณีที่ — คุณเลือกเข้าร่วม
  ส่วนขยาย/เว็บไซต์อาจแชร์ YouTube **รหัสช่อง** (ไม่ใช้ชื่อวิดีโอ
  ประวัติการดูหรืออะไรก็ตามที่เป็นส่วนตัว) เพื่อช่วยจำแนกผู้สร้างสำหรับทุกคน
- **การส่งด้วยตนเอง** เมื่อผู้ใช้ที่เข้าสู่ระบบตั้งใจส่ง ความเชื่อมโยงระหว่าง
  อีเมลกับรหัสช่องจะเก็บไว้เฉพาะช่วงโควตา 24 ชั่วโมงและล้างทุกชั่วโมง
- **คิวสาธารณะ** อาจแสดงรหัสและสถานะ แต่ไม่แสดงเวลาที่ส่งหรือผู้ส่ง

## เด็กๆ

ส่วนขยายนี้เป็นเครื่องมือเพิ่มประสิทธิภาพการทำงานทั่วไป มันไม่ใช่
มุ่งเป้าไปที่เด็ก ไม่รวบรวมข้อมูลจากใครโดยเจตนา และ
ไม่แสดงโฆษณา

## การเปลี่ยนแปลงนโยบายนี้

หากแนวทางปฏิบัติด้านข้อมูลมีการเปลี่ยนแปลงในเวอร์ชันในอนาคต ไฟล์นี้จะมีการเปลี่ยนแปลง
ได้รับการอัปเดตและการเปลี่ยนแปลงจะถูกสรุปไว้ในหมายเหตุเวอร์ชันสำหรับ
การเปิดตัวครั้งนั้น

## ติดต่อ

คำถาม ข้อกังวล หรือรายงานข้อผิดพลาด: โปรดเปิดประเด็นที่
ที่เก็บซอร์สของส่วนขยาย หรือใช้อีเมลสนับสนุนที่แสดงอยู่ใน
รายการ Chrome เว็บสโตร์
