# ส่วนขยายห้องนิรภัย

ส่วนขยาย Vault เป็นเครื่องมือโฟกัส Manifest V3 สำหรับเบราว์เซอร์ Chromium ตัวแก้ไขปัจจุบันจัดการกลุ่มบล็อกเว็บไซต์ กลุ่มแพลตฟอร์มที่รองรับ กลุ่ม JavaScript ที่กำหนดเอง ตารางเวลา การควบคุมการหยุดและเลื่อน และลิงก์เสริมของเว็บแอปบริดจ์

ซอร์สโค้ดคือสัญญาผลิตภัณฑ์ คู่มือในแอปภาษาอังกฤษที่ [manual/en.md](manual/en.md) อธิบายการควบคุมที่จัดส่ง มันมาแทนที่คู่มือที่คัดลอกและแปลด้วยเครื่องก่อนหน้านี้

## ความสามารถในปัจจุบัน

- กลุ่มเว็บไซต์เริ่มต้นที่มีรายการบล็อกหรือรายการที่อนุญาต การเปลี่ยนเส้นทางที่เป็นตัวเลือก การบล็อกทันที การเผื่อเวลา หรือการนับถอยหลัง
- กลุ่มเฉพาะสำหรับ YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord และ Twitter / X
- ตัวกรองเฉพาะแพลตฟอร์มและตัวควบคุมองค์ประกอบซ่อนเพิ่มเติมที่โปรไฟล์แพลตฟอร์มปัจจุบันรองรับ
- กลุ่ม JavaScript แบบกำหนดเองพร้อมการตรวจสอบไวยากรณ์ เทมเพลต การควบคุมการรัน รันไทม์ที่มีการควบคุม และฟีดบันทึก
- กำหนดการต่อกลุ่ม โหมดหยุด การควบคุมการเลื่อน การนำเข้า/ส่งออก และการบันทึกอัตโนมัติ
- การเข้าถึงโฟลเดอร์ในเครื่องที่เป็นทางเลือกสำหรับการดำเนินการข้อความกฎที่กำหนดเอง, CSV และ JSON ที่รองรับ
- ตัวเลือกการเชื่อมต่อกับฮับ Vault Bridge ดั้งเดิมสำหรับกลุ่มที่เชื่อมโยงอย่างชัดเจน

## เรียกใช้ในพื้นที่

1. เปิด `chrome://extensions` ในเบราว์เซอร์ Chromium
2. เปิดใช้งาน **โหมดนักพัฒนาซอฟต์แวร์**
3. เลือก **โหลดแตกไฟล์** และเลือกโฟลเดอร์ที่เก็บข้อมูลนี้
4. เปิดส่วนขยาย Vault และสร้างกลุ่ม

ไฟล์ Manifest ต้องใช้ Chrome 116 ขึ้นไปสำหรับ API นอกหน้าจอและกฎปัจจุบัน

## การตรวจสอบการพัฒนา

เรียกใช้ชุดทดสอบส่วนขยายจากโฟลเดอร์นี้:

```bash
./tests/run.sh
```

ชุดฝึกพฤติกรรมตัวช่วย โปรไฟล์แพลตฟอร์ม การเรนเดอร์ Markdown และการตรวจสอบแค็ตตาล็อกการแปล

## คู่มือและการแปลเป็นภาษาท้องถิ่น

เอกสารภาษาอังกฤษยังคงเป็นแหล่งที่มาของ Canonical ส่วนขยายจะจัดส่งคู่มือที่แปลเป็นภาษาท้องถิ่นควบคู่ไปกับ `manual/en.md` และสำเนาเอกสารที่ได้รับการดูแลอื่นๆ ที่แปลเป็นภาษาท้องถิ่นจะอยู่ภายใต้ `i18n-docs/<locale>/`

แค็ตตาล็อก UI ใน `translation/*.json` ครบถ้วนสำหรับทุกภาษาที่รองรับ ตรวจสอบแคตตาล็อกและเอกสารเป็นภาษาท้องถิ่นด้วย:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## ขอบเขต

ส่วนขยายห้องนิรภัยจะทำงานเฉพาะในโปรไฟล์เบราว์เซอร์ที่ติดตั้งและในหน้าที่เบราว์เซอร์ให้สิทธิ์การเข้าถึงเท่านั้น จะไม่ติดตั้งแอปเนทีฟ เปลี่ยนสิทธิ์ของระบบ หรือซิงโครไนซ์กลุ่ม เว้นแต่ผู้ใช้จะเชื่อมต่อบริดจ์และลิงก์กลุ่มที่ตรงกันอย่างชัดเจน
