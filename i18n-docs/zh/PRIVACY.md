# 隐私政策 — 自定义网页拦截器

_最后更新：2026-06-30_

此页面准确解释了 **自定义 Web 阻止程序** 浏览器的数据
扩展程序收集信息、去向以及每个浏览器权限的原因
要求。简而言之：什么都不会离开你的浏览器。

## 总结

- **没有数据发送到任何服务器。** 该扩展使零网络
  向任何第三方（或我们）提出请求。它没有分析，没有
  遥测、无崩溃报告、无远程配置、无自动
  超出标准 Chrome Web Store 机制的更新。
- **所有数据都保留在您的浏览器中**，通过 Chrome 本地保存
  扩展存储（`chrome.storage.local`）。它永远不会同步，除非
  Chrome 本身会同步您的本地个人资料。
- **不会收集任何个人身份信息**
  随时延期。
- **不跟踪**超出绝对必要的浏览活动
  应用您自己配置的阻止规则。

## 本地存储的内容

该扩展程序将以下内容存储在浏览器的本地扩展程序中
存储，以便它可以跨会话完成其工作：

- 您创建的块组：名称、规则类型、列表
  阻止的站点、时间表、暂停设置、冻结状态以及任何
  您编写的自定义规则 JavaScript。
- 每组运行时状态需要强制执行限制（例如，有多少
  延迟津贴预算的会议记录今天仍然存在，当小睡时
  当严格冻结期结束时结束）。
- 在**设置**中设置您自己的偏好（滴答率、自动保存
  反跳、默认暂停持续时间、默认回退 URL、调试模式
  切换，选择的 UI 语言）。
- 应用程序内**日志**面板中显示的活动日志条目，您可以
  从 UI 中清除。

该数据只能由扩展程序自己的脚本读取和写入，仅
在您的设备上，并且仅在您自己的浏览器配置文件中。

## 不收集或传输的内容

- 浏览历史记录不会被记录、总结或传输。
- 页面内容不会被泄露、截图或记录。
- 表单输入、密码和个人信息永远不会被读取。
- 不会将有关您、您的设备或您的使用情况的信息发送至
  扩展作者或任何第三方。

## 为什么请求每个权限

|许可|它的用途是什么 |
| --- | --- |
| `storage` |仅在浏览器中保存和加载块组、设置和运行时状态。 |
| `declarativeNetRequest` |根据您配置的规则，告诉 Chrome 本机阻止哪些 URL。浏览器处理阻塞；该扩展仅注册和更新规则列表。 |
| `alarms` |当暂停、冻结或计划窗口结束时，按计划唤醒后台服务工作线程以刷新基于时间的限制并更新规则状态。 |
| `offscreen` |在屏幕外文档中运行沙盒自定义规则 JavaScript，这样它就无法逃避扩展或直接触摸您的页面。 |
| `tabs` |单击工具栏图标时，将编辑器作为完整选项卡打开，查找活动选项卡的 URL 以评估组规则，并在编辑器中进行规则更改后重新加载选项卡。 |
| `webNavigation` |检测 SPA URL 更改（推送状态导航），以便每个平台的提要隐藏器和事件驱动的规则可以对页内导航做出反应，而不仅仅是整个页面加载。 |
| `<all_urls>` 主机访问 |在您选择阻止的任何网站上应用您的阻止规则和每个平台的 Feed 隐藏器。该扩展程序仅读取/修改您已主动配置规则的 URL 上的页面，并且仅执行该规则。 |

## 自定义规则

如果您编写自定义 JavaScript 规则，则该代码：

- 在沙盒离屏文档中运行；它不能直接到达
  网络、您的页面或其他扩展。
- 仅通过固定消息桥与内容脚本通信
  由扩展的帮助程序 API 定义。
- 如果存在，则自动隔离（通过日志条目禁用）
  超出内置 CPU、日志、消息后或 DOM 突变上限。

您的自定义规则与其余设置一起存储在本地
并且永远不会从设备传输出去。

## 网站和创建者标签服务统计

本节是关于 **网站和可选的创建者标签服务**，
它们与扩展本身是分开的。分机仍然发送
如上所述，什么也没有。该网站发布了一个小**统计数据**
面板，并为了填充它，服务器保留一些聚合计数：

- **下载计数** — 每个产品的下载按钮被点击的次数
  单击（macOS、Windows、浏览器扩展、Safari）。
- **创作者分类** — 有多少 YouTube 创作者被标记。
- **帐户** — 存在多少个帐户。
- **问答活动** — 论坛帖子和评论的总数。

服务器每小时记录一次每个计数的当前值并
没有别的。没有每个事件的记录，没有点击流，也没有会话
历史。

- **完全匿名/去识别化。** 这些是简单的运行总计。他们
  **不**链接到您的姓名、帐户、电子邮件、IP 地址、设备或任何
  其他标识符——无法将计数归因于一个人。
- **绝不用于商业用途。** 该数据仅用于显示公共统计数据
  面板。 **绝不出售、与第三方共享、用于广告、
  或用于任何其他商业目的。**
- **可选的频道 ID 贡献。** 如果且仅当您选择加入，
  扩展程序/网站可能会共享 YouTube **频道 ID**（绝不是视频标题，
  观看历史记录或任何个人内容）以帮助对每个人的创作者进行分类。

## 儿童

该扩展是一个通用的生产力工具。它不是
针对儿童，不会故意收集任何人的数据，并且
不显示广告。

如果数据实践在未来版本中发生变化，该文件将
进行更新，并且更改将在版本说明中进行总结
那个释放。
