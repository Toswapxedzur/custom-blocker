# 隐私政策 — 自定义网页拦截器

_最后更新：2026-08-04_

本页确切说明 **自定义网页拦截器** 浏览器扩展会收集哪些数据、这些数据流向何处，以及为何请求每一项浏览器权限。简而言之：我们不会保存你的规则和个人浏览数据。可选的 Vault Classifier 收集与分类始终由你掌控，并使用经过身份验证的本地桥接。另有一项可选的本地 AI（MCP）集成同样默认关闭，仅向你亲自连接并批准的助手公开数据。

## 摘要

- **你的配置保留在你的浏览器中。** 拦截分组、时间表、自定义规则、日志、计时器和偏好设置仅保存在 Chrome 的本地扩展存储（`chrome.storage.local`）中。
- **Vault Classifier 仅在本地运行。** 如果你明确启用可选的 Vault Classifier 集成，YouTube 卡片/页面上的可见凭据（例如标题、可见描述、显示的标签，以及公开的创作者/视频 ID）只会通过经过身份验证的本地 Vault 桥接发送到你 Mac 上的 Vault Classifier。它们不会发送到我们的网站、模型提供商、YouTube Data API 或任何其他服务器。
- **收集是单独的选择性启用（opt-in）。** 只有在你于 Vault Classifier 的分类数据工作区中开启 YouTube 收集之后，它才会向扩展请求已渲染的、无广告的 YouTube 元数据。关闭时，扩展不会为收集发送任何标题或创作者元数据。开启时，保留的本地字段可能包括可见标题、创作者名称/标识符、视频类型、时长、可见的订阅者/观看次数/发布时间文本以及规范 URL。
- **可选的本地 AI（MCP）集成。** 如果你开启它并连接自己的 AI 助手，该助手可以——在你的明确指示下——通过你设备上的本地 Vault 服务器读取选定的数据（你的配置、活动、使用时长、活动/打开标签页的 URL、你所配置站点上的可见页面内容，以及任何 Classifier 凭据）。它默认关闭，每次连接都由你批准，密码和 API 密钥永远无法通过它读取。参见下文“可选的本地 AI（MCP）集成”。
- **没有分析、广告画像、遥测或崩溃报告。**
- **不追踪** 浏览活动，除非是应用你自己配置的拦截规则所必需的。

## 本地存储的内容

扩展会将以下内容存储在你浏览器的本地扩展存储中，以便跨会话完成其工作：

- 你创建的拦截分组：其名称、规则类型、被拦截站点列表、时间表、暂停（snooze）设置、冻结状态，以及你编写的任何自定义规则 JavaScript。
- 执行限制所需的每组运行时状态（例如，某个延迟额度预算今天还剩多少分钟、暂停何时结束、严格冻结期何时结束）。
- 你在 **设置** 中设定的偏好（刷新频率、自动保存防抖、默认暂停时长、默认回退 URL、调试模式开关、所选界面语言）。
- 应用内 **日志** 面板中显示的活动日志条目，你可以从界面中清除它们。
- 当你明确启用 Vault Classifier 时，其本地应用会保留一份由用户限定的本地缓存，其中包含分类和解释条目所需的可见凭据、本地评分、决定和更正。该缓存保留在你的 Mac 上，不属于扩展与服务器之间的常规流量。

你的配置、运行时状态和活动日志保留在你的设备上，我们的服务不会保存它们。视浏览器版本及你启用的功能而定，它们可能由扩展、其设备本地的 Safari 配套应用，或一个明确关联的本地 Vault 桥接进行处理。

## 不会收集或传输的内容

以下描述扩展自身的行为。唯一的例外是你可以自行启用并连接的可选本地 AI（MCP）集成，详见下一节。

- 浏览历史不会被扩展本身记录、汇总或传输；它仅用于应用你所配置的规则。
- 页面内容不会被扩展本身外泄、截屏或记录。
- Vault Classifier 凭据不会被扩展传出设备。仅当你明确启用该集成时，它们才由已配对的本地桥接和应用处理。
- 扩展绝不会读取表单输入和密码；密码和 API 密钥也无法通过本地 AI（MCP）集成读取。
- 常规规则执行不会传输任何扩展标识符、账户标识符、设备标识符或你的规则配置。

## 可选的本地 AI（MCP）集成

扩展可以选择性地响应来自本地 **Vault MCP 服务器** 的请求，该服务器运行在你自己设备上的 Vault 桌面应用内部，因此你可以连接自己的 AI 助手（“MCP 客户端”），让它替你读取 Vault 设置或对其执行操作。此集成 **默认关闭**，除非你有意开启，否则不会有任何改变。

- **由你发起。** 在你启用该集成并连接 MCP 客户端之前，不会公开任何内容，且每个客户端连接都由你批准。关闭它会立即撤销访问权限。
- **服务器是本地的。** 扩展提供的数据会通过同一条经过身份验证的设备内桥接，交给你 Mac 上的 Vault MCP 服务器——而非我们的网站或任何 Vault 服务器。扩展本身不会将你的数据发送给第三方。
- **随后由你的助手决定。** 一旦已连接的 MCP 客户端应你的请求收到数据，随后如何处理便取决于 **该客户端** 及其自身的隐私条款。如果你选择的助手依托远程服务，该助手可能会按你的指示传输你的数据——就像你把信息粘贴到任何 AI 工具中一样。请选择你信任的客户端。
- **可能公开的内容。** 在你的指示下，已连接的助手可以读取你的拦截分组、时间表、自定义规则、活动日志、使用时长计数器、活动标签页或已打开标签页的 URL、你所配置站点上的可见页面内容，以及任何 Vault Classifier 凭据和决定。改变状态的操作（编辑分组、开始暂停、运行已保存的规则、触发分类）会逐项确认。
- **机密始终保密。** 密码（例如家长控制密码）和提供商 API 密钥通过此集成为 **只写**：可以设置，但任何助手都无法回读。
- **仅限 Chromium。** 与 Classifier 桥接一样，此集成仅存在于具备设备本地主机的 Chromium 浏览器中；Firefox 和 Safari 不会公开它。

## 为何请求每一项权限

| 权限 | 用途 |
| --- | --- |
| `storage` | 仅在你的浏览器中保存和加载你的拦截分组、设置和运行时状态。 |
| `favicon` | 在 Chromium 中于规则旁显示浏览器缓存的站点图标。这不会发送浏览历史，也不会向我们的服务发起请求。 |
| `nativeMessaging` | 在 Chromium 中，向设备请求本地 Native Messaging 凭证以用于经过身份验证的 Vault Classifier 桥接；在 Safari 中，将自定义规则沙箱请求转发到设备本地的容器应用。这不是云端传输。 |
| `alarms` | 按计划唤醒后台 service worker，在暂停、冻结或时间表窗口结束时刷新基于时间的限制和规则状态。 |
| `offscreen` | 在屏幕外文档的沙箱中运行自定义规则 JavaScript，使其无法逃出扩展或直接触及你的页面。 |
| `tabs` | 当你点击工具栏图标时以完整标签页打开编辑器，查询活动标签页的 URL 以评估分组规则，并在你于编辑器中更改规则后重新加载标签页。 |
| `webNavigation` | 检测 SPA 的 URL 变化（push-state 导航），以便按平台的信息流隐藏器和事件驱动规则能够对页面内导航（而不仅是整页加载）作出反应。 |
| `<all_urls>` 主机访问 | 在你选择拦截的站点上应用你的拦截规则和按平台的信息流隐藏器。扩展仅在你已主动配置规则的 URL 上读取/修改页面，且仅用于执行该规则；可选的 Vault Classifier 适配器仅限于 YouTube。 |

## 自定义规则

如果你编写自定义 JavaScript 规则，该代码：

- 在屏幕外文档的沙箱中运行；它无法直接访问网络、你的页面或其他扩展。
- 仅通过扩展辅助 API 定义的固定消息桥接与内容脚本通信。
- 如果超出内置的 CPU、日志、post-message 或 DOM 变更上限，会被自动隔离（停用并附带一条日志记录）。

你的自定义规则与其余设置一起本地存储，绝不会传出设备。

## 网站统计

本节涉及 **网站**。网站会发布一个小型 **统计** 面板，为填充该面板，服务器会保留少量聚合计数：

- **下载计数** — 每个产品的下载按钮被点击的次数（macOS、Windows、浏览器扩展、Safari）。
- **账户数** — 存在多少个账户。
- **问答活动** — 论坛帖子和评论的总数。

服务器每小时记录一次每个聚合计数的当前值。这些快照不包含任何按访客的事件、点击流或会话历史。

- **完全匿名 / 去标识化。** 这些只是简单的累计总数。它们 **不会** 与你的姓名、账户、电子邮件、IP 地址、设备或任何其他标识符相关联——无法将某个计数归因于个人。
- **绝不用于商业目的。** 这些数据仅用于展示公开的统计面板。它们 **绝不会被出售、与第三方共享、用于广告或任何其他商业目的。**

## 儿童

本扩展是一款通用生产力工具。它并非面向儿童，不会有意收集任何人的数据，也不展示广告。
