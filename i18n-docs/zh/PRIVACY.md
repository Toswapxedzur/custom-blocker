# 隐私政策 — 自定义网页拦截器

_最后更新：2026-07-13_

此页面准确解释了 **自定义 Web 阻止程序** 浏览器的数据
扩展程序收集信息、去向以及每个浏览器权限的原因
要求。简而言之：我们不会保存您的规则或个人浏览数据。标签规则可能会查询
公开的 YouTube 频道 ID，但这些查询不会被保留，也不会与您关联。

## 总结

- **配置保留在浏览器中。** 分组、计划、规则、日志、计时器和偏好设置只保存在
  `chrome.storage.local` 中。
- **标签查询只包含公开频道 ID。** 不会发送网址、视频标题、搜索词、时间、
  帐户或扩展设置。
- **查询不会被保存。** 接口为只读，不会把未知频道写入数据库，也不会把请求
  与任何个人关联。
- **没有分析、遥测、广告或崩溃报告。**
- **不跟踪**超出绝对必要的浏览活动
  应用您自己配置的阻止规则。

## 本地存储的内容

该扩展程序将以下内容存储在浏览器的本地扩展程序中
存储，以便它可以跨会话完成其工作：

- 您创建的块组：名称、规则类型、列表
  阻止的站点、时间表、暂停设置、冻结状态以及任何
  您编写的自定义规则 JavaScript。
- 每组运行时状态需要强制执行限制（例如，有多少
  延迟津贴预算的会议记录今天仍然存在，当小睡时
  当严格冻结期结束时结束）。
- 在**设置**中设置您自己的偏好（滴答率、自动保存
  反跳、默认暂停持续时间、默认回退 URL、调试模式
  切换，选择的 UI 语言）。
- 应用程序内**日志**面板中显示的活动日志条目，您可以
  从 UI 中清除。

该数据只能由扩展程序自己的脚本读取和写入，仅
在您的设备上，并且仅在您自己的浏览器配置文件中。

## 不收集或传输的内容

- 浏览历史记录不会被记录、总结或传输。
- 页面内容不会被泄露、截图或记录。
- 表单输入、密码和个人信息永远不会被读取。
- 不会将有关您、您的设备或您的使用情况的信息发送至
  扩展作者或任何第三方。

## 为什么请求每个权限

|许可|它的用途是什么 |
| --- | --- |
| `storage` |仅在浏览器中保存和加载块组、设置和运行时状态。 |
| `favicon` | 在 Chromium 中显示浏览器已缓存的网站图标。此操作不会发送浏览历史记录，也不会请求我们的服务。 |
| `nativeMessaging` | 在 Chromium 中，为经过认证的 Vault Classifier 桥接请求设备本地 Native Messaging 证明；在 Safari 中，将自定义规则的沙盒请求转发给设备上的本地配套应用。这不是云端传输。 |
| `alarms` |当暂停、冻结或计划窗口结束时，按计划唤醒后台服务工作线程以刷新基于时间的限制并更新规则状态。 |
| `offscreen` |在屏幕外文档中运行沙盒自定义规则 JavaScript，这样它就无法逃避扩展或直接触摸您的页面。 |
| `tabs` |单击工具栏图标时，将编辑器作为完整选项卡打开，查找活动选项卡的 URL 以评估组规则，并在编辑器中进行规则更改后重新加载选项卡。 |
| `webNavigation` |检测 SPA URL 更改（推送状态导航），以便每个平台的提要隐藏器和事件驱动的规则可以对页内导航做出反应，而不仅仅是整个页面加载。 |
| `<all_urls>` 主机访问 |在您选择阻止的任何网站上应用您的阻止规则和每个平台的 Feed 隐藏器。该扩展程序仅读取/修改您已主动配置规则的 URL 上的页面，并且仅执行该规则。 |

## 自定义规则

如果您编写自定义 JavaScript 规则，则该代码：

- 在沙盒离屏文档中运行；它不能直接到达
  网络、您的页面或其他扩展。
- 仅通过固定消息桥与内容脚本通信
  由扩展的帮助程序 API 定义。
- 如果存在，则自动隔离（通过日志条目禁用）
  超出内置 CPU、日志、消息后或 DOM 突变上限。

您的自定义规则与其余设置一起存储在本地
并且永远不会从设备传输出去。

## 网站和创建者标签服务统计

本节介绍 **网站和创作者标签服务**。扩展可以只读查询公开频道 ID，
但这些查询不会被保存。网站的**统计数据**只保留无法关联到个人的汇总计数：

- **下载计数** — 每个产品的下载按钮被点击的次数
  单击（macOS、Windows、浏览器扩展、Safari）。
- **创作者分类** — 有多少 YouTube 创作者被标记。
- **帐户** — 存在多少个帐户。
- **问答活动** — 论坛帖子和评论的总数。

服务器每小时记录一次每个计数的当前值并
没有别的。没有每个事件的记录，没有点击流，也没有会话
历史。

- **完全匿名/去识别化。** 这些是简单的运行总计。他们
  **不**链接到您的姓名、帐户、电子邮件、IP 地址、设备或任何
  其他标识符——无法将计数归因于一个人。
- **绝不用于商业用途。** 该数据仅用于显示公共统计数据
  面板。 **绝不出售、与第三方共享、用于广告、
  或用于任何其他商业目的。**
- **可选的频道 ID 贡献。** 如果且仅当您选择加入，
  扩展程序/网站可能会共享 YouTube **频道 ID**（绝不是视频标题，
  观看历史记录或任何个人内容）以帮助对每个人的创作者进行分类。
- **手动贡献。** 登录用户主动提交时，电子邮件与频道 ID 的对应关系只在
  24 小时滚动限额所需的期限内保留，并由每小时清理任务删除。
- **公开队列。** 可以显示公开 ID 和处理状态，但不会显示提交时间或提交者。

## 儿童

该扩展是一个通用的生产力工具。它不是
针对儿童，不会故意收集任何人的数据，并且
不显示广告。
