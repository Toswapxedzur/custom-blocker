# 条款和使用 — 自定义网页拦截器

_最后更新：2026-06-27_

扩展、macOS / iOS 应用程序和网站。通过安装或使用任何
作为该项目的一部分，您同意以下内容。简短版本：它是免费的，
它是开源的，可以自由使用，并且没有任何保证。

## 该产品是免费的

- 每个功能都可以免费使用。无需购买、订阅或付费
  等级——现在或以后。
- 该项目获得资金的唯一方式是自愿的、可选的
  捐赠。没有任何东西被关在后面。

## 您的数据

- 默认情况下，您的浏览不会离开您的设备。
- 我们绝不会与第三方分享您的数据或从中获利
  它。有关完整详细信息，请参阅隐私政策。
- 唯一可选的例外是频道 ID 分类选择加入，它
  共享匿名频道 ID（绝不是标题或观看历史记录）以帮助标记
  为所有人创造的创作者。除非您将其打开，否则它会关闭。

## 账户

- 帐户是**可选**。每个下载和每个阻止功能都有效
  完全无需登录。
- 帐户仅添加可选的跨设备同步和显示名称。
- 您有责任保证您的密码安全。你可以改变你的
  显示名称或**永久删除您的帐户**随时从
  帐户面板；删除会删除您的帐户、会话和待处理代码。

- 请勿使用它来伤害他人、规避不属于您的安全或侵犯
  您访问的网站和平台的条款。
