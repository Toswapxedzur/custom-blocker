# ভল্ট এক্সটেনশন

ভল্ট এক্সটেনশন হল Chromium ব্রাউজারগুলির জন্য একটি ম্যানিফেস্ট V3 ফোকাস টুল। এর বর্তমান সম্পাদক ওয়েবসাইট ব্লক গ্রুপ, সমর্থিত-প্ল্যাটফর্ম গ্রুপ, কাস্টম জাভাস্ক্রিপ্ট গ্রুপ, সময়সূচী, ফ্রিজ এবং স্নুজ নিয়ন্ত্রণ এবং ঐচ্ছিক ওয়েব-অ্যাপ ব্রিজ লিঙ্ক পরিচালনা করে।

উৎস কোড পণ্য চুক্তি. [manual/en.md](manual/en.md) এ ইংলিশ ইন-অ্যাপ ম্যানুয়াল পাঠানো নিয়ন্ত্রণগুলি ব্যাখ্যা করে; এটি পূর্ববর্তী অনুলিপি করা এবং মেশিন-অনুবাদিত ম্যানুয়ালগুলিকে প্রতিস্থাপন করে।

## বর্তমান ক্ষমতা

- ব্লকলিস্ট বা অ্যালাউলিস্ট আচরণ, ঐচ্ছিক পুনঃনির্দেশ, অবিলম্বে ব্লক করা, সময় ভাতা বা কাউন্টডাউন সহ ডিফল্ট ওয়েবসাইট গ্রুপ।
- YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord, এবং Twitter/X-এর জন্য ডেডিকেটেড গ্রুপ।
- প্ল্যাটফর্ম-নির্দিষ্ট ফিল্টার এবং ঐচ্ছিক হাইড-এলিমেন্ট নিয়ন্ত্রণ যেখানে বর্তমান প্ল্যাটফর্ম প্রোফাইল তাদের সমর্থন করে।
- সিনট্যাক্স চেকিং, টেমপ্লেট, রান কন্ট্রোল, একটি নিয়ন্ত্রিত রানটাইম এবং একটি লগ ফিড সহ কাস্টম জাভাস্ক্রিপ্ট গ্রুপ।
- প্রতি-গ্রুপ সময়সূচী, ফ্রিজ মোড, স্নুজ নিয়ন্ত্রণ, আমদানি/রপ্তানি, এবং স্বয়ংক্রিয় সংরক্ষণ।
- সমর্থিত কাস্টম-রুল টেক্সট, CSV, এবং JSON অপারেশনের জন্য ঐচ্ছিক স্থানীয়-ফোল্ডার অ্যাক্সেস।
- স্পষ্টভাবে লিঙ্ক করা গোষ্ঠীগুলির জন্য একটি নেটিভ ভল্ট ব্রিজ হাবের ঐচ্ছিক সংযোগ৷

## স্থানীয়ভাবে চালান

1. একটি Chromium ব্রাউজারে `chrome://extensions` খুলুন৷
2. **ডেভেলপার মোড** সক্ষম করুন।
3. **লোড আনপ্যাক** নির্বাচন করুন এবং এই সংগ্রহস্থল ফোল্ডারটি চয়ন করুন৷
4. ভল্ট এক্সটেনশন খুলুন এবং একটি গ্রুপ তৈরি করুন।

ম্যানিফেস্টের বর্তমান অফস্ক্রিন এবং নিয়ম API-এর জন্য Chrome 116 বা তার পরবর্তী সংস্করণ প্রয়োজন৷

## উন্নয়ন চেক

এই ফোল্ডার থেকে এক্সটেনশন টেস্ট স্যুট চালান:

```bash
./tests/run.sh
```

স্যুট সাহায্যকারী আচরণ, প্ল্যাটফর্ম প্রোফাইল, মার্কডাউন রেন্ডারিং, এবং অনুবাদ ক্যাটালগ অডিট অনুশীলন করে।

## স্থানীয় ম্যানুয়াল এবং অনুবাদ

ইংরেজি নথিগুলি প্রামাণিক উত্স হিসাবে রয়ে গেছে। এক্সটেনশনটি তার স্থানীয় ম্যানুয়ালগুলি `manual/en.md` এর পাশে পাঠায়, এবং অন্যান্য রক্ষণাবেক্ষণ করা নথিগুলির স্থানীয়কৃত অনুলিপিগুলি `i18n-docs/<locale>/` এর অধীনে থাকে।

`translation/*.json`-এ UI ক্যাটালগগুলি প্রতিটি সমর্থিত লোকেলের জন্য সম্পূর্ণ। এর সাথে ক্যাটালগ এবং স্থানীয়কৃত নথি যাচাই করুন:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## সুযোগ

ভল্ট এক্সটেনশন শুধুমাত্র ব্রাউজার প্রোফাইলে কাজ করে যেখানে এটি ইনস্টল করা আছে এবং পৃষ্ঠাগুলিতে ব্রাউজার এটি অ্যাক্সেস দেয়। এটি নেটিভ অ্যাপস ইনস্টল করে না, সিস্টেমের অনুমতি পরিবর্তন করে না বা গোষ্ঠীগুলিকে সিঙ্ক্রোনাইজ করে না যদি না ব্যবহারকারী স্পষ্টভাবে একটি সেতু সংযোগ করে এবং মিলিত গ্রুপগুলিকে লিঙ্ক করে।
