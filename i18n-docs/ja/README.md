# ボールト拡張機能

Vault 拡張機能は、Chromium ブラウザ用の Manifest V3 フォーカス ツールです。現在のエディターは、Web サイト ブロック グループ、サポートされているプラ​​ットフォーム グループ、カスタム JavaScript グループ、スケジュール、フリーズおよびスヌーズ コントロール、およびオプションの Web アプリ ブリッジ リンクを管理します。

ソース コードは製品契約です。 [manual/en.md](manual/en.md) にある英語のアプリ内マニュアルでは、同梱のコントロールについて説明しています。これは、以前にコピーされ機械翻訳されたマニュアルに代わるものです。

## 現在の機能

- ブロックリストまたは許可リストの動作、オプションのリダイレクト、即時ブロック、時間制限、またはカウントダウンを備えたデフォルトの Web サイト グループ。
- YouTube、TikTok、Facebook、Instagram、Twitch、Reddit、Discord、Twitter / X の専用グループ。
- プラットフォーム固有のフィルターとオプションの非表示要素コントロール (現在のプラットフォーム プロファイルがサポートしている場合)。
- 構文チェック、テンプレート、実行コントロール、制御されたランタイム、およびログ フィードを備えたカスタム JavaScript グループ。
- グループごとのスケジュール、フリーズモード、スヌーズコントロール、インポート/エクスポート、自動保存。
- サポートされているカスタム ルール テキスト、CSV、および JSON 操作のためのオプションのローカル フォルダー アクセス。
- 明示的にリンクされたグループのネイティブ Vault ブリッジ ハブへのオプションの接続。

## ローカルで実行

1. Chromium ブラウザで `chrome://extensions` を開きます。
2. **開発者モード**を有効にします。
3. [**解凍してロード**] を選択し、このリポジトリ フォルダーを選択します。
4. Vault 拡張機能を開き、グループを作成します。

マニフェストでは、現在のオフスクリーン API とルール API を使用するには Chrome 116 以降が必要です。

## 開発チェック

このフォルダーから拡張テスト スイートを実行します。

```bash
./tests/run.sh
```

このスイートは、ヘルパー動作、プラットフォーム プロファイル、マークダウン レンダリング、および翻訳カタログ監査を実行します。

## ローカライズされたマニュアルと翻訳

英語の文書が引き続き正規の情報源となります。この拡張機能では、ローカライズされたマニュアルが `manual/en.md` の横に同梱されており、他の保守ドキュメントのローカライズされたコピーは `i18n-docs/<locale>/` の下にあります。

`translation/*.json` の UI カタログは、サポートされているすべてのロケールに対応しています。次の方法でカタログとローカライズされたドキュメントを確認します。

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## 範囲

Vault 拡張機能は、それがインストールされているブラウザ プロファイルと、ブラウザがアクセスを許可したページでのみ機能します。ユーザーが明示的にブリッジに接続し、一致するグループをリンクしない限り、ネイティブ アプリのインストール、システム権限の変更、グループの同期は行われません。
