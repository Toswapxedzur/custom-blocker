# プライバシー ポリシー — カスタム Web ブロッカー

_最終更新日: 2026-07-13_

このページでは、**カスタム Web ブロッカー** ブラウザーがどのようなデータを使用するのかを正確に説明します。
拡張機能が収集され、どこに送信されるか、各ブラウザーのアクセス許可が制限される理由
要求される理由を説明します。要点は、ルールや個人の閲覧データを当社が
保存することはない、ということです。タグルールは公開 YouTube チャンネル ID
を照会する場合がありますが、その照会は保存されず、利用者にも関連付けられません。

## 概要

- **設定はブラウザ内に残ります。** グループ、スケジュール、ルール、ログ、
  タイマー、設定は `chrome.storage.local` にのみ保存されます。
- **タグ照会には公開チャンネル ID だけが含まれます。** URL、動画名、
  検索語、時刻、アカウント、拡張機能の設定は送信しません。
- **照会は保存されません。** 読み取り専用で、未知のチャンネルを登録せず、
  リクエストを個人に関連付けません。
- **解析、テレメトリ、広告、クラッシュ報告はありません。**
- **絶対に必要な範囲を超えた閲覧アクティビティの追跡は禁止**
  自分で設定したブロック ルールを適用します。

## ローカルに保存されるもの

この拡張機能は、ブラウザのローカル拡張機能に次のものを保存します。
セッションをまたいで仕事をできるようにストレージを確保します。

- 作成するブロック グループ: 名前、ルール タイプ、ルールのリスト
  ブロックされたサイト、スケジュール、スヌーズ設定、フリーズ状態など
  カスタムルール JavaScript を作成します。
- 制限を適用するために必要なグループごとのランタイム状態 (例: いくつ
  今日は、遅延許容予算が数分残っており、居眠りをしたとき
  完全凍結期間が終了すると終了します)。
- **設定**で設定した独自の設定 (ティックレート、自動保存)
  デバウンス、デフォルトのスヌーズ期間、デフォルトのフォールバック URL、デバッグモード
  トグル、選択した UI 言語)。
- アプリ内の **ログ** パネルに表示されるアクティビティ ログ エントリ。
  UIからクリアされます。

このデータは、拡張機能独自のスクリプトによってのみ読み書きされます。
あなたのデバイス上で、あなた自身のブラウザプロファイル内でのみ。

## 収集または送信されないもの

- 閲覧履歴は記録、要約、送信されません。
- ページのコンテンツは漏洩、スクリーンショット、または記録されません。
- フォーム入力、パスワード、個人情報が読み取られることはありません。
- あなた、あなたのデバイス、またはあなたの使用状況に関する情報は、
  拡張機能の作成者または第三者。

## 各権限が要求される理由

|許可 |用途 |
| --- | --- |
| `storage` |ブロック グループ、設定、実行時状態の保存と読み込みはブラウザーのみで行います。 |
| `favicon` | Chromium で、ブラウザにキャッシュ済みのサイトアイコンをルールの横に表示します。閲覧履歴の送信や当社サービスへのリクエストは行いません。 |
| `nativeMessaging` | Chromium では、認証された Vault Classifier ブリッジ用に端末内の Native Messaging 証明を要求します。Safari では、カスタムルールのサンドボックス要求を端末内のコンパニオンアプリへ転送します。クラウド通信ではありません。 |
| `alarms` |スヌーズ、フリーズ、またはスケジュールのウィンドウが終了したときに、スケジュールに従ってバックグラウンド サービス ワーカーを起動して、時間ベースの制限を更新し、ルールの状態を更新します。 |
| `offscreen` |サンドボックス化されたカスタム ルール JavaScript をオフスクリーン ドキュメントで実行すると、拡張機能をエスケープしたり、ページに直接アクセスしたりすることができなくなります。 |
| `tabs` |ツールバー アイコンをクリックするとエディターを完全なタブとして開き、アクティブなタブの URL を検索してグループ ルールを評価し、エディターでルールを変更した後にタブをリロードします。 |
| `webNavigation` | SPA URL の変更 (プッシュ状態ナビゲーション) を検出することで、プラットフォームごとのフィード非表示機能とイベント駆動ルールがページ全体の読み込みだけでなくページ内ナビゲーションに反応できるようになります。 |
| `<all_urls>` ホスト アクセス |ブロックすることを選択したサイトに、ブロック ルールとプラットフォームごとのフィード非表示機能を適用します。この拡張機能は、ルールをアクティブに構成した URL のページのみを読み取り/変更し、そのルールを適用するためだけに使用します。 |

## カスタムルール

カスタム JavaScript ルールを作成する場合、そのコードは次のようになります。

- サンドボックス化されたオフスクリーン ドキュメントで実行されます。直接到達することはできません
  ネットワーク、ページ、またはその他の拡張機能。
- 固定メッセージ ブリッジを介してのみコンテンツ スクリプトと通信します。
  拡張機能のヘルパー API によって定義されます。
- 次の場合は自動的に隔離されます (ログ エントリで無効になります)。
  組み込みの CPU、ログ、ポストメッセージ、または DOM ミューテーションの上限を超えています。

カスタム ルールは、残りの設定とともにローカルに保存されます
デバイスから送信されることはありません。

## ウェブサイトとクリエイタータグサービスの統計

このセクションは **Web サイトとクリエイタータグサービス**に関するものです。
拡張機能は公開チャンネル ID を読み取り専用で照会できますが、その照会は
保存されません。Web サイトの **統計** には個人と結び付かない集計値だけを保持します。

- **ダウンロード数** — 各製品のダウンロード ボタンが押された回数
  クリックされました (macOS、Windows、ブラウザ拡張機能、Safari)。
- **クリエイターの分類** — タグ付けされた YouTube クリエイターの数。
- **アカウント** — 存在するアカウントの数。
- **Q&A アクティビティ** — フォーラムの投稿とコメントの合計数。

サーバーは 1 時間に 1 回、これらの各カウントの現在値を記録し、
他には何もありません。イベントごとのレコード、クリックストリーム、セッションはありません。
歴史。

- **完全に匿名/匿名化されています。** これらは単純な累計です。彼らは
  あなたの名前、アカウント、電子メール、IP アドレス、デバイスなどにリンクされていません**
  他の識別子 — カウントを個人に帰す方法はありません。
- **決して営利目的ではありません。** このデータは、公開統計を示すためにのみ存在します。
  パネル。 **決して販売したり、第三者と共有したり、広告に使用したりすることはありません。
  またはその他の商業目的で使用されます。**
- **オプションのチャネル ID 貢献。** オプトインした場合に限り、
  拡張機能/ウェブサイトは YouTube **チャンネル ID** を共有する場合があります (動画タイトルは使用しないでください)。
  視聴履歴や個人的なものなど）すべてのクリエイターを分類するのに役立ちます。
