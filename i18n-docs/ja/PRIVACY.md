# プライバシー ポリシー — カスタム Web ブロッカー

_最終更新日: 2026-08-04_

このページでは、**カスタム Web ブロッカー** ブラウザー拡張機能が収集するデータの内容、その送信先、および各ブラウザー権限を要求する理由を正確に説明します。要点は次のとおりです。当社はあなたのルールや個人的な閲覧データを保存しません。任意の Vault Classifier の収集と分類は引き続きあなたの管理下にあり、認証済みのローカル ブリッジを使用します。別個の任意のローカル AI（MCP）連携も既定では無効であり、あなた自身が接続して承認したアシスタントにのみデータを開示します。

## 概要

- **設定はブラウザー内にとどまります。** ブロック グループ、スケジュール、カスタム ルール、ログ、タイマー、環境設定は、Chrome のローカル拡張機能ストレージ（`chrome.storage.local`）にのみ保存されます。
- **Vault Classifier はローカル専用です。** 任意の Vault Classifier 連携を明示的に有効にした場合、YouTube のカード/ページ上の可視的な証跡（タイトル、表示中の説明、表示中のタグ、公開されているクリエイター/動画 ID など）は、認証済みのローカル Vault ブリッジ経由で、あなたの Mac 上の Vault Classifier にのみ送られます。当社のウェブサイト、モデル プロバイダー、YouTube Data API、その他いかなるサーバーにも送信されません。
- **収集は別個のオプトインです。** Vault Classifier は、その分類データ ワークスペースで YouTube の収集を有効にした後にのみ、レンダリング済みで広告を含まない YouTube のメタデータを拡張機能に要求します。無効のときは、拡張機能は収集のためのタイトルやクリエイター メタデータを一切送信しません。有効のときに保持されるローカル フィールドには、可視的なタイトル、クリエイター名/識別子、動画の種類、長さ、可視的な登録者数/再生回数/公開日時のテキスト、正規 URL が含まれ得ます。
- **任意のローカル AI（MCP）連携。** これを有効にして自分の AI アシスタントを接続すると、そのアシスタントは——あなたの明示的な指示のもとで——あなたのデバイス上のローカル Vault サーバーを介して、選択されたデータ（設定、アクティビティ、使用時間、アクティブ/開いているタブの URL、あなたが設定したサイト上の可視的なページ内容、任意の Classifier 証跡）を読み取れます。既定では無効で、接続ごとにあなたが承認し、パスワードや API キーはこれを通じて決して読み取れません。下記「任意のローカル AI（MCP）連携」を参照してください。
- **分析、広告プロファイル、テレメトリ、クラッシュ レポートはありません。**
- 自分で設定したブロック ルールの適用に厳密に必要な範囲を超えて、閲覧アクティビティを **追跡することはありません。**

## ローカルに保存される内容

拡張機能はセッションをまたいで機能できるよう、次の内容をブラウザーのローカル拡張機能ストレージに保存します。

- 作成したブロック グループ：その名前、ルールの種類、ブロック対象サイトのリスト、スケジュール、スヌーズ設定、フリーズ状態、およびあなたが記述した任意のカスタム ルール JavaScript。
- 制限を適用するために必要なグループごとのランタイム状態（例：繰り延べ許可の予算のうち今日あと何分残っているか、スヌーズがいつ終了するか、厳格フリーズ期間がいつ終了するか）。
- **設定** で指定した自分の環境設定（ティック レート、自動保存のデバウンス、既定のスヌーズ時間、既定のフォールバック URL、デバッグ モードの切り替え、選択した UI 言語）。
- アプリ内の **ログ** パネルに表示されるアクティビティ ログのエントリ。UI から消去できます。
- Vault Classifier を明示的に有効にすると、そのローカル アプリは、エントリの分類と説明に必要な可視的な証跡、ローカル スコア、判定、修正について、ユーザーによって上限が定められたローカル キャッシュを保持します。このキャッシュはあなたの Mac 上に残り、拡張機能とサーバー間の通常の通信には含まれません。

あなたの設定、ランタイム状態、アクティビティ ログはデバイス上にとどまり、当社のサービスには保存されません。ブラウザーのビルドと有効にした機能に応じて、それらは拡張機能、そのデバイス ローカルの Safari コンパニオン アプリ、または明示的にリンクされたローカル Vault ブリッジによって処理される場合があります。

## 収集も送信もされない内容

以下は拡張機能それ自体の動作を説明したものです。唯一の例外は、あなた自身が有効化して接続できる任意のローカル AI（MCP）連携であり、次のセクションで説明します。

- 閲覧履歴は拡張機能自体によって記録・要約・送信されることはありません。あなたが設定したルールの適用にのみ使用されます。
- ページ内容は拡張機能自体によって持ち出し・スクリーンショット取得・ログ記録されることはありません。
- Vault Classifier の証跡は拡張機能によってデバイス外へ送信されません。それらは、あなたがこの連携を明示的に有効にした場合にのみ、ペアリングされたローカル ブリッジとアプリによって処理されます。
- フォーム入力とパスワードは拡張機能によって決して読み取られません。パスワードと API キーは、ローカル AI（MCP）連携を通じても読み取れません。
- 通常のルール適用のために、拡張機能識別子、アカウント識別子、デバイス識別子、あなたのルール設定が送信されることはありません。

## 任意のローカル AI（MCP）連携

拡張機能は、あなた自身のデバイス上の Vault デスクトップ アプリ内で動作するローカルの **Vault MCP サーバー** からのリクエストに、任意で応答できます。これにより、自分の AI アシスタント（「MCP クライアント」）を接続し、あなたに代わって Vault の設定を読み取ったり操作したりさせることができます。この連携は **既定で無効** であり、意図的に有効化しない限り何も変わりません。

- **開始するのはあなたです。** 連携を有効にして MCP クライアントを接続するまで、何も開示されません。クライアントの接続はそれぞれあなたが承認します。無効にすると直ちにアクセスが取り消されます。
- **サーバーはローカルです。** 拡張機能が提供するデータは、同じ認証済みのデバイス内ブリッジを介して、あなたの Mac 上の Vault MCP サーバーに渡されます——当社のウェブサイトや Vault サーバーには渡されません。拡張機能自体があなたのデータを第三者に送信することはありません。
- **その後はあなたのアシスタントが判断します。** 接続された MCP クライアントがあなたの要求に応じてデータを受け取った後、それがどう扱われるかは **そのクライアント** とその独自のプライバシー条項によって定まります。選択したアシスタントがリモート サービスに依拠している場合、そのアシスタントはあなたの指示のもとであなたのデータを送信することがあります——任意の AI ツールに情報を貼り付けるのと同じです。信頼できるクライアントを選んでください。
- **開示され得る内容。** あなたの指示のもとで、接続されたアシスタントは、ブロック グループ、スケジュール、カスタム ルール、アクティビティ ログ、使用時間カウンター、アクティブなタブまたは開いているタブの URL、あなたが設定したサイト上の可視的なページ内容、任意の Vault Classifier の証跡と判定を読み取れます。状態を変更する操作（グループの編集、スヌーズの開始、保存済みルールの実行、分類のトリガー）は個別に確認されます。
- **秘密は秘密のままです。** パスワード（保護者による使用制限のパスワードなど）とプロバイダーの API キーは、この連携を通じて **書き込み専用** です。設定はできますが、どのアシスタントも読み返すことはできません。
- **Chromium のみ。** Classifier ブリッジと同様に、この連携はデバイス ローカルのホストを備えた Chromium ブラウザーにのみ存在します。Firefox と Safari では公開されません。

## 各権限を要求する理由

| 権限 | 用途 |
| --- | --- |
| `storage` | ブロック グループ、設定、ランタイム状態をあなたのブラウザー内にのみ保存・読み込みします。 |
| `favicon` | Chromium でルールの横に、ブラウザーがキャッシュしたサイト アイコンを表示します。これは閲覧履歴を送信せず、当社のサービスへのリクエストも行いません。 |
| `nativeMessaging` | Chromium では、認証済みの Vault Classifier ブリッジのためにデバイス ローカルの Native Messaging 証明をデバイスに要求します。Safari では、カスタム ルールのサンドボックス要求をデバイス ローカルのコンテナ アプリに転送します。クラウド トランスポートではありません。 |
| `alarms` | スヌーズ、フリーズ、またはスケジュールのウィンドウが終了したときに、時間ベースの制限とルール状態を更新するため、バックグラウンドの service worker をスケジュールどおりに起動します。 |
| `offscreen` | カスタム ルールの JavaScript を画面外ドキュメント内のサンドボックスで実行し、拡張機能から抜け出したりあなたのページに直接触れたりできないようにします。 |
| `tabs` | ツールバー アイコンをクリックしたときにエディターを全画面タブとして開き、グループ ルールを評価するためにアクティブなタブの URL を参照し、エディターで行ったルール変更の後にタブを再読み込みします。 |
| `webNavigation` | SPA の URL 変更（push-state ナビゲーション）を検出し、プラットフォーム別のフィード非表示機能やイベント駆動のルールが、全ページの読み込みだけでなくページ内ナビゲーションにも反応できるようにします。 |
| `<all_urls>` ホスト アクセス | ブロックすることを選んだサイトで、ブロック ルールとプラットフォーム別のフィード非表示機能を適用します。拡張機能は、あなたが実際にルールを設定した URL でのみ、かつそのルールを適用するためだけにページを読み取り/変更します。任意の Vault Classifier アダプターは YouTube に限定されます。 |

## カスタム ルール

カスタム JavaScript ルールを記述した場合、そのコードは次のとおりです。

- 画面外ドキュメントのサンドボックスで実行され、ネットワーク、あなたのページ、他の拡張機能に直接到達することはできません。
- 拡張機能のヘルパー API によって定義された固定のメッセージ ブリッジを通じてのみ、コンテンツ スクリプトと通信します。
- 組み込みの CPU、ログ、post-message、または DOM 変更の上限を超えると、自動的に隔離されます（ログ エントリとともに無効化）。

あなたのカスタム ルールは、他の設定とともにローカルに保存され、デバイス外に送信されることは決してありません。

## ウェブサイトの統計

このセクションは **ウェブサイト** に関するものです。ウェブサイトは小さな **統計** パネルを公開しており、それを埋めるためにサーバーはいくつかの集計カウントを保持します。

- **ダウンロード数** — 各製品のダウンロード ボタンがクリックされた回数（macOS、Windows、ブラウザー拡張機能、Safari）。
- **アカウント数** — アカウントがいくつ存在するか。
- **Q&A アクティビティ** — フォーラムの投稿とコメントの総数。

サーバーは 1 時間に 1 回、各集計カウントの現在値を記録します。これらのスナップショットには、訪問者ごとのイベント、クリックストリーム、セッション履歴は一切含まれません。

- **完全に匿名 / 非識別化。** これらは単純な累積合計です。あなたの氏名、アカウント、メール、IP アドレス、デバイス、その他いかなる識別子とも **関連付けられません**——カウントを個人にひも付ける方法はありません。
- **決して商用ではありません。** このデータは公開の統計パネルを表示するためだけに存在します。**決して販売、第三者との共有、広告目的、その他いかなる商用目的にも使用されません。**

## 子ども

本拡張機能は汎用の生産性ツールです。子どもを対象としておらず、誰からも意図的にデータを収集せず、広告も表示しません。
