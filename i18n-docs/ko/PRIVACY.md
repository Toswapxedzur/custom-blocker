# 개인 정보 보호 정책 — 맞춤형 웹 차단기

_최종 업데이트 날짜: 2026-06-30_

이 페이지에서는 **Custom Web Blocker** 브라우저가 어떤 데이터를 사용하는지 정확하게 설명합니다.
확장 프로그램이 수집하는 위치, 각 브라우저 권한이 부여되는 이유
요청했습니다. 짧은 버전은 다음과 같습니다. 브라우저에는 아무것도 남지 않습니다.

## 요약

- **어떤 서버에도 데이터가 전송되지 않습니다.** 확장 프로그램은 네트워크를 0으로 만듭니다.
  제3자(또는 당사)에 대한 요청. 분석이 없습니다.
  원격 측정, 충돌 보고 없음, 원격 구성 없음, 자동 없음
  표준 Chrome 웹 스토어 메커니즘 이상의 업데이트.
- **모든 데이터는 브라우저에 유지되며** Chrome의 로컬을 통해 유지됩니다.
  확장 스토리지(`chrome.storage.local`). 다음을 제외하면 동기화되지 않습니다.
  Chrome 자체는 로컬 프로필을 동기화합니다.
- **개인 식별 정보는 수집되지 않습니다**
  언제든지 연장.
- 꼭 필요한 것 이상으로 브라우징 활동을 **추적하지 않습니다**
  자신이 구성한 차단 규칙을 적용하려면

## 로컬에 저장되는 내용

확장 프로그램은 브라우저의 로컬 확장 프로그램에 다음을 저장합니다.
세션 전반에 걸쳐 작업을 수행할 수 있도록 저장합니다.

- 귀하가 생성한 블록 그룹: 이름, 규칙 유형, 목록
  차단된 사이트, 일정, 다시 알림 설정, 정지 상태 등
  사용자가 작성하는 사용자 정의 규칙 JavaScript.
- 제한을 적용하는 데 필요한 그룹별 런타임 상태(예:
  오늘 지연된 수당 예산이 몇 분 남습니다.
  엄격한 동결 기간이 끝나면 종료됩니다).
- **설정**에서 원하는 대로 설정하세요(틱율, 자동 저장).
  디바운스, 기본 다시 알림 기간, 기본 대체 URL, 디버그 모드
  토글, 선택한 UI 언어).
- 인앱 **로그** 패널에 표시되는 활동 로그 항목
  UI에서 지웁니다.

이 데이터는 확장 프로그램의 자체 스크립트에 의해서만 읽고 쓰여집니다.
귀하의 기기에서만, 귀하의 브라우저 프로필 내에서만 가능합니다.

## 수집 또는 전송되지 않는 사항

- 검색 기록은 기록, 요약, 전송되지 않습니다.
- 페이지 콘텐츠는 유출되거나, 스크린샷으로 찍히거나, 기록되지 않습니다.
- 양식 입력, 비밀번호, 개인정보는 절대 읽지 않습니다.
- 귀하, 귀하의 장치 또는 귀하의 사용에 관한 정보는 다음으로 전송되지 않습니다.
  확장 작성자 또는 제3자.

## 각 권한이 요청되는 이유

| 허가 | 용도 |
| --- | --- |
| `storage` | 브라우저에서만 블록 그룹, 설정 및 런타임 상태를 저장하고 로드하세요. |
| `declarativeNetRequest` | 구성한 규칙에 따라 기본적으로 차단할 URL을 Chrome에 알려줍니다. 브라우저가 차단을 처리합니다. 확장 프로그램은 규칙 목록만 등록하고 업데이트합니다. |
| `alarms` | 일정에 따라 백그라운드 서비스 작업자를 깨워 시간 기반 제한을 새로 고치고 다시 알림, 정지 또는 일정 기간이 끝나면 규칙 상태를 업데이트합니다. |
| `offscreen` | 확장 프로그램을 벗어나거나 페이지를 직접 터치할 수 없도록 오프스크린 문서에서 샌드박스 사용자 정의 규칙 JavaScript를 실행하세요. |
| `tabs` | 도구 모음 아이콘을 클릭하여 편집기를 전체 탭으로 열고, 활성 탭의 URL을 찾아 그룹 규칙을 평가하고, 편집기에서 규칙을 변경한 후 탭을 다시 로드하세요. |
| `webNavigation` | SPA URL 변경(푸시 상태 탐색)을 감지하여 플랫폼별 피드 숨기기 및 이벤트 중심 규칙이 전체 페이지 로드뿐만 아니라 페이지 내 탐색에 반응할 수 있도록 합니다. |
| `<all_urls>` 호스트 액세스 | 차단하기로 선택한 사이트에 차단 규칙과 플랫폼별 피드 숨기기를 적용하세요. 확장 프로그램은 규칙을 적극적으로 구성한 URL의 페이지만 읽고 수정하며 해당 규칙을 시행합니다. |

## 맞춤 규칙

사용자 정의 JavaScript 규칙을 작성하는 경우 해당 코드는 다음과 같습니다.

- 샌드박스가 적용된 오프스크린 문서에서 실행됩니다. 직접 도달할 수 없습니다.
  네트워크, 페이지 또는 기타 확장 프로그램.
- 고정된 메시지 브리지를 통해서만 콘텐츠 스크립트와 통신합니다.
  확장의 도우미 API에 의해 정의됩니다.
- 다음과 같은 경우 자동으로 격리됩니다(로그 항목으로 비활성화).
  내장 CPU, 로그, 메시지 후 또는 DOM 돌연변이 한도를 초과합니다.

맞춤 규칙은 나머지 설정과 함께 로컬에 저장됩니다.
장치 외부로 전송되지 않습니다.

## 웹사이트 및 크리에이터 태그 서비스 통계

이 섹션은 **웹사이트 및 선택적 크리에이터 태그 서비스**에 관한 것입니다.
이는 확장 자체와 별개입니다. 확장 프로그램이 계속 전송됩니다.
위에서 설명한 것처럼 아무것도 없습니다. 웹사이트에서는 작은 **통계**를 게시합니다.
패널을 채우고 이를 채우기 위해 서버는 몇 가지 집계 수를 유지합니다.

- **다운로드 횟수** — 각 제품의 다운로드 버튼이 클릭된 횟수
  클릭했습니다(macOS, Windows, 브라우저 확장, Safari).
- **크리에이터 분류** — 태그된 YouTube 크리에이터 수입니다.
- **계정** — 존재하는 계정 수입니다.
- **Q&A 활동** — 포럼 게시물 및 댓글의 총 개수입니다.

한 시간에 한 번씩 서버는 이러한 각 개수의 현재 값을 기록하고
다른 것은 없습니다. 이벤트별 기록, 클릭스트림, 세션이 없습니다.
역사.

- **완전히 익명/비식별화됨.** 이는 일반 누계입니다. 그들은
  귀하의 이름, 계정, 이메일, IP 주소, 장치 등에 연결되어 있지 **않습니다**
  기타 식별자 — 카운트를 개인에게 다시 부여할 수 있는 방법이 없습니다.
- **상업적이지 않습니다.** 이 데이터는 대중에게 통계를 보여주기 위해서만 존재합니다.
  패널. **절대 판매되지 않으며, 제3자와 공유되거나, 광고에 사용되지 않습니다.
  또는 기타 상업적 목적으로 사용됩니다.**
- **선택적 채널 ID 기여.** 귀하가 동의하는 경우에만,
  확장 프로그램/웹사이트는 YouTube **채널 ID**를 공유할 수 있습니다(동영상 제목은 공유하지 않음,
  시청 기록 또는 개인적인 모든 것)을 사용하여 모든 사람을 위해 제작자를 분류하는 데 도움을 줍니다.

## 어린이

확장은 범용 생산성 도구입니다. 그렇지 않다
어린이를 대상으로 하며 누구에게서든 고의로 데이터를 수집하지 않습니다.
광고를 표시하지 않습니다.

그 릴리스.
