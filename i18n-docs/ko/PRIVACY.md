# 개인 정보 보호 정책 — 맞춤형 웹 차단기

_최종 업데이트 날짜: 2026-08-04_

이 페이지는 **맞춤형 웹 차단기** 브라우저 확장 프로그램이 어떤 데이터를 수집하고, 그 데이터가 어디로 가며, 각 브라우저 권한을 요청하는 이유를 정확히 설명합니다. 요약하면: 당사는 사용자의 규칙이나 개인 브라우징 데이터를 저장하지 않습니다. 선택적 Vault Classifier 수집 및 분류는 계속 사용자의 관리하에 있으며, 인증된 로컬 브리지를 사용합니다. 별도의 선택적 로컬 AI(MCP) 통합 역시 기본적으로 꺼져 있으며, 사용자가 직접 연결하고 승인한 어시스턴트에만 데이터를 노출합니다.

## 요약

- **사용자의 구성은 브라우저 안에 남아 있습니다.** 차단 그룹, 일정, 맞춤 규칙, 로그, 타이머, 환경설정은 Chrome의 로컬 확장 프로그램 저장소(`chrome.storage.local`)에만 저장됩니다.
- **Vault Classifier는 로컬 전용입니다.** 선택적 Vault Classifier 통합을 명시적으로 활성화하면, YouTube 카드/페이지의 표시된 증거(제목, 표시된 설명, 표시된 태그, 공개된 크리에이터/동영상 ID 등)는 인증된 로컬 Vault 브리지를 통해서만 사용자의 Mac에 있는 Vault Classifier로 전달됩니다. 그것은 당사 웹사이트, 모델 제공업체, YouTube Data API, 그 밖의 어떤 서버로도 전송되지 않습니다.
- **수집은 별도의 옵트인입니다.** Vault Classifier는 사용자가 그 분류 데이터 작업 공간에서 YouTube 수집을 켠 후에만 렌더링된 광고 없는 YouTube 메타데이터를 확장 프로그램에 요청합니다. 꺼져 있을 때 확장 프로그램은 수집을 위한 제목이나 크리에이터 메타데이터를 전혀 전송하지 않습니다. 켜져 있을 때 보관되는 로컬 필드에는 표시된 제목, 크리에이터 이름/식별자, 동영상 유형, 길이, 표시된 구독자/조회수/게시 시각 텍스트, 정규 URL이 포함될 수 있습니다.
- **선택적 로컬 AI(MCP) 통합.** 이를 켜고 자신의 AI 어시스턴트를 연결하면, 그 어시스턴트는 — 사용자의 명시적 지시에 따라 — 사용자의 기기에 있는 로컬 Vault 서버를 통해 선택된 데이터(구성, 활동, 사용 시간, 활성/열린 탭의 URL, 사용자가 구성한 사이트의 표시된 페이지 내용, 모든 Classifier 증거)를 읽을 수 있습니다. 기본적으로 꺼져 있고, 연결마다 사용자가 승인하며, 비밀번호와 API 키는 이를 통해 결코 읽을 수 없습니다. 아래 "선택적 로컬 AI(MCP) 통합"을 참조하세요.
- **분석, 광고 프로필, 원격 측정, 비정상 종료 보고가 없습니다.**
- 사용자가 직접 구성한 차단 규칙을 적용하는 데 엄격히 필요한 범위를 넘어 브라우징 활동을 **추적하지 않습니다.**

## 로컬에 저장되는 내용

확장 프로그램은 세션 간에도 작동할 수 있도록 다음 항목을 브라우저의 로컬 확장 프로그램 저장소에 저장합니다.

- 사용자가 만든 차단 그룹: 그 이름, 규칙 유형, 차단된 사이트 목록, 일정, 미루기(snooze) 설정, 동결 상태, 사용자가 작성한 모든 맞춤 규칙 JavaScript.
- 한도를 적용하는 데 필요한 그룹별 런타임 상태(예: 지연 허용 예산에서 오늘 몇 분이 남았는지, 미루기가 언제 끝나는지, 엄격 동결 기간이 언제 끝나는지).
- **설정**에서 지정한 사용자 자신의 환경설정(틱 속도, 자동 저장 디바운스, 기본 미루기 시간, 기본 대체 URL, 디버그 모드 전환, 선택한 UI 언어).
- 앱 내 **로그** 패널에 표시되는 활동 로그 항목으로, UI에서 지울 수 있습니다.
- Vault Classifier를 명시적으로 활성화하면, 그 로컬 앱은 항목을 분류하고 설명하는 데 필요한 표시된 증거, 로컬 점수, 결정, 수정 사항에 대해 사용자에 의해 한도가 정해진 로컬 캐시를 유지합니다. 이 캐시는 사용자의 Mac에 남아 있으며 확장 프로그램과 서버 간의 일반적인 트래픽에 포함되지 않습니다.

사용자의 구성, 런타임 상태, 활동 로그는 사용자의 기기에 남아 있으며 당사 서비스에 의해 저장되지 않습니다. 브라우저 빌드와 사용자가 활성화한 기능에 따라, 그것들은 확장 프로그램, 기기 로컬 Safari 컴패니언 앱, 또는 명시적으로 연결된 로컬 Vault 브리지에 의해 처리될 수 있습니다.

## 수집하거나 전송하지 않는 내용

다음은 확장 프로그램 자체의 동작을 설명합니다. 유일한 예외는 사용자가 직접 활성화하고 연결할 수 있는 선택적 로컬 AI(MCP) 통합이며, 다음 섹션에서 설명합니다.

- 브라우징 기록은 확장 프로그램 자체에 의해 기록·요약·전송되지 않습니다. 그것은 사용자가 구성한 규칙을 적용하는 데에만 사용됩니다.
- 페이지 내용은 확장 프로그램 자체에 의해 유출·스크린샷·기록되지 않습니다.
- Vault Classifier 증거는 확장 프로그램에 의해 기기 밖으로 전송되지 않습니다. 그것은 사용자가 이 통합을 명시적으로 활성화한 경우에만 페어링된 로컬 브리지와 앱에 의해 처리됩니다.
- 폼 입력과 비밀번호는 확장 프로그램에 의해 결코 읽히지 않습니다. 비밀번호와 API 키는 로컬 AI(MCP) 통합을 통해서도 읽을 수 없습니다.
- 일반적인 규칙 적용을 위해 어떤 확장 프로그램 식별자, 계정 식별자, 기기 식별자, 또는 사용자의 규칙 구성도 전송되지 않습니다.

## 선택적 로컬 AI(MCP) 통합

확장 프로그램은 사용자의 기기에 있는 Vault 데스크톱 앱 내부에서 실행되는 로컬 **Vault MCP 서버**의 요청에 선택적으로 응답할 수 있습니다. 이를 통해 사용자는 자신의 AI 어시스턴트("MCP 클라이언트")를 연결하고, 사용자를 대신하여 Vault 설정을 읽거나 그에 대해 작업하게 할 수 있습니다. 이 통합은 **기본적으로 꺼져 있으며**, 사용자가 의도적으로 켜지 않는 한 아무것도 바뀌지 않습니다.

- **사용자가 시작합니다.** 통합을 활성화하고 MCP 클라이언트를 연결하기 전까지는 아무것도 노출되지 않으며, 각 클라이언트 연결은 사용자가 승인합니다. 끄면 즉시 접근이 취소됩니다.
- **서버는 로컬입니다.** 확장 프로그램이 제공하는 데이터는 동일한 인증된 기기 내 브리지를 통해 사용자의 Mac에 있는 Vault MCP 서버로 전달됩니다 — 당사 웹사이트나 어떤 Vault 서버로도 전달되지 않습니다. 확장 프로그램 자체는 사용자의 데이터를 제3자에게 보내지 않습니다.
- **그다음에는 사용자의 어시스턴트가 결정합니다.** 연결된 MCP 클라이언트가 사용자의 요청에 따라 데이터를 받으면, 그 데이터에 어떤 일이 일어나는지는 **그 클라이언트**와 그 자체의 개인정보 약관에 따라 정해집니다. 선택한 어시스턴트가 원격 서비스에 의존한다면, 그 어시스턴트는 사용자의 지시에 따라 데이터를 전송할 수 있습니다 — 어떤 AI 도구에 정보를 붙여 넣을 때와 마찬가지입니다. 신뢰하는 클라이언트를 선택하세요.
- **노출될 수 있는 내용.** 사용자의 지시에 따라 연결된 어시스턴트는 차단 그룹, 일정, 맞춤 규칙, 활동 로그, 사용 시간 카운터, 활성 탭 또는 열린 탭의 URL, 사용자가 구성한 사이트의 표시된 페이지 내용, 모든 Vault Classifier 증거와 결정을 읽을 수 있습니다. 상태를 바꾸는 작업(그룹 편집, 미루기 시작, 저장된 규칙 실행, 분류 트리거)은 개별적으로 확인됩니다.
- **비밀은 비밀로 유지됩니다.** 비밀번호(예: 자녀 보호 비밀번호)와 제공업체 API 키는 이 통합을 통해 **쓰기 전용**입니다. 설정할 수는 있지만 어떤 어시스턴트도 다시 읽을 수 없습니다.
- **Chromium 전용.** Classifier 브리지와 마찬가지로 이 통합은 기기 로컬 호스트가 있는 Chromium 브라우저에만 존재합니다. Firefox와 Safari는 이를 노출하지 않습니다.

## 각 권한을 요청하는 이유

| 권한 | 용도 |
| --- | --- |
| `storage` | 차단 그룹, 설정, 런타임 상태를 사용자의 브라우저에만 저장하고 불러옵니다. |
| `favicon` | Chromium에서 규칙 옆에 브라우저가 캐시한 사이트 아이콘을 표시합니다. 이는 브라우징 기록을 전송하지 않으며 당사 서비스에 요청을 보내지도 않습니다. |
| `nativeMessaging` | Chromium에서는 인증된 Vault Classifier 브리지를 위해 기기에 로컬 Native Messaging 증명을 요청하고, Safari에서는 맞춤 규칙 샌드박스 요청을 기기 로컬 컨테이너 앱으로 전달합니다. 이는 클라우드 전송이 아닙니다. |
| `alarms` | 미루기, 동결, 또는 일정 창이 끝날 때 시간 기반 한도와 규칙 상태를 새로 고치기 위해 백그라운드 service worker를 일정에 따라 깨웁니다. |
| `offscreen` | 맞춤 규칙 JavaScript를 화면 밖 문서의 샌드박스에서 실행하여, 확장 프로그램을 벗어나거나 페이지에 직접 손대지 못하게 합니다. |
| `tabs` | 도구 모음 아이콘을 클릭하면 편집기를 전체 탭으로 열고, 그룹 규칙을 평가하기 위해 활성 탭의 URL을 조회하며, 편집기에서 변경한 규칙 이후 탭을 새로 고칩니다. |
| `webNavigation` | SPA의 URL 변경(push-state 내비게이션)을 감지하여, 플랫폼별 피드 숨김 기능과 이벤트 기반 규칙이 전체 페이지 로드뿐 아니라 페이지 내 내비게이션에도 반응할 수 있게 합니다. |
| `<all_urls>` 호스트 접근 | 사용자가 차단하기로 선택한 사이트에서 차단 규칙과 플랫폼별 피드 숨김 기능을 적용합니다. 확장 프로그램은 사용자가 실제로 규칙을 구성한 URL에서만, 그리고 그 규칙을 적용하기 위해서만 페이지를 읽고/수정합니다. 선택적 Vault Classifier 어댑터는 YouTube로 제한됩니다. |

## 맞춤 규칙

맞춤 JavaScript 규칙을 작성하면 그 코드는 다음과 같습니다.

- 화면 밖 문서의 샌드박스에서 실행되며, 네트워크, 사용자의 페이지, 다른 확장 프로그램에 직접 접근할 수 없습니다.
- 확장 프로그램의 헬퍼 API로 정의된 고정된 메시지 브리지를 통해서만 콘텐츠 스크립트와 통신합니다.
- 내장된 CPU, 로그, post-message, 또는 DOM 변경 한도를 초과하면 자동으로 격리됩니다(로그 항목과 함께 비활성화).

사용자의 맞춤 규칙은 나머지 설정과 함께 로컬에 저장되며 기기 밖으로 전송되는 일이 결코 없습니다.

## 웹사이트 통계

이 섹션은 **웹사이트**에 관한 것입니다. 웹사이트는 작은 **통계** 패널을 게시하며, 이를 채우기 위해 서버는 몇 가지 집계 수치를 유지합니다.

- **다운로드 수** — 각 제품의 다운로드 버튼이 클릭된 횟수(macOS, Windows, 브라우저 확장 프로그램, Safari).
- **계정 수** — 존재하는 계정 수.
- **Q&A 활동** — 포럼 게시물과 댓글의 총수.

서버는 한 시간에 한 번 각 집계 수치의 현재 값을 기록합니다. 이 스냅숏에는 방문자별 이벤트, 클릭스트림, 세션 기록이 전혀 포함되지 않습니다.

- **완전 익명 / 비식별화.** 이는 단순한 누적 합계입니다. 그것들은 사용자의 이름, 계정, 이메일, IP 주소, 기기, 그 밖의 어떤 식별자와도 **연결되지 않습니다** — 어떤 수치를 개인에게 귀속시킬 방법이 없습니다.
- **결코 상업적이지 않음.** 이 데이터는 오직 공개 통계 패널을 표시하기 위해서만 존재합니다. 그것은 **결코 판매, 제3자 공유, 광고 목적, 또는 그 밖의 어떤 상업적 목적에도 사용되지 않습니다.**

## 아동

이 확장 프로그램은 범용 생산성 도구입니다. 아동을 대상으로 하지 않으며, 누구로부터도 고의로 데이터를 수집하지 않고, 광고를 표시하지 않습니다.
