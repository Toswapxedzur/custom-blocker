# 볼트 확장

Vault 확장은 Chromium 브라우저용 Manifest V3 포커스 도구입니다. 현재 편집기는 웹사이트 블록 그룹, 지원되는 플랫폼 그룹, 사용자 정의 JavaScript 그룹, 일정, 정지 및 일시 중지 제어, 선택적 웹 앱 브리지 링크를 관리합니다.

소스 코드는 제품 계약입니다. [manual/en.md](manual/en.md)의 영어 앱 내 매뉴얼에는 배송된 컨트롤이 설명되어 있습니다. 이는 이전에 복사되고 기계 번역된 매뉴얼을 대체합니다.

## 현재 기능

- 차단 목록 또는 허용 목록 동작, 선택적 리디렉션, 즉시 차단, 시간 허용 또는 카운트다운이 포함된 기본 웹사이트 그룹입니다.
- YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord 및 Twitter/X 전용 그룹.
- 현재 플랫폼 프로필이 지원하는 플랫폼별 필터 및 선택적 숨기기 요소 컨트롤입니다.
- 구문 검사, 템플릿, 실행 제어, 제어된 런타임 및 로그 피드를 갖춘 사용자 정의 JavaScript 그룹입니다.
- 그룹별 일정, 동결 모드, 일시 중지 제어, 가져오기/내보내기 및 자동 저장.
- 지원되는 사용자 정의 규칙 텍스트, CSV 및 JSON 작업을 위한 선택적 로컬 폴더 액세스.
- 명시적으로 연결된 그룹을 위한 기본 Vault 브리지 허브에 대한 선택적 연결입니다.

## 로컬에서 실행

1. Chromium 브라우저에서 `chrome://extensions`을 엽니다.
2. **개발자 모드**를 활성화합니다.
3. **압축 해제된 로드**를 선택하고 이 저장소 폴더를 선택합니다.
4. Vault 확장을 열고 그룹을 생성합니다.

매니페스트에는 현재 오프스크린 및 규칙 API를 위해 Chrome 116 이상이 필요합니다.

## 개발 확인

이 폴더에서 확장 테스트 모음을 실행합니다.

```bash
./tests/run.sh
```

이 제품군은 도우미 동작, 플랫폼 프로필, Markdown 렌더링 및 번역 카탈로그 감사를 실행합니다.

## 현지화된 매뉴얼 및 번역

영어 문서는 정식 소스로 남아 있습니다. 확장 프로그램은 `manual/en.md` 옆에 현지화된 설명서를 제공하고, 기타 유지 관리 문서의 현지화된 복사본은 `i18n-docs/<locale>/` 아래에 있습니다.

`translation/*.json`의 UI 카탈로그는 지원되는 모든 로케일에 대해 완전합니다. 다음을 통해 카탈로그와 현지화된 문서를 확인하세요.

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## 범위

Vault 확장 프로그램은 설치된 브라우저 프로필과 브라우저에서 액세스 권한을 부여한 페이지에서만 작동합니다. 사용자가 명시적으로 브리지를 연결하고 일치하는 그룹을 연결하지 않는 한 기본 앱을 설치하거나 시스템 권한을 변경하거나 그룹을 동기화하지 않습니다.
