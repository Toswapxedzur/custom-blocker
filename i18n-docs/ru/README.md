# расширение хранилища

Расширение Vault — это инструмент фокусировки Manifest V3 для браузеров Chromium. Его текущий редактор управляет группами блокировки веб-сайтов, группами поддерживаемых платформ, пользовательскими группами JavaScript, расписаниями, элементами управления зависанием и откладыванием, а также дополнительными мостовыми ссылками веб-приложений.

Исходный код — это контракт на продукт. В руководстве по приложению на английском языке по адресу [manual/en.md](manual/en.md) объясняются встроенные элементы управления; оно заменяет предыдущие скопированные и машинно переведенные руководства.

## Текущие возможности

- Группы веб-сайтов по умолчанию с поведением черного или белого списка, необязательным перенаправлением, немедленной блокировкой, временным ограничением или обратным отсчетом.
- Выделенные группы для YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord и Twitter/X.
- Фильтры, специфичные для платформы, и дополнительные элементы управления скрытыми элементами, если текущий профиль платформы их поддерживает.
- Пользовательские группы JavaScript с проверкой синтаксиса, шаблонами, элементами управления запуском, контролируемой средой выполнения и каналом журнала.
- Расписания для каждой группы, режимы заморозки, контроль повтора, импорт/экспорт и автоматическое сохранение.
- Дополнительный доступ к локальной папке для поддерживаемых операций с текстом настраиваемых правил, CSV и JSON.
— Дополнительное подключение к собственному концентратору Vault Bridge для явно связанных групп.

## Запускать локально

1. Откройте `chrome://extensions` в браузере Chromium.
2. Включите **Режим разработчика**.
3. Выберите **Загрузить в распакованном виде** и выберите папку репозитория.
4. Откройте расширение Vault и создайте группу.

Для манифеста требуется Chrome 116 или более поздняя версия для текущих API-интерфейсов закадрового режима и правил.

## Проверки разработки

Запустите набор тестов расширения из этой папки:

```bash
./tests/run.sh
```

Пакет осуществляет вспомогательное поведение, профили платформы, рендеринг Markdown и аудит каталога переводов.

## Локализованные руководства и переводы

Английские документы остаются каноническим источником. Расширение отправляет локализованные руководства рядом с `manual/en.md`, а локализованные копии других поддерживаемых документов находятся под адресом `i18n-docs/<locale>/`.

Каталоги пользовательского интерфейса в `translation/*.json` полны для всех поддерживаемых языковых стандартов. Проверьте каталоги и локализованные документы с помощью:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## Область применения

Расширение Vault действует только в профиле браузера, в котором оно установлено, и на страницах, к которым браузер предоставляет ему доступ. Он не устанавливает собственные приложения, не изменяет системные разрешения и не синхронизирует группы, если пользователь явно не подключит мост и не свяжет соответствующие группы.
