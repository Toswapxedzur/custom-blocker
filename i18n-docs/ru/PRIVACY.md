# Политика конфиденциальности — Пользовательский веб-блокировщик

_Последнее обновление: 4 августа 2026 г._

На этой странице подробно объясняется, какие данные собирает расширение браузера **Пользовательский веб-блокировщик**, куда они направляются и почему запрашивается каждое разрешение браузера. Если коротко: мы не храним ваши правила и личные данные о просмотрах. Необязательные сбор и классификация с помощью Vault Classifier остаются под вашим контролем и используют аутентифицированный локальный мост. Отдельная необязательная интеграция локального ИИ (MCP) также по умолчанию отключена и раскрывает данные только тому ассистенту, которого вы сами подключаете и одобряете.

## Краткий обзор

- **Ваша конфигурация остаётся в вашем браузере.** Группы блокировки, расписания, пользовательские правила, журналы, таймеры и настройки сохраняются только в локальном хранилище расширения Chrome (`chrome.storage.local`).
- **Vault Classifier работает только локально.** Если вы явно включите необязательную интеграцию с Vault Classifier, видимые данные карточек/страниц YouTube (например, заголовок, видимое описание, отображаемые теги и публичные идентификаторы автора/видео) направляются только через аутентифицированный локальный мост Vault в Vault Classifier на вашем Mac. Они не отправляются на наш сайт, поставщику модели, в YouTube Data API или на любой другой сервер.
- **Сбор — это отдельное согласие (opt-in).** Vault Classifier запрашивает у расширения отрисованные метаданные YouTube без рекламы только после того, как вы включите сбор с YouTube в его рабочей области данных классификации. Когда он выключен, расширение не отправляет для сбора никаких заголовков или метаданных автора. Когда он включён, сохраняемые локальные поля могут включать видимый заголовок, имя/идентификатор автора, тип видео, длительность, видимый текст с числом подписчиков/просмотров/датой публикации и канонический URL.
- **Необязательная интеграция локального ИИ (MCP).** Если вы включите её и подключите собственного ИИ-ассистента, этот ассистент сможет — по вашему явному указанию — прочитать выбранные данные (вашу конфигурацию, активность, время использования, URL активной/открытых вкладок, видимое содержимое страниц на настроенных вами сайтах и любые данные Classifier) через локальный сервер Vault на вашем устройстве. По умолчанию она отключена, каждое подключение одобряется вами, а пароли и ключи API через неё никогда не читаются. См. раздел «Необязательная интеграция локального ИИ (MCP)» ниже.
- **Нет аналитики, рекламного профиля, телеметрии и отчётов о сбоях.**
- **Никакого отслеживания** активности просмотра сверх того, что строго необходимо для применения правил блокировки, настроенных вами самими.

## Что хранится локально

Расширение хранит следующее в локальном хранилище расширения вашего браузера, чтобы работать между сеансами:

- Создаваемые вами группы блокировки: их названия, типы правил, списки заблокированных сайтов, расписания, настройки откладывания (snooze), состояние заморозки и любой написанный вами JavaScript пользовательских правил.
- Состояние выполнения по каждой группе, необходимое для соблюдения лимитов (например, сколько минут отложенного бюджета разрешённого времени осталось сегодня, когда заканчивается откладывание, когда заканчивается период строгой заморозки).
- Ваши собственные настройки, заданные в разделе **Настройки** (частота обновления, задержка автосохранения, длительность откладывания по умолчанию, запасной URL по умолчанию, переключатель режима отладки, выбранный язык интерфейса).
- Записи журнала активности, отображаемые в панели **Журнал** в приложении, которые вы можете очистить через интерфейс.
- Когда вы явно включаете Vault Classifier, его локальное приложение ведёт ограниченный пользователем локальный кэш видимых данных, локальных оценок, решений и исправлений, необходимых для классификации и пояснения записей. Этот кэш остаётся на вашем Mac и не является частью обычного трафика между расширением и сервером.

Ваша конфигурация, состояние выполнения и журнал активности остаются на вашем устройстве и не сохраняются нашим сервисом. В зависимости от сборки браузера и включённых вами функций они могут обрабатываться расширением, его локальным приложением-компаньоном для Safari или явно связанным локальным мостом Vault.

## Что НЕ собирается и не передаётся

Здесь описано поведение расширения само по себе. Единственное исключение — необязательная интеграция локального ИИ (MCP), которую вы можете сами включить и подключить и которая описана в следующем разделе.

- История просмотров не записывается, не резюмируется и не передаётся самим расширением; она используется только для применения настроенных вами правил.
- Содержимое страниц не извлекается, не сохраняется в виде снимков экрана и не журналируется самим расширением.
- Данные Vault Classifier не передаются расширением за пределы устройства. Они обрабатываются связанным локальным мостом и приложением только тогда, когда вы явно включаете эту интеграцию.
- Ввод в формы и пароли никогда не считываются расширением; пароли и ключи API также нельзя прочитать через интеграцию локального ИИ (MCP).
- Для обычного применения правил не передаётся никакой идентификатор расширения, учётной записи или устройства, а также ваша конфигурация правил.

## Необязательная интеграция локального ИИ (MCP)

Расширение может по желанию отвечать на запросы локального **сервера MCP Vault**, работающего внутри настольных приложений Vault на вашем собственном устройстве, чтобы вы могли подключить собственного ИИ-ассистента («клиент MCP») и поручить ему читать вашу конфигурацию Vault или действовать в ней за вас. Эта интеграция **по умолчанию отключена** и ничего не меняет, пока вы намеренно её не включите.

- **Вы её инициируете.** Ничего не раскрывается, пока вы не включите интеграцию и не подключите клиент MCP, и каждое подключение клиента одобряется вами. Отключение немедленно отзывает доступ.
- **Сервер локальный.** Данные, предоставляемые расширением, передаются через тот же аутентифицированный мост на устройстве серверу MCP Vault на вашем Mac — не на наш сайт и не на какой-либо сервер Vault. Само расширение не отправляет ваши данные третьим лицам.
- **Дальше решает ваш ассистент.** Как только подключённый клиент MCP получает данные по вашему запросу, то, что с ними происходит, определяется **этим клиентом** и его собственными условиями конфиденциальности. Если выбранный вами ассистент опирается на удалённый сервис, этот ассистент может передать ваши данные по вашему указанию — так же, как когда вы вставляете информацию в любой ИИ-инструмент. Выбирайте клиент, которому доверяете.
- **Что может быть раскрыто.** По вашему указанию подключённый ассистент может прочитать ваши группы блокировки, расписания, пользовательские правила, журнал активности, счётчики времени использования, URL активной вкладки или открытых вкладок, видимое содержимое страниц на настроенных вами сайтах, а также любые данные и решения Vault Classifier. Действия, изменяющие состояние (редактирование групп, запуск откладывания, выполнение сохранённого правила, запуск классификации), подтверждаются по отдельности.
- **Секреты остаются секретными.** Пароли (например, пароль родительского контроля) и ключи API поставщиков в рамках этой интеграции доступны **только для записи**: их можно задать, но ни один ассистент не может прочитать их обратно.
- **Только Chromium.** Как и мост Classifier, эта интеграция существует только в браузерах Chromium с локальным хостом на устройстве; Firefox и Safari её не предоставляют.

## Зачем запрашивается каждое разрешение

| Разрешение | Для чего используется |
| --- | --- |
| `storage` | Сохранять и загружать ваши группы блокировки, настройки и состояние выполнения только в вашем браузере. |
| `favicon` | Показывать рядом с правилами кэшированные браузером значки сайтов в Chromium. Это не отправляет историю просмотров и не выполняет запросов к нашему сервису. |
| `nativeMessaging` | В Chromium запрашивать у устройства локальное подтверждение Native Messaging для аутентифицированного моста Vault Classifier; в Safari пересылать запросы песочницы пользовательских правил в локальное контейнерное приложение устройства. Это не облачный транспорт. |
| `alarms` | Пробуждать фоновый service worker по расписанию для обновления лимитов на основе времени и состояния правил по завершении окна откладывания, заморозки или расписания. |
| `offscreen` | Выполнять JavaScript пользовательских правил в песочнице во внеэкранном документе, чтобы он не мог выйти за пределы расширения и напрямую воздействовать на ваши страницы. |
| `tabs` | Открывать редактор в виде полноценной вкладки при нажатии на значок панели инструментов, определять URL активной вкладки для оценки правил группы и перезагружать вкладки после изменения правила, внесённого вами в редакторе. |
| `webNavigation` | Обнаруживать изменения URL в SPA (навигация push-state), чтобы средства скрытия ленты для конкретных платформ и правила, управляемые событиями, могли реагировать на навигацию внутри страницы, а не только на полную загрузку страниц. |
| Доступ к хостам `<all_urls>` | Применять ваши правила блокировки и средства скрытия ленты для конкретных платформ на сайтах, которые вы решите блокировать. Расширение читает/изменяет страницы только по тем URL, для которых вы активно настроили правило, и только для его применения; необязательный адаптер Vault Classifier ограничен YouTube. |

## Пользовательские правила

Если вы пишете пользовательские правила на JavaScript, этот код:

- Выполняется во внеэкранном документе в песочнице; он не может напрямую обращаться к сети, вашим страницам или другим расширениям.
- Взаимодействует со сценариями содержимого только через фиксированный мост сообщений, определённый вспомогательным API расширения.
- Автоматически помещается в карантин (отключается с записью в журнале), если превышает встроенные лимиты по ЦП, журналу, post-message или мутациям DOM.

Ваши пользовательские правила хранятся локально вместе с остальными настройками и никогда не передаются за пределы устройства.

## Статистика веб-сайта

Этот раздел касается **веб-сайта**. Веб-сайт публикует небольшую панель **Статистика**, и для её заполнения сервер хранит несколько агрегированных счётчиков:

- **Количество загрузок** — сколько раз была нажата кнопка загрузки каждого продукта (macOS, Windows, расширение браузера, Safari).
- **Учётные записи** — сколько учётных записей существует.
- **Активность вопросов и ответов** — общее число сообщений и комментариев на форуме.

Раз в час сервер записывает текущее значение каждого агрегированного счётчика. Эти снимки не содержат ни одного события по посетителю, последовательности кликов или истории сеанса.

- **Полностью анонимно / обезличено.** Это простые нарастающие итоги. Они **не** связаны с вашим именем, учётной записью, электронной почтой, IP-адресом, устройством или любым другим идентификатором — нет способа сопоставить счётчик с человеком.
- **Никогда не в коммерческих целях.** Эти данные существуют только для отображения публичной панели «Статистика». Они **никогда не продаются, не передаются третьим лицам, не используются для рекламы или для любых других коммерческих целей.**

## Дети

Расширение — это инструмент повышения продуктивности общего назначения. Оно не предназначено для детей, сознательно не собирает данные ни у кого и не показывает рекламу.
