# Политика конфиденциальности — Пользовательский веб-блокировщик

_Последнее обновление: 30 июня 2026 г._

На этой странице объясняется, какие именно данные использует браузер **Пользовательский веб-блокировщик**.
расширение собирает, куда оно идет и почему каждое разрешение браузера
просил. Вкратце: ничто не покидает ваш браузер.

## Резюме

- **Данные не отправляются ни на один сервер.** Расширение создает нулевую сеть.
  запросы к какой-либо третьей стороне (или нам). У него нет аналитики, нет
  телеметрия, отсутствие отчетов о сбоях, отсутствие удаленной настройки, отсутствие автоматического
  обновления, выходящие за рамки стандартного механизма Интернет-магазина Chrome.
- **Все данные остаются в вашем браузере** и сохраняются через локальную версию Chrome.
  расширение хранилища (`chrome.storage.local`). Он никогда не синхронизируется, если только
  Chrome сам синхронизирует ваш локальный профиль.
- **Информация, позволяющая установить личность, не собирается** компанией
  продление в любое время.
- **Нет отслеживания** активности в Интернете, кроме строго необходимого.
  применить правила блокировки, настроенные вами самостоятельно.

## Что хранится локально

Расширение сохраняет следующее в локальном расширении вашего браузера
хранилище, чтобы оно могло выполнять свою работу между сеансами:

- Группы блоков, которые вы создаете: их названия, типы правил, списки
  заблокированные сайты, расписания, настройки повтора, состояние заморозки и любые другие
  JavaScript, написанный вами по индивидуальному правилу.
- Состояние выполнения для каждой группы, необходимое для обеспечения соблюдения ограничений (например, сколько
  минуты бюджета отложенных пособий остаются сегодня, когда отложить
  заканчивается, когда заканчивается период строгого замораживания).
- Ваши собственные настройки, установленные в **Настройки** (тикрейт, автосохранение).
  устранение дребезга, продолжительность повтора по умолчанию, резервный URL-адрес по умолчанию, режим отладки
  переключить, выбранный язык пользовательского интерфейса).
- Записи журнала активности отображаются на панели **Журнал** в приложении, которую вы можете
  очистить из пользовательского интерфейса.

Эти данные читаются и записываются только собственными скриптами расширения, только
на вашем устройстве и только в вашем профиле браузера.

## Что НЕ собирается и не передается

- История просмотров не записывается, не обобщается и не передается.
- Содержимое страницы не фильтруется, не снимается с экрана и не регистрируется.
- Ввод формы, пароли и личная информация никогда не читаются.
- Никакая информация о вас, вашем устройстве или вашем использовании не отправляется на
  автор расширения или любая третья сторона.

## Почему запрашивается каждое разрешение

| Разрешение | Для чего он используется |
| --- | --- |
| `storage` | Сохраняйте и загружайте группы блоков, настройки и состояние выполнения только в браузере. |
| `declarativeNetRequest` | Сообщите Chrome, какие URL-адреса следует блокировать в соответствии с настроенными вами правилами. Браузер обрабатывает блокировку; расширение только регистрирует и обновляет список правил. |
| `alarms` | Разбудите работника фоновой службы по расписанию, чтобы обновить ограничения по времени и состояние правил, когда заканчивается окно повтора, замораживания или расписания. |
| `offscreen` | Запускайте изолированный JavaScript с пользовательскими правилами в закадровом документе, чтобы он не мог выйти за рамки расширения или напрямую коснуться ваших страниц. |
| `tabs` | Откройте редактор как полную вкладку, щелкнув значок на панели инструментов, найдите URL-адрес активной вкладки, чтобы оценить правила группы, и перезагрузите вкладки после изменения правила, внесенного вами в редакторе. |
| `webNavigation` | Обнаруживайте изменения URL-адреса SPA (навигация по состоянию), чтобы скрытия каналов для каждой платформы и правила, управляемые событиями, могли реагировать на навигацию на странице, а не только на полную загрузку страницы. |
| `<all_urls>` доступ к хосту | Применяйте свои правила блокировки и средства скрытия каналов для каждой платформы на любых сайтах, которые вы решите заблокировать. Расширение читает/изменяет страницы только по URL-адресам, для которых вы активно настроили правило, и только для обеспечения соблюдения этого правила. |

## Пользовательские правила

Если вы пишете собственные правила JavaScript, этот код:

- Запускается в изолированном закадровом документе; он не может напрямую достичь
  сеть, ваши страницы или другие расширения.
- Общается со скриптами контента только через фиксированный мост сообщений.
  определяется вспомогательным API расширения.
- Автоматически помещается в карантин (отключается с помощью записи в журнале), если
  превышает встроенные ограничения ЦП, журнала, пост-сообщений или мутаций DOM.

Ваши пользовательские правила хранятся локально вместе с остальными настройками.
и никогда не передаются с устройства.

## Статистика веб-сайта и службы тегов создателя

Этот раздел посвящен **веб-сайту и дополнительной службе тегов авторов**.
которые отделены от самого расширения. Расширение по-прежнему отправляет
ничего, как описано выше. На сайте публикуется небольшая **Статистика**.
панель, и для ее заполнения сервер сохраняет несколько совокупных значений:

- **Счетчик загрузок** — сколько раз была нажата кнопка загрузки каждого продукта.
  нажали (macOS, Windows, расширение браузера, Safari).
– **Классификация авторов** — сколько авторов YouTube было отмечено.
- **Аккаунты** — сколько существует аккаунтов.
- **Активность вопросов и ответов** — общее количество сообщений и комментариев на форуме.

Раз в час сервер записывает текущее значение каждого из этих счетчиков и
ничего больше. Нет записей по каждому событию, нет потоков кликов и нет сеансов.
история.

- **Полностью анонимно/обезличено.** Это простые промежуточные итоги. Они
  **не** связаны с вашим именем, учетной записью, электронной почтой, IP-адресом, устройством или любым другим
  другой идентификатор — нет возможности приписать счетчик обратно человеку.
- **Никогда не является коммерческим.** Эти данные существуют только для показа общедоступной статистики.
  панель. Он **никогда не продается, не передается третьим лицам, не используется для рекламы,
  или использоваться в любых других коммерческих целях.**
- **Дополнительные идентификаторы каналов.** Если — и только если — вы дадите согласие,
  расширение/веб-сайт могут использовать **идентификаторы каналов YouTube** (никогда не заголовки видео,
  посмотрите историю или что-нибудь личное), чтобы классифицировать авторов для всех.

## Дети

Расширение представляет собой универсальный инструмент повышения производительности. Это не
направлено на детей, сознательно не собирает ни от кого данные и
не отображает рекламу.
