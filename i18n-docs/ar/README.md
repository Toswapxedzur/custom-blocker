# ملحق قبو

ملحق Vault عبارة عن أداة تركيز Manifest V3 لمتصفحات Chromium. يدير محرره الحالي مجموعات حظر مواقع الويب، ومجموعات الأنظمة الأساسية المدعومة، ومجموعات JavaScript المخصصة، والجداول الزمنية، وعناصر التحكم في التجميد والتأجيل، وروابط جسر تطبيقات الويب الاختيارية.

كود المصدر هو عقد المنتج. يشرح دليل التطبيق باللغة الإنجليزية الموجود على [manual/en.md](manual/en.md) عناصر التحكم التي يتم شحنها؛ فهو يحل محل الأدلة السابقة المنسوخة والمترجمة آليًا.

## الإمكانيات الحالية

- مجموعات مواقع الويب الافتراضية مع سلوك القائمة المحظورة أو القائمة المسموح بها، أو إعادة التوجيه الاختيارية، أو الحظر الفوري، أو بدل الوقت، أو العد التنازلي.
- مجموعات مخصصة لـ YouTube وTikTok وFacebook وInstagram وTwitch وReddit وDiscord وTwitter/X.
- عوامل التصفية الخاصة بالنظام الأساسي وعناصر التحكم الاختيارية في إخفاء العناصر حيث يدعمها ملف تعريف النظام الأساسي الحالي.
- مجموعات JavaScript مخصصة مع التحقق من بناء الجملة، والقوالب، وعناصر التحكم في التشغيل، ووقت تشغيل متحكم فيه، وخلاصة السجل.
- الجداول الزمنية لكل مجموعة، وأوضاع التجميد، وعناصر التحكم في التأجيل، والاستيراد/التصدير، والحفظ التلقائي.
- وصول اختياري للمجلد المحلي لعمليات نص القاعدة المخصصة وCSV وJSON المدعومة.
- اتصال اختياري بمركز جسر Vault الأصلي للمجموعات المرتبطة بشكل صريح.

## تشغيل محليا

1. افتح `chrome://extensions` في متصفح Chromium.
2. قم بتمكين **وضع المطور**.
3. حدد **تحميل غير مضغوط** واختر مجلد المستودع هذا.
4. افتح امتداد Vault وقم بإنشاء مجموعة.

يتطلب البيان الإصدار 116 من Chrome أو إصدارًا أحدث لواجهات برمجة التطبيقات الحالية الموجودة خارج الشاشة والقاعدة.

## فحوصات التطوير

قم بتشغيل مجموعة اختبار الامتداد من هذا المجلد:

```bash
./tests/run.sh
```

تمارس المجموعة السلوك المساعد وملفات تعريف النظام الأساسي وعرض Markdown وتدقيق كتالوج الترجمة.

## الأدلة والترجمات المترجمة

تظل الوثائق الإنجليزية هي المصدر القانوني. يقوم الملحق بشحن الأدلة المترجمة الخاصة به بجانب `manual/en.md`، والنسخ المترجمة من المستندات الأخرى التي تمت صيانتها موجودة تحت `i18n-docs/<locale>/`.

كتالوجات واجهة المستخدم في `translation/*.json` كاملة لكل لغة محلية مدعومة. تحقق من الكتالوجات والمستندات المترجمة باستخدام:

```bash
node scripts/translation-audit.js
node scripts/documentation-audit.js
```

## النطاق

يعمل ملحق Vault فقط في ملف تعريف المتصفح حيث تم تثبيته وعلى الصفحات التي يمنحه المتصفح حق الوصول إليها. ولا يقوم بتثبيت التطبيقات الأصلية، أو تغيير أذونات النظام، أو مزامنة المجموعات ما لم يتصل المستخدم بشكل صريح بجسر ويربط المجموعات المتطابقة.
