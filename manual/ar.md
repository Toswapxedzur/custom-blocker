# المرجع الوظيفي لامتداد Vault

## الغرض والحالة

هذه هي المواصفات الوظيفية الرسمية لامتداد متصفح Vault. فهو يوثق عقد المنتج: البيانات التي يمكن للمستخدم تكوينها، والسلوكيات الدقيقة التي ينتجها التكوين، ولغة القواعد المخصصة العامة، والحدود التي تنطبق عليها.

إنه ليس دليل البدء السريع عن عمد. البرنامج التعليمي للموقع هو مسار التعلم. هذا المستند مخصص للأشخاص الذين يحتاجون إلى تكوين سلوك Vault المرئي للمستخدم أو اختباره أو صيانته أو تدقيقه أو إعادة إنتاجه.

الكود هو الحقيقة الأساسية عندما يختلف هذا المستند والمنتج. تستخدم الأسماء الموجودة في هذا المستند المفردات المخزنة/العامة للمنتج حيثما كان ذلك ممكنًا. كلمة مثل "إرجاع" تعني قيمة الإرجاع المتاحة لقاعدة مخصصة؛ ولا يعد بنتيجة على مستوى المتصفح إذا رفض المتصفح أو الصفحة الإجراء المطلوب.

## 1. حدود المنتج

Vault عبارة عن WebExtension للتحكم في التركيز. وحدة التكوين الخاصة بها هي **مجموعة الكتل**. يمكن للمجموعة:

- اتخاذ قرار بحظر موقع ويب أو صفحة منصة أو منشئ أو مجتمع أو خادم أو قناة أو حساب عالي المستوى؛
- إخفاء أسطح المنصة التي تم تكوينها أو بطاقات التغذية المطابقة؛
- قياس الوقت الذي يقضيه في نطاق مطابقة؛
- تطبيق جدول زمني أو تجميد الحماية أو قيلولة بعد الظهر المؤقتة حيث يدعمها نوع المجموعة هذا؛
- تشغيل قاعدة JavaScript مخصصة باستخدام واجهة برمجة التطبيقات للحدث؛
- إظهار مؤقت أو لوحة أو رسالة أو سجل صفحة على الصفحة؛
- إعادة التوجيه، أو التنقل، أو إغلاق علامة تبويب المتصفح، أو الاحتفاظ بقائمة الحظر الخاصة بالموقع التي تم إنشاؤها بقاعدة للجلسة فقط؛
- المشاركة اختياريًا في مجموعة جسر Vault المتصلة محليًا.

يعمل Vault فقط داخل ملف تعريف المتصفح حيث تم تثبيته وفقط عندما يسمح المتصفح بتشغيل البرنامج النصي للمحتوى الخاص به. لا:

- تثبيت تطبيق أصلي أو امتداد للمتصفح؛
- حظر تطبيقات نظام التشغيل؛
- تجاوز مطالبات إذن المتصفح، أو قيود التصفح الخاص، أو نموذج الأمان الخاص بموقع الويب؛
- ضمان الإخفاء المستند إلى المحدد عندما تقوم منصة تابعة لجهة خارجية بتغيير DOM الخاص بها؛
- جعل حالة القاعدة المخصصة قابلة للنقل عبر الملفات الشخصية ما لم يقوم المستخدم بتصديرها/تكوينها بشكل منفصل؛
- توفير جدار حماية للشبكة، أو وكيل، أو التحكم في الحساب، أو خدمة المراقبة الأبوية.

يتم استخدام المصطلحات التالية في جميع أنحاء:

| مصطلح | معنى |
| --- | --- |
| المجموعة | كائن تكوين واحد مسمى بشكل مستقل. يجب أن تكون الأسماء فريدة داخل الامتداد، مع تجاهل حالة الأحرف. |
| مجموعة المواقع | مجموعة عادية تكون قائمة نطاقاتها هي شرط المطابقة الرئيسي الخاص بها. |
| مجموعة المنصة | مجموعة عادية متخصصة في YouTube أو TikTok أو Facebook أو Instagram أو Twitch أو Reddit أو Discord أو Twitter/X. |
| مجموعة مخصصة | مجموعة تمتلك قاعدة JavaScript وتسجيلات الأحداث الخاصة بها. حكمها يقرر سلوكها. |
| مباراة | تستوفي الصفحة أو عنصر الخلاصة أو سطح النظام الأساسي الشروط التي تم تكوينها للمجموعة. |
| نشط | المجموعة ممكّنة، ومؤهلة لجدولها الزمني، ولم يتم تأجيلها حاليًا. لا تخضع المجموعات المخصصة لواجهة مستخدم الجدول العادي. |
| كتلة | منع صفحة المستوى الأعلى الحالية من أن تظل قابلة للاستخدام، عادةً عن طريق إعادة التوجيه إلى هدفها الاحتياطي. |
| إخفاء | إزالة أو إخفاء عنصر/بطاقة في الصفحة المعروضة حاليًا. الإخفاء ليس كتلة شبكة. |
| عنوان URL الاحتياطي | هدف إعادة توجيه خاص بالمجموعة. إذا كان فارغًا، فسيتم استخدام الاحتياطي العام. |
| السماح/تأثير الاستثناء | حكم بطاقة النظام الأساسي الذي ينقذ المحتوى المطابق من قواعد الإخفاء ذات الأولوية المنخفضة. وهي ليست قائمة مسموح بها عامة لموقع الويب. |

## 2. نموذج المجموعة ودورة الحياة المشتركة

تحتوي كل مجموعة مخزنة على معرف ثابت واسم ونوع وعلامة ممكّنة وحقول سياسة مشتركة. يتم تمكين المجموعة العادية الجديدة بشكل افتراضي. يمكن تحديد مجموعة أو حفظها من خلال سلوك الحفظ التلقائي للمحرر أو إعادة ترتيبها أو تصديرها أو استيرادها أو تجميدها أو إلغاء تجميدها أو تأجيلها أو تعطيلها أو حذفها.

### 2.1 الترتيب والتداخل

يمكن لأكثر من مجموعة أن تتطابق مع نفس الصفحة. يقوم Vault بتقييم المجموعات المخزنة من نهاية القائمة المعروضة وحتى البداية. تعامل مع العناصر السفلية في القائمة على أنها مطابقات لاحقة/ذات أسبقية أعلى عند تصميم قواعد متداخلة.

بالنسبة للحظر العادي للمواقع ذات المستوى الأعلى، يمكن لأي مجموعة حظر قابلة للتطبيق أن تجعل الصفحة غير متاحة. بالنسبة لتصفية بطاقة التغذية، يستخدم تتالي النظام الأساسي ترتيب كل مجموعة مطابقة وتأثيرها: يمكن أن يؤدي السماح/الاستثناء المطابقة اللاحقة إلى إنقاذ عنصر من مسندات الحظر ذات الأولوية المنخفضة. يقتصر سلوك الاستثناء هذا على سطح تصفية بطاقة النظام الأساسي؛ ولا يؤدي إلى التراجع عن حظر الموقع العادي للصفحة بأكملها.

### 2.2 الحالة الممكّنة

يتم الاحتفاظ بالمجموعات المعطلة ولكنها لا تشارك في المطابقة العادية أو الموقتات أو الجداول الزمنية أو عمليات التأجيل العادية. يؤدي تعطيل مجموعة مخصصة أيضًا إلى إلغاء تحميل التسجيلات النشطة الخاصة بها. لا تؤدي إعادة التمكين إلى تحويل النص غير المحفوظ إلى قاعدة مخصصة نشطة؛ قم بتشغيل القاعدة لتحميل المصدر المحفوظ.

### 2.3 الحقول المشتركة

| المجال | المعنى والقيود |
| --- | --- |
| الاسم | غير فارغ، ومقتطع، وفريد ​​من نوعه وغير حساس لحالة الأحرف ضمن نقطة النهاية هذه. يحدد الجسر أيضًا المجموعات القابلة للربط حسب الاسم والنوع، لذا فإن الأسماء الثابتة مهمة. |
| ممكّن | تمكين أو تعطيل المطابقة العادية. |
| السلوك | حظر فوري، أو حظر بعد البدل، أو مؤقت/عد تصاعدي. تستخدم المجموعات المخصصة قاعدتها الخاصة بدلاً من محدد السلوك العادي هذا. |
| الدقائق المسموح بها | الرقم الموجب الذي يستخدمه سلوك الكتلة بعد البدل. المجموعات الجديدة الافتراضية هي 15 دقيقة. |
| إعادة تعيين ساعات الفاصل الزمني | الرقم الموجب الذي تستخدمه المجموعات العادية المحددة بوقت. المجموعات الجديدة الافتراضية هي 24 ساعة. |
| الأيام النشطة | من الاثنين إلى الأحد. تكون المجموعة العادية غير نشطة عندما لا يتم تحديد يوم الأسبوع المحلي الحالي. |
| نوافذ الزمن | لا يوجد أي نوافذ بالتوقيت المحلي أو أكثر، واحدة لكل سطر، مكتوبة كـ HHMM-HHMM. |
| وضع التجميد | لا شيء، مجمد، تجميد صارم، أو تجميد الوالدين. |
| سياسة الغفوة | ما إذا كانت المجموعة تسمح بالتأجيل، مع عناصر التحكم في المدة/التأخير/التهدئة/التأكيد للمجموعات العادية. |
| عنوان URL الاحتياطي | يتم استخدام الوجهة إذا قامت المجموعة بحظر صفحة ما. |
| انتقل إلى التالي | عند تقديمه في المحرر، يطلب من تدفق الحجب الطبيعي تجاوز الهدف المحظور بدلاً من البقاء عليه. |

### 2.4 سلوكيات المجموعة العادية

يقدم المحرر العادي ثلاثة سلوكيات:

| السلوك | النتيجة الوظيفية |
| --- | --- |
| احظر فورًا | بمجرد أن تصبح المجموعة نشطة ومتطابقة، يصبح القرار العادي لحظر الصفحة فوريًا. |
| الحظر بعد عدة دقائق | تتراكم مطابقة وقت الصفحة المرئية مع البدل الذي تم تكوينه. عند استنفاد السعة المسموح بها، يتم حظر المجموعة العادية حتى تتم إعادة تعيين فترة استخدامها أو تصبح المجموعة غير نشطة/مؤجلة. |
| مؤقت (العد التصاعدي، بدون كتلة) | يتم تسجيل وقت الصفحة المرئية المطابق ويمكن عرضه. هذا الوضع لا يحظر أبدًا لمجرد أن مؤقته يصل إلى قيمة ما. |

يعتمد الاستخدام المحدد على وقت الصفحة المرئية. ليس المقصود منه تحصيل الوقت أثناء إخفاء الصفحة في علامة تبويب الخلفية. الفاصل الزمني لإعادة التعيين هو فاصل زمني لسياسة متجددة للمجموعة الزمنية العادية. الموقتات العادية مستقلة حسب المجموعة.

### 2.5 الجداول

تنطبق الجداول على المجموعات العادية. لا تحتوي المجموعة المخصصة على واجهة مستخدم جدولة عادية وتعتبر نشطة لأغراض JavaScript الخاصة بها؛ يجب أن تفرض القاعدة أي شرط زمني مرغوب بنفسها.

يتم تقييم سياسة اليوم النشط باستخدام التوقيت المحلي:

1. إذا لم يتم تحديد يوم الأسبوع الحالي، فستكون المجموعة العادية غير نشطة.
2. إذا لم يتم توفير أي نوافذ زمنية صالحة، فإن اليوم النشط يعني اليوم الكامل.
3. في حالة توفير نوافذ صالحة، يجب أن يكون التوقيت المحلي الحالي في نافذة واحدة على الأقل.

تحتوي كل نافذة على الشكل الدقيق HHMM-HHMM، على سبيل المثال 0900-1200. يجب أن تكون الساعات من 00 إلى 23، والدقائق من 00 إلى 59، ويجب أن تكون البداية قبل النهاية في نفس اليوم. نافذة تشمل بدايتها وتستبعد نهايتها. النوافذ المتقاطعة في منتصف الليل، مثل 2300-0100، غير صالحة. يتم تجاهل الأسطر الفارغة ويتم طي النوافذ المكررة.

### 2.6 قيلولة بعد الظهر

بالنسبة للمجموعة العادية، تعتبر الغفوة حالة غير نشطة مؤقتة تصل إلى ثلاث مراحل:

| المرحلة | النتيجة |
| --- | --- |
| في انتظار | التأجيل المطلوب موجود ولكنه لم يبدأ بسبب تأخير التنشيط. المجموعة لا تزال نشطة. |
| نشط | المجموعة غير نشطة مؤقتًا طوال مدة التأجيل. |
| فترة التهدئة | انتهت فترة التأجيل، وأصبحت المجموعة نشطة مرة أخرى، ولا يمكن بدء تأجيل آخر حتى تنتهي فترة التهدئة. |

حقول تكوين المجموعة العادية هي:

| المجال | القاعدة |
| --- | --- |
| السماح بالتأجيل | في حالة إيقاف التشغيل، لا يمكن بدء الغفوة العادية. |
| مدة الغفوة | دقائق إيجابية. مجموعة عادية جديدة تأخذ الإعداد الافتراضي العالمي، في البداية 30. |
| تأخير التنشيط | صفر دقيقة أو أكثر. فارغ يعني صفر |
| فترة التهدئة | صفر خلال خمس دقائق. فارغ يعني صفر |
| تأكيدات | عدد صحيح غير سالب. يتطلب المنتج العديد من تفاعلات التأكيد قبل منح الطلب. |

تتعامل المجموعة المخصصة مع زر الغفوة كحدث إدخال فقط. يصدر Vault الحدث المخصص المسمى snoozePress لهذه المجموعة؛ ولا يطبق الإجراء الاحتياطي العادي للمدة/التأخير/التهدئة نيابة عن القاعدة. يمكن للقاعدة المخصصة استخدام الحدث، أو استمراريته، أو لوحة، أو مؤقت، أو عدم اتخاذ أي إجراء على الإطلاق.

### 2.7 تجميد

يعمل التجميد على حماية المجموعة من تغييرات التكوين العادية ومن تغييرات التأجيل العادية. لا يؤدي اختيار وضع التجميد في المحدد إلى تجميد المجموعة من تلقاء نفسه؛ يطبق إجراء التجميد الوضع المختار.

| الوضع | العقد الوظيفي |
| --- | --- |
| مجمدة | يتم قفل المجموعة حتى يكتمل تدفق تأكيد إلغاء التجميد الطبيعي للمنتج. |
| صارمة المجمدة | لا يمكن إلغاء تجميد المجموعة إلا بعد انقضاء مدة التجميد الصارم الخاصة بها. يجب أن تكون المدة أكبر من صفر ولا تزيد عن 72 ساعة؛ مجموعة جديدة افتراضية إلى 24 ساعة. |
| الوالدين المجمدة | مطلوب كلمة مرور الوصي لإدارة التجميد/إلغاء التجميد. يستخدم مربع حوار التكوين كلمة مرور مكونة من ستة أرقام. |

لا يمكن تحرير المجموعات المجمدة من خلال الحقول العادية. قد تقوم أيضًا مجموعة مرتبطة بالجسر مع عضو غير متصل بتأمين عناصر التحكم في التجميد لأن Vault لا يمكنه تنسيق الحالة المجمدة عبر المجموعة بشكل آمن. التجميد هو حماية ضد عمليات واجهة المستخدم العادية؛ ولا يحول ملف تعريف المتصفح إلى حدود أمنية غير قابلة للتغيير.

### 2.8 الاستيراد والتصدير والمسح وإعادة التعيين

يؤدي التصدير إلى تمثيل متوافق للمجموعة المحددة. يقوم الاستيراد بالتحقق من صحة بيانات المجموعة المتوافقة وتطبيعها قبل إضافتها. يجب أن تظل أسماء المجموعات المستوردة فريدة. يؤدي حذف المجموعة إلى إزالة تلك المجموعة وحالة الاستخدام/التأجيل العادية الخاصة بها. مسح يزيل كافة المجموعات بعد التأكيد.

إعادة التعيين إلى الإعدادات الافتراضية هي عملية **الإعدادات العامة**. فهو يتجاهل التفضيلات على مستوى الامتداد؛ فهو ليس بديلاً للاستيراد/التصدير ويجب التعامل معه على أنه مدمر.

## 3. أنواع المجموعات والعقد المطابق

### 3.1 مجموعة مواقع الويب الافتراضية

تمتلك مجموعة المواقع قائمة مواقع ويب مفصولة بأسطر. يتم تسوية الإدخالات في نموذج المضيف/المجال. يتطابق إدخال المضيف مع ذلك المضيف وجميع نطاقاته الفرعية.

| الإعداد | النتيجة |
| --- | --- |
| قم بحظر كل شيء باستثناء هذه المواقع | القائمة عبارة عن قائمة حظر. تم حظر المضيف المطابق. |
| احظر كل شيء ما عدا هذه المواقع على | القائمة عبارة عن قائمة مسموح بها. يتم حظر كل مضيف غير موجود في القائمة. وبالتالي فإن القائمة المسموح بها الفارغة هي إغلاق متعمد للويب بالكامل. |
| حجب الصفحة الرئيسية | يطبق سياسة المجموعة على سطح البداية/الصفحة الرئيسية للمتصفح الذي تم تكوينه حيث يتوفر عنصر التحكم هذا. |
| عنوان URL الاحتياطي | إعادة توجيه الوجهة للكتلة. تعود قيمة المجموعة الفارغة إلى القيمة الافتراضية العامة. |

قائمة مجال مجموعة الموقع العادية هي القائمة التعريفية الوحيدة للموقع بالكامل التي يعرضها المحرر. تقوم مجموعات الأنظمة الأساسية بمطابقة النظام الأساسي الخاص بها وشروط النظام الأساسي التي تم تكوينها بدلاً من ذلك.

### 3.2 مجموعات منصات الفيديو

YouTube وTikTok وFacebook وInstagram وTwitch هي مجموعات منصات فيديو. يقتصر كل منها على مضيف النظام الأساسي الخاص به. يمكن للمجموعة استهداف نموذج المحتوى، ونطاق المؤلف/الحساب، والخلاصة الرئيسية للنظام الأساسي، وعناصر التحكم الاختيارية في إخفاء العناصر.

أوضاع المؤلف العامة هي:

| الوضع | النتيجة |
| --- | --- |
| الكل | لا تقيد من قبل المؤلف. المحاور الأخرى التي تم تكوينها تحدد المطابقة. |
| تضمين | تطابق فقط المبدعين/الحسابات التي تمت تسويتها والمدرجة. |
| استبعاد | تطابق جميع المبدعين/الحسابات التي تم اكتشافها باستثناء الإدخالات المدرجة. |
| لا أحد | لا يتطابق مع أي مؤلف. هذا محور مؤلف متعمد غير متطابق. |

| منصة | نماذج المحتوى |

### 3.6 الحقول التعريفية للمجموعة المخصصة

تقوم المجموعة المخصصة بشكل أساسي بتشغيل مصدر JavaScript الخاص بها. ولا يستخدم محدد السلوك العادي أو واجهة مستخدم الجدول العادي. ومع ذلك، يمكنه حمل قائمة النطاق عند استيرادها أو تهيئتها من خلال بيانات متوافقة:

- يمكن لقائمة الحظر المخصصة غير الفارغة أن تشارك في القرار العادي لموقع الصفحة بأكملها؛
- يمكن للقائمة المسموح بها المشاركة حتى عندما تكون فارغة، مما ينتج عنه تأمين تصريحي للويب بالكامل؛
- لا تقوم المجموعة المخصصة غير المكونة عن طريق الخطأ بحظر الصفحات لمجرد أنها تحتوي على قاعدة؛
- لا يتم حظر الموقتات المخصصة من تلقاء نفسها أبدًا؛ تقرر القاعدة صراحة ما إذا كان سيتم الحظر عند انتهاء صلاحية المؤقت أم لا.

### 4.1 واجهة المحرر وأسطح الملاحظات

يحتوي محرر الامتداد على قائمة مجموعة ثابتة ومحرر مجموعة محددة. توفر قائمة المجموعة منتقي نوع المجموعة والإضافة والمسح والتحديد وتمكين التبديل وترتيب السحب. مقسمها يمكن تغيير حجمه. يوفر محرر المجموعة المحددة حقولًا خاصة بالمجموعة وإجراءات التصدير/الاستيراد للمجموعة.

يقوم المحرر تلقائيًا بحفظ تغييرات الحقول العادية بعد فترة الارتداد العالمية. يتم الإبلاغ عن أخطاء التحقق من الصحة كملاحظات عن الحالة/التقييم المحمص؛ لا يتم تحويل القيم العادية غير الصالحة بصمت إلى إعدادات غير ذات صلة. تقوم المجموعة المجمدة بتعطيل عناصر التحكم في التحرير العادية الخاصة بها.

يحتوي الامتداد أيضًا على أسطح التعليقات المرئية للمستخدم:

| السطح | الغرض الوظيفي |
| --- | --- |
| دليل التعليمات | يفتح هذا المرجع في الامتداد. |
| منتقي اللغة | يختار لغة واجهة الامتداد. |
| الإعدادات | يفتح الإعدادات العامة الموضحة أعلاه. |
| تعليقات الحالة/النخب | يتم حفظ التقارير واستيرادها والتحقق من صحتها ونتائج الإجراء. |
| تراكب المؤقت على الصفحة | يعرض عناصر المؤقت/العد التنازلي العادية النشطة والمؤقتات المخصصة الموجودة في نطاق العرض الخاص بها. يمكن أن تتعايش عناصر متعددة. |
| سطح السجل على الصفحة | يتلقى مكالمات السجل والتحذير والخطأ المخصصة عندما تسمح الإعدادات العامة بذلك. |
| سجل مخصص | سجل نشاط مباشر للإدخالات المرئية المنبثقة التي تم إنشاؤها بواسطة القاعدة. يمكن مسحها وتنزيلها. |

بالنسبة للمجموعات المخصصة، يقوم حقل القواعد بتخزين النص المصدر. ينفذ Run first الاختبار المبدئي لبناء جملة القاعدة ويحمل المصدر فقط عندما ينجح ذلك. يقوم المحرر أيضًا بإجراء فحص المصدر المحلي مع تغير النص. يفتح عنصر التحكم **Let AI Code** المرئي حقل مطالبة وينسخ حزمة إنشاء التعليمات البرمجية التي تحتوي على طلب المستخدم والقاعدة الحالية والمرجع الذي تم إنشاؤه إلى واجهة برمجة تطبيقات القاعدة المخصصة الحالية. ولا يتصل بخدمة الذكاء الاصطناعي أو يغير القاعدة تلقائيًا.

يفتح عنصر التحكم القوالب مستعرض القالب. يحتوي القالب، عند شحنه، على عنوان ووصف وعلامات ومعلمات ومعاينة تم إنشاؤها. يؤدي تطبيقه إلى استبدال نص القواعد الحالي بعد التأكيد. كتالوج القالب الذي تم شحنه حاليًا فارغ؛ يظل المتصفح متاحًا للقوالب المنسقة المستقبلية ويجب عدم معاملته كمصدر للقواعد النشطة.

## 5. لغة القواعد المخصصة

### 5.1 نماذج مصدر القاعدة

مصدر المجموعة المخصصة هو JavaScript. في **تشغيل**، يقوم Vault بإزالة التسجيلات السابقة للمجموعة والحالة التي أنشأها المصدر النشط السابق، ثم يقوم بتحميل المصدر الجديد.

المصدر قد يكون إما:

1. a function expression accepting events and helpers; or
2. البيانات العارية التي تستخدم الأحداث المتوفرة (أو الحدث القديم) والمتغيرات المساعدة.

```js
// Function-expression form
(events, helpers) => {
  events.on("openWebEvent", "welcome", (event, h) => {
    h.log("Opened", event.url);
  });
}
```

```js
// Bare-statement form
events.on("openWebEvent", "welcome", (event, h) => {
  h.log("Opened", event.url);
});
```

يقوم Run بتنفيذ بناء جملة JavaScript/التحقق المبدئي، وفقط عندما ينجح ذلك، يجعل المصدر الحالي نشطًا. يختلف حفظ النص وتشغيل النص عن قصد: يمكن حفظ القاعدة دون أن تصبح مصدر الحدث النشط.

يتم إلغاء تحميل المصدر النشط عند إعادة تشغيل المجموعة المخصصة أو تعطيلها أو حذفها أو إيقافها بشكل صريح. تؤدي إعادة التشغيل إلى مسح معالجات القاعدة، وأجهزة ضبط الوقت، واللوحات، ومجموعة الثبات، ومسندات النظام الأساسي التي تم إنشاؤها بواسطة القاعدة قبل بدء التسجيل. يمكن لاسترداد وضع الحماية إعادة تحميل المصدر النشط؛ ولذلك يجب على واضعي القواعد جعل التسجيل غير فعال.

### 5.2 نموذج التنفيذ والافتراضات الآمنة

Custom rules are event registrations, not a continuous script loop. Register handlers during rule initialization, then respond to events.

يتلقى كل معالج:

```js
(event, helpers) => {
  // event: the currently dispatched event object
  // helpers: the public Vault Custom-rule API
}
```

معالجات الحدث يتم تشغيلها حسب الأولوية الرقمية التنازلية؛ الأولوية المتساوية تستخدم أمر التسجيل. يمكن استبدال المعالج بتسجيل نفس نوع الحدث والمعرف مرة أخرى. يوجد حد أقصى قدره 1000 معالج مسجل لمجموعة مخصصة واحدة.

يقوم Vault بتقييد العمل النشط لأحد المعالجين بحوالي ثانية واحدة. ثلاث تجاوزات للمواعيد النهائية لنفس المجموعة خلال دقيقة واحدة تعزل القاعدة: يقوم Vault بتعطيلها بدلاً من تشغيل معالج به مشكلات بشكل متكرر. لا تستخدم فترات الانتظار المزدحمة، أو الحلقات غير المحدودة، أو الاستقصاء المتزامن، أو عددًا كبيرًا من الطفرات/السجلات لكل حدث.

لكل إرسال، يقبل Vault ما يلي على الأكثر:

| العنصر | الحد الأقصى |
| --- | --- |
| إدخالات سجل القاعدة | 200 |
| الأحداث المنشورة | 64 |
| عمليات DOM | 256 |
| العمل / النوايا | 256 |
| لوحات لكل مجموعة | 24 |
| الضوابط في لوحة واحدة | 32 |
| الخيارات في التحديد/التحكم في الراديو | 64 |

قد يتم إسقاط إدخالات السجل الزائد والحدث المنشور وعمليات DOM والقصد. يجب ألا تعتمد القاعدة المخصصة على الإدخالات الزائدة التي يتم تسليمها.

### 5.3 أنواع الأحداث المضمنة

تم تضمين سلاسل نوع الحدث التالية. قد تستخدم القاعدة أيضًا سلسلة نوع غير فارغة خاصة بها، طالما أنها لا تبدأ بشرطة سفلية.

| نوع الحدث | عندما يتم إرساله | بيانات مهمة |
| --- | --- | --- |
| حدث القراد | القراد الدوري المشترك في إعداد معدل القراد العالمي. | سياق الصفحة/علامة التبويب الحالية حيثما كان ذلك متاحًا. استخدم خيار تسجيل InterMs لتحديد معدل المعالج الفردي. |
| حدث ويب مفتوح | تصبح صفحة المستوى الأعلى متاحة للقاعدة. | عنوان URL، اسم المضيف، معرفات علامة التبويب/الصفحة، الوقت. |
| CloseWebEvent | يتم إغلاق الصفحة/علامة التبويب ذات المستوى الأعلى. | سياق عنوان URL/اسم المضيف حيثما كان ذلك متاحًا. |
| webChangedEvent | تنقل مخصص عالي المستوى، بما في ذلك عمليات إعادة تحميل عنوان URL نفسه. | تحمل البيانات عنوان URL/اسم المضيف وعلامات التنقل السابقة مثل isFirstLoad وisReload وsameDomain. |
| انتهى الموقت | يتغير المؤقت المخصص إلى حالته منتهية الصلاحية. | البيانات: timerId، اسم العرض، الاتجاه، currentMs. يتم تسليمه فقط إلى المجموعة المالكة للمؤقت. |
| غفوة اضغط | يقوم المستخدم بالضغط على Start Snooze لهذه المجموعة المخصصة. | القاعدة تملك الرد؛ لا يتم إجراء أي تراجع طبيعي للغفوة. |
| حدث اللوحة | تحتوي اللوحة المخصصة المقدمة على تفاعل. | تتضمن حقول البيانات والملاءمة معلومات اللوحة/التحكم/الحدث/القيمة. |
| حدث الملف المحلي | اكتمل إجراء الملف المحلي المطلوب. | تتضمن حقول البيانات والراحة معرف الطلب والمسار والنتيجة والبايتات والإدخالات والخطأ. |
| صفحة نبضات القلبالحدث | نبضات مرئية للصفحة، كل 250 مللي ثانية تقريبًا أثناء ظهور علامة التبويب. | المنقضي هو الوقت المنقضي للصفحة المرئية. تستخدم أجهزة ضبط الوقت المخصصة ذات النطاق تلقائيًا حتى بدون معالج مسجل. |

### 5.4 واجهة برمجة تطبيقات تسجيل الأحداث

الوسيطة الأولى لمصدر نمط الوظيفة هي سجل الأحداث. في مصدر البيان المجرد، تشير كل من الأحداث والأحداث إلى هذا السجل.

| الطريقة | العقد |
| --- | --- |
| events.on(type, id, handler, options) | Register a handler. Returns true when accepted, false for invalid/capped registrations. |
| events.register(type, id, handler, options) | Alias of on. |
| events.off(type, id) | Unregister a handler. Returns whether something was removed. |
| events.unregister(type, id) | Alias of off. |
| events.unregisterAll(type) | Remove all handlers owned by this group for that event type. Returns the number removed. |
| events.getEvent(type, id) | Return the registered function for this group/id, or null. |
| events.getEvents(type) | Return an object mapping this group's handler ids to functions. |
| events.countRegistered(type) | Return this group's number of registrations for type. |
| events.emit(type, data, options) | Queue a synthetic event. |
| events.post(type, data, options) | Alias of emit. |

يدعم كائن خيارات المعالج الاختياري:

| الخيار | معنى |
| --- | --- |
| الأولوية | ترتيب رقمي. يتم تشغيل القيم الأعلى قبل القيم الأقل. الافتراضي 0. |
| الفاصل الزمني | رقم إيجابي. بالنسبة لـticEvent فقط، يتم منع المكالمات حتى انقضاء هذا الوقت الطويل منذ المكالمة السابقة للمعالج. |

يتم تعيين الأحداث الاصطناعية بشكل افتراضي على نطاق المجموعة: فقط المعالجات التي تنتمي إلى مجموعة الإرسال هي التي تستقبلها. استخدم { النطاق: "عالمي" } لإرسال الحدث إلى كل قاعدة سجلت نفس النوع. لا تستخدم الشرطة السفلية في اسم الحدث؛ إنه محجوز.

### 5.5 كائن الحدث

| المجال/الطريقة | العقد |
| --- | --- |

| معرف علامة التبويب، معرف الصفحة | معرفات المتصفح عندما تكون متاحة؛ وإلا فارغة. |
| عنوان URL، اسم المضيف | عنوان URL للمستوى الأعلى الحالي واسم المضيف، أو السلاسل الفارغة. |
| الوقت | نسخة من كائن وقت الإرسال، أو فارغة. |
| البيانات | الحمولة الخاصة بالحدث، أو فارغة. |
| منع الافتراضي () | وضع علامة على الإرسال كإجراء حظر الصفحة. تتم إعادة توجيه الصفحة إلى رابط/نتيجة إعادة التوجيه الحالية في حالة وجودها؛ وإلا فإن Vault يستخدم مسار الخروج/الاحتياطي العادي. |
| توقف الانتشار () | إيقاف المعالجات اللاحقة لإرسال الحدث الحالي. |
| setResult(value) | يخزن رقمًا أو نتيجة سلسلة. يتم التعامل مع السلسلة غير الفارغة كهدف إعادة توجيه؛ النتيجة 1 تمنع نتيجة منع افتراضية متراكمة. |
| الحصول على النتيجة () | إرجاع النتيجة التي تم تعيينها بواسطة كائن الحدث هذا، أو إرجاعها فارغة. |
| منشور (النوع، البيانات، الخيارات) | قم بوضع حدث اصطناعي في قائمة الانتظار، بنفس قواعد النطاق مثل Events.post. |
| setRedirectLink(url) | قم بتعيين عنوان URL لإعادة التوجيه لهذا الإرسال. إرجاع خطأ فقط للإدخال غير السلسلة. |

| إغلاق (المعرف) | طلب إغلاق علامة التبويب. الرقم هو معرف علامة تبويب، وتعرف السلسلة عنوان URL، وتستهدف القيمة المحذوفة علامة التبويب النشطة. |

يمكن للمعالج إرفاق خصائص إضافية عشوائية بالحدث. اقرأها من خلال events.custom أو مباشرة من خلال الاسم المخصص أثناء وجود كائن الحدث هذا. إنها ليست حالة مستمرة ولا يتم تخزينها عبر الأحداث.

تعمل أنماط الكتل التي تم إنشاؤها بواسطة القاعدة على تطبيع http/https، وwww.، والمسارات في نمط مضيف. أنها تطابق المضيف والنطاقات الفرعية بالضبط. قائمة الحظر الديناميكية هذه هي ذاكرة الجلسة، وليست مجموعة مواقع عادية محفوظة.

### 6.8 مساعد مجلد الملفات المحلي

## 8. وصفات عمل القواعد المخصصة

الأمثلة التالية هي مواصفات التكوين العام، وليس البرنامج التعليمي.

### 8.1 إعادة توجيه الصفحة الافتتاحية

```js
(events, helpers) => {
  events.on("openWebEvent", "redirect-distracting-search", (event, h) => {
    const domain = h.getDomainHelper();
    if (!domain.isSearchPage(event.url)) return;
    event.setRedirectLink(h.getRedirectionHelper().createMessageUrl("Return to your planned task."));
    event.preventDefault();
  });
}
```

### 8.2 العد التنازلي للوقت المرئي مع حظر واضح

```js
(events, helpers) => {
  const timer = helpers.getTimerHelper();
  timer.create({
    id: "reading-budget",
    displayName: "Reading budget",
    direction: "backward",
    currentMs: 10 * 60 * 1000,
    scope: (url) => url.includes("example.com")
  });

  events.on("timerEnded", "stop-at-zero", (event) => {
    if (event.data?.timerId !== "reading-budget") return;
    event.setRedirectLink("about:blank");
    event.preventDefault();
  });
}
```

### 8.3 تغيير مسند الخلاصة من اللوحة

```js
(events, helpers) => {
  const panel = helpers.getPanelHelper();
  const youtube = helpers.platform("youtube");

  panel.create({
    id: "feed-filter",
    title: "Feed filter",
    controls: [{
      id: "hide-sponsored",
      type: "toggle",
      label: "Hide sponsored items",
      value: true,
      onChange: (event, h) => {
        const api = h.platform("youtube");
        if (event.value) {
          api.hide("videos", (item) => item?.sponsored === true);
        } else {
          api.show("videos");
        }
        api.rescan();
      }
    }]
  });

  youtube.hide("shorts", () => true);
}
```

يجب كتابة المسندات لقيم لقطة/عنصر النظام الأساسي التي يوفرها سطح النظام الأساسي النشط. إذا لم يتمكن النظام الأساسي من تحديد الحقل بشكل موثوق، فيجب أن يفشل المسند في الفتح بدلاً من افتراض أن القيمة صحيحة.

## 9. بروتوكول طلب المجلد المحلي

عمليات المجلد المحلي ليست إدخال/إخراج ملف فوري. التسلسل الوظيفي الكامل هو:

1. يقوم المستخدم بتحديد مجلد في الإعدادات العامة.
2. تقوم القاعدة بوضع الطلب في قائمة الانتظار وتتلقى معرف الطلب.
3. يطلب Vault من المجلد المعتمد إمكانية إجراء العملية.
4. يرسل Vault localFileEvent إلى نفس المجموعة المخصصة.
5. يربط المعالج events.requestId بمعرف الطلب الأصلي.

تكتمل القراءة الناجحة بنص الملفات النصية أو قيمة JSON. قائمة ترجع الإدخالات. موجود عوائد موجود. كتابة/إلحاق يوفر بايت حيثما ينطبق ذلك. الفشل يوفر الخطأ والخطأ. يجب ألا تفترض القواعد أبدًا أن المجلد المحدد يظل مصرحًا به بعد إعادة التحميل أو إعادة تشغيل المتصفح أو إلغاء الإذن.

## 10. دلالات السلامة والفشل في القواعد المخصصة

### 10.1 أخطاء التجميع والتشغيل

تحقق من فشل تجميع تقارير بناء الجملة. يمكن للتشغيل أيضًا الإبلاغ عن خطأ في وقت التشغيل أثناء التسجيل. إذا كان المصدر الشبيه بالوظيفة به خطأ في بناء الجملة، فلن يتراجع Vault بصمت إلى التعامل معه باعتباره عبارات مجردة غير ضارة.

المصدر الفارغ لا يحتوي على معالجات. إنها صالحة كقاعدة مخصصة غير نشطة، ولكنها لا تنفذ أي إجراء مخصص تم تكوينه.

### 10.2 أخطاء المعالج

يتم عزل الاستثناء من معالج واحد عن إرسال الحدث الإجمالي. إنه مخرج تشخيصي؛ فهو لا يجعل المعالجات اللاحقة تنجح بطريقة سحرية. استخدم معالجات ضيقة وسجل الأخطاء القابلة للتنفيذ.

### 10.3 الحجر الصحي

يمكن لـ Vault عزل مجموعة مخصصة بعد تجاوز الموعد النهائي المتكرر أو التجاوز أثناء التسجيل. يقوم العزل بتعطيل المجموعة وتسجيل سبب الإجهاض الخاص بها. قم بتصحيح المصدر وحفظه وتشغيله مرة أخرى بشكل صريح لاستعادة التسجيلات النشطة.

### 10.4 حدود المتصفح/الصفحة

لا تتلقى أي قاعدة مخصصة واجهات برمجة تطبيقات ملحقة غير مقيدة. على وجه الخصوص:

- لا يمكن لمحدد DOM العثور على أي شيء على النظام الأساسي الذي تم تغييره؛
- يظل التنقل وإغلاق علامة التبويب وإجراءات الشاشة خاضعة لإمكانيات المتصفح؛
- لا يمكن للامتداد فتح التطبيقات الأصلية؛
- تتطلب عمليات المجلد المحلي وجود مجلد منحه المستخدم وأنواع الملفات المدعومة؛
- لا يمكن لمعالج الحدث الاعتماد على صفحة غير مرئية تستمر في إنتاج نبضات مرئية في الوقت المناسب؛
- يمكن إعادة تحميل الصفحة أو التنقل فيها أو تجاهلها أو إبطال نص المحتوى النصي بشكل مستقل عن القاعدة؛
- كتل الموقع الديناميكية التي تم إنشاؤها بواسطة القاعدة هي إجراءات حالة الجلسة، وليست تعديلات دائمة لمجموعة الموقع.

## 11. جسر تطبيق الويب

الجسر اختياري. فهو يقوم بتوصيل عميل ملحق المتصفح بمركز Vault محلي متوافق. امتداد المتصفح هو عميل؛ يوفر تطبيق Vault الأصلي المحور. نقطة النهاية المحلية الثابتة هي ws://127.0.0.1:8787 ويلزم توافق البروتوكول.

حالات الاتصال هي "إيقاف"، و"متصل"، و"منقطع الاتصال"، و"متصل"، و"خطأ". مع تمكين العميل، يقوم Vault أولاً بالتحقق بسرعة ثم يستمر في محاولات إعادة الاتصال الأبطأ حتى يتم الاتصال أو يقوم المستخدم بإيقاف تشغيله. لا يقوم الاتصال بحد ذاته بدمج كافة المجموعات.

### 11.1 ربط المجموعات

تكون المجموعات قابلة للربط فقط عندما يتطابق اسمها ونوعها وتكون مؤهلة للربط. يقوم المستخدم باختيار/ربط البرامج المشاركة بشكل صريح. تشكل المجموعة المرتبطة كتلة. يؤدي قطع الاتصال إلى ترك بيانات المجموعة المحلية سليمة؛ فإنه يتوقف عن المزامنة المباشرة.

يقوم الجسر بمزامنة سياسة العددية المشتركة للمجموعات المرتبطة المدعومة، بما في ذلك وضع الحظر العادي، وقيم السماح/إعادة التعيين، وإعدادات التأجيل، والأيام/النوافذ النشطة، وحالة/اختيار/مدة التجميد، وسياسة الصفحة الرئيسية، وإعداد القائمة المسموح بها، وعنوان URL الاحتياطي، وسياسة التخطي إلى التالي. كما أنه ينسق الاستخدام وحالة التأجيل لأعضاء المجموعة.

لا يعد الجسر بأن كل حقل خاص بالمنتج، أو محدد النظام الأساسي، أو نص المصدر المخصص، أو الإمكانية الخاصة بالمتصفح قابلة للتحويل إلى برنامج مختلف. يمكن أن تظل المجموعة محلية وغير مرتبطة حتى أثناء اتصال الجسر.

تتطلب مجموعات الجسور المجمدة أن يكون جميع الأعضاء المعنيين متصلين بالإنترنت لإجراءات حالة التجميد التي تحتاج إلى طفرة منسقة. الاتصال هو نقل محلي، وليس نسخة احتياطية سحابية أو قناة تحكم عن بعد.

## 12. قائمة التحقق للمشرفين

استخدم قائمة التحقق هذه عند تدقيق إصدار أو إعادة إنتاج السلوك:

1. تأكد من أن المجموعة لها اسم فريد غير فارغ، ونوع صحيح، وحالة ممكّنة، والقائمة/الترتيب المقصود.
2. بالنسبة للمجموعات العادية، قم بتأكيد أيام الأسبوع النشطة، ونافذة التوقيت المحلي الصالحة، وعدم وجود قيلولة بعد الظهر النشطة، وحالة التحرير غير المجمدة.
3. بالنسبة لمجموعة مواقع، اختبر المضيف الدقيق والنطاق الفرعي و(للقائمة المسموح بها) مضيفًا خارج القائمة.
4. بالنسبة لمجموعة النظام الأساسي، قم باختبار المطابقة على مستوى الصفحة بشكل منفصل، ومطابقة العنصر/البطاقة المستهدفة، ووضع المؤلف، ووضع نموذج المحتوى، وكل إخفاء سطحي ممكّن.
5. بالنسبة للمجموعات العادية المحددة بوقت، تحقق من استحقاق الصفحة المرئية، وانتهاء الصلاحية المسموح بها أو السلوك غير المحظور للعد التصاعدي، وإعادة تعيين الفاصل الزمني.
6. بالنسبة للقواعد المخصصة، قم بتشغيل فحص بناء الجملة، وتشغيل، وفحص عدد/سجلات المعالج، واختبار كل حدث مدمج مسجل، ثم اختبار إعادة التحميل/التنقل.
7. اختبر كل مؤقت مخصص عند حدود النطاق وعند الصفر؛ تحقق من أن أي كتلة صريحة في القاعدة.
8. اختبار اللوحات مع كل قيمة تحكم، وحالة تعطيل، وإجراء إرسال/إلغاء/إغلاق، ومعالج أحداث اللوحة.
9. اختبر فشل المجلد المحلي قبل النجاح: لا يوجد مجلد محدد، إذن تم إبطاله، مسار غير صالح، امتداد غير مدعوم، ثم تم التصريح بالقراءة/الكتابة.
10. اختبار إيقاف تشغيل الجسر، وبدء الاتصال، والمجموعة المرتبطة/غير المرتبطة، وعضو المجموعة غير المتصل قبل الاعتماد على المزامنة أو تجميد التنسيق.

## 13. قاعدة الإصدار

هذا الملف الإنجليزي هو دليل المصدر الذي تمت صيانته. الأدلة المترجمة هي ترجمات لها وقد تتطلب التجديد بعد تحديث الوثائق الوظيفية. يظل مصدر المنتج هو الحقيقة الأساسية للغموض على مستوى التنفيذ.
