# Vault 브라우저 확장 프로그램 사용자 설명서

Vault는 설치된 브라우저 프로필에서 웹사이트와 지원되는 플랫폼 콘텐츠를 제어합니다. 확장 프로그램 도구 모음 버튼으로 편집기를 여세요. 연결되면 Mac Vault 또는 Windows Vault가 로컬 태그 지정과 활동 기록을 제공하고, 확장 프로그램은 브라우저 대상을 적용합니다.

## 차단 그룹

**차단 그룹**은 차단 정책을 적용합니다. **분류기 그룹**은 콘텐츠에 태그를 지정하며, 그 자체로는 차단하지 않습니다.

1. 차단 그룹을 추가하고 이름을 지정하세요.
2. **적용 대상**에서 대상을 선택하세요.
3. 차단을 적용할 시점을 선택하고 일정이나 시간 할당량을 설정하세요.
4. 그룹을 활성화하세요. 대상에는 그룹 정책이 적용됩니다.

일반적인 편집은 자동으로 저장됩니다. 오류가 나면 편집이 승인되지 않은 것이므로 필드를 수정하고 다시 시도하세요. 설정은 유지하면서 정책을 멈추려면 그룹을 비활성화하세요. **그룹 삭제**는 그룹을 제거합니다. 그룹을 끌어 순서를 바꾸세요. 한 대상에 여러 그룹이 적용될 수 있으며, 하나를 잠시 미뤄도 다른 그룹의 차단은 해제되지 않습니다.

**내보내기**는 그룹 구성을 복사합니다. **가져오기**는 확인 후 선택한 그룹의 구성을 바꿉니다.

### 시간 할당량 및 일정

**즉시 차단**은 활성 그룹이 대상과 일치하고 일정이 활성일 때 적용됩니다. **시간 할당량을 다 쓰면 차단**은 할당량이 소진될 때까지 일치하는 사용을 허용합니다.

할당량은 분 단위, 재설정 간격은 시간 단위로 설정하세요. 롤링 한도는 직전 창의 사용량을 셉니다. 자정 재설정은 롤링 한도도 포함해 현지 시각 자정에 새 기간을 시작합니다.

활성 요일과 선택적 현지 시간 창을 한 줄에 하나씩 선택하세요(예: **09:00-12:00**). 창 목록이 비어 있으면 선택한 요일 전체에 적용됩니다. 창은 같은 날 시작 시각보다 늦게 끝나야 합니다. 밤을 넘기는 일정은 날짜별로 나누세요.

### 잠시 미루기

각 차단 그룹에서 미루기를 설정하세요. **차단 일시 중지**는 해당 그룹의 정책을 지정한 시간 동안 중단합니다. **시간 할당량에 추가**는 시간 제한 그룹에 사용할 수 있는 분을 더합니다. 실제로 사용한 추가 할당량만 미룬 시간에 포함됩니다. 사용하지 않은 추가 할당량은 다음 재설정 때 만료됩니다. 롤링 한도에서는 한 창 뒤에, 설정에 따라 자정에 더 일찍 만료됩니다.

**활성화 지연** 중에는 차단이 계속되고 미루기가 늦게 시작됩니다. **대기시간**은 미루기가 끝난 뒤 다음 요청 전까지 기다리는 시간입니다. **필요한 확인 횟수**는 확인 단계 수를 지정합니다. 그룹 동결 전에 허용한 경우에만 동결된 그룹에서 미루기를 사용할 수 있습니다.

### 편집 잠금과 PIN

**동결**은 일반 편집을 막습니다. 해제하려면 5초 간격으로 10회 확인하고, 설정된 대기 시간 및 6자리 PIN이 있다면 입력해야 합니다. **해제 전 대기**는 0~72시간입니다. 0은 추가 대기가 없다는 뜻입니다.

동결된 동안 대기 시간을 늘리고 PIN이 없다면 추가할 수 있습니다. 그룹을 해제할 때까지 이 조건을 완화할 수 없습니다. 삭제에도 남은 대기 시간과 PIN이 적용됩니다.

### 연결된 그룹

**연결**을 사용하면 다른 Vault 프로그램에서 명시적으로 선택한 그룹을 이어 줍니다. 연결된 그룹은 이름, 지원되는 정책 설정, 대상, 사용량, 동결 조건을 공유합니다. 각 프로그램은 지원하는 대상 유형을 편집하고 적용하며, 다른 대상 항목은 연결된 프로그램에서 사용할 수 있습니다. 연결을 해제해도 그룹과 설정은 유지됩니다.

연결된 구성원이 오프라인이면 편집할 수 없을 수 있습니다. 다시 연결하려면 데스크톱 Vault 앱과 연결된 브라우저를 여세요. 구성원이 오프라인이어도 로컬에 저장된 정책은 계속 적용될 수 있습니다.

## 도움말 보기

필드 옆의 작은 **i**를 클릭하면 설명을 볼 수 있습니다. 바깥을 클릭하거나 Escape를 눌러 닫으세요. 목록은 스크롤 가능한 상자 안에 있습니다. 더 보려면 상자 안을 스크롤하세요. 검색은 항목을 삭제하지 않고 보이는 목록만 필터링합니다.

사용자 지정 규칙에는 별도의 [코드 설명서](../code-manual/ko.md)가 있습니다. 편집기, 활성화, 로그, 파일 접근, 지원되는 API를 설명합니다.

## 웹사이트와 플랫폼 콘텐츠

도메인이나 전체 URL을 항목마다 하나씩 추가하세요. 도메인에는 하위 도메인도 포함됩니다. 경로는 해당 경로와 하위 경로로 일치를 제한합니다. **이 사이트 외에는 모두 차단**하면 목록이 허용 목록으로 바뀝니다.

같은 웹사이트를 여러 번 추가할 수 있습니다. 항목마다 필터와 페이지 제어가 따로 있습니다. 예를 들어 한 YouTube 항목은 Shorts를 차단하고 다른 항목은 특정 크리에이터를 차단할 수 있습니다. 일치하는 항목은 그룹 안에서 결합되며 일정, 할당량, 미루기를 공유합니다.

대상은 일치하는 페이지를 덮거나 먼저 멈춘 뒤 카운트다운 후 계속하기를 제공할 수 있습니다. 같은 그룹에서는 차단 대상이 일시 중지 대상보다 우선합니다. **차단 시: 리디렉션 주소 또는 메시지**에는 웹 주소나 덮개 메시지를 입력하세요. 페이지를 그 자리에서 덮으려면 비워 두세요. 일시 중지는 리디렉션하지 않습니다.

플랫폼 대상은 동영상 플랫폼에 **크리에이터**, Twitter / X에 **계정**, Reddit에 **커뮤니티**, Discord에 서버/채널 ID를 사용합니다. Vault가 출처와 콘텐츠 유형을 식별할 수 있을 때 제어가 적용됩니다. 콘텐츠 제어는 광고나 동영상 카드처럼 지원되는 페이지 요소를 숨깁니다. 브라우저 권한과 웹사이트 변경이 영향을 줄 수 있습니다.

### 콘텐츠 태그 필터

분류기 연결과 태그 수정은 Chrome, Edge 같은 지원 Chromium 브라우저와 macOS의 Safari Vault에서 사용할 수 있습니다.

태그를 가져오려면 Mac Vault 또는 Windows Vault를 연결하고 분류기를 설정하세요. 차단 그룹의 태그 필터는 무엇을 덮거나 숨길지 선택합니다. 태그 지정을 시작하거나 멈추지는 않습니다. 데스크톱 앱의 분류기 설정이나 각 분류기 그룹의 일시 중지 제어를 사용하세요.

각 웹사이트 항목에는 **적용 대상** 필터가 하나 있습니다. 전체 콘텐츠, 선택한 크리에이터, 선택한 크리에이터 제외, 선택한 태그, 선택한 태그 제외 중에서 고릅니다. 다른 필터가 필요하면 같은 웹사이트 항목을 하나 더 추가하세요.

특정 태그 또는 특정 태그를 제외한 전체를 선택하세요. 규칙은 태그를 결합하거나(**Gaming + Drama**), 신뢰도를 요구하거나(**Gaming @3**), 예외를 둘 수 있습니다(**!Tutorial**). **콘텐츠 덮기**는 태그 수정을 계속 사용할 수 있게 합니다. **콘텐츠 숨기기**는 일치하는 항목을 제거합니다.

**확실한 태그가 없는 콘텐츠도 차단**은 기본 신뢰도 기준에서 태그 없이 완료된 결과를 포함하며, 신뢰도가 낮은 결과도 해당됩니다. 명시적으로 나열한 규칙을 먼저 확인합니다. **태그 없음**은 태그 지정이 끝났고 태그가 없다는 뜻이며, **태그 지정 중**은 결과가 대기 중이라는 뜻입니다. 별도의 대기 중 콘텐츠 옵션이 태그 지정이 끝날 때까지 항목을 덮을지 제어합니다.

### 태그 수정

항목 태그 옆의 **+ 태그**를 클릭해 수정 선택기를 여세요. 분류기의 기존 태그를 검색해 추가할 태그를 고릅니다. 선택된 태그의 제거 제어를 클릭하거나 태그를 선택하고 Delete를 한 번 눌러 제거하세요. 수정은 연결된 데스크톱 앱으로 전송되어 향후 태그 지정에 쓰입니다. 조회할 수 없으면 **태그 없음**으로 표시되고 자동 재시도될 수 있습니다. 이 표시는 분류기에 태그를 만들지 않습니다.

## 설정과 연결

**빠른 추가 + 표시**는 지원 페이지에 작은 버튼을 추가합니다. 목록에서 대상 그룹을 선택하세요. Vault를 다시 열어도 선택이 기억됩니다. 페이지 버튼으로 해당 페이지를 웹사이트 목록에 추가하세요. 허용 목록에서는 페이지가 허용됩니다. 동결된 그룹에는 빠르게 추가할 수 없습니다.

공식 사전 및 개인 사전 가져오기/내보내기는 데스크톱 앱의 **설정 → 분류기 → 공식 사전**에서 설정합니다. 캐시에서 찾지 못하거나 선택적 크리에이터 기여가 켜져 있으면 사전 서비스에 연결될 수 있습니다. 웹 리서치에는 별도의 동의와 제공자 설정이 있습니다. 데스크톱 설명서와 공개 안내를 확인하세요.

분류기 연결은 로컬 데스크톱 Vault 서비스를 나타냅니다. 연결된 데스크톱 앱에서 분류기 그룹, 모델 다운로드, 지식, 조사 동의, API 제공자를 설정하세요.

태그가 없으면 데스크톱 Vault 앱이 열려 있는지, 연결되었는지, 태그 지정이 활성화되었는지, 해당 분류기 그룹이 재개되었는지, 플랫폼 피드가 기록되는지 확인하세요. 앱에서 모델 다운로드 상태도 확인하세요. 차단이 적용되지 않으면 그룹 활성화, 대상, 일정, 할당량, 미루기 상태를 확인하세요.
