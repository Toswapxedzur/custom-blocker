# Vault 浏览器扩展用户手册

Vault 控制安装它的浏览器配置文件中的网站和受支持的平台内容。点击扩展的工具栏按钮打开编辑器。连接 Mac Vault 或 Windows Vault 后，桌面应用提供本地打标和活动记录；扩展负责执行浏览器目标的屏蔽规则。

## 屏蔽组

**屏蔽组**执行屏蔽策略。**分类器组**为内容分配标签，本身不会屏蔽任何内容。

1. 添加屏蔽组并为其命名。
2. 在**应用于**中选择目标。
3. 选择屏蔽生效的条件，再设置时间安排或可用时长。
4. 启用该组。它的目标共用该组的策略。

常规修改会自动保存。出现错误说明修改未被接受；请纠正字段后重试。停用组会停止执行策略，但保留配置。**删除组**会将其移除。拖动组可调整顺序。多个组可以同时应用于同一目标；暂缓其中一个组不会解除其他组的屏蔽。

**导出**复制组的配置。**导入**会在确认后替换所选组的配置。

### 可用时长和时间安排

**立即屏蔽**会在已启用的组匹配目标且处于生效时间内时执行屏蔽。**可用时长用尽后屏蔽**允许先使用匹配的目标，直至可用时长耗尽。

可用时长以分钟设置，重置间隔以小时设置。滚动限制统计最近一个时间窗口内的使用。午夜重置会在本地午夜开始新周期，也适用于滚动限制。

选择生效的星期几，并可添加本地时间段，每行一个，例如 **09:00-12:00**。时间段列表为空时，在所选日期全天生效。同一日期的结束时间必须晚于开始时间；跨夜安排需拆分到不同日期。

### 暂缓

在每个屏蔽组中配置暂缓。**暂停屏蔽**会在指定时长内暂停该组的策略。**增加可用时长**为有时间限制的组增加可使用的分钟数。只有实际消耗的额外时长才计入暂缓使用时间。未用完的额外时长在下次重置时失效；使用滚动限制时，在一个窗口后失效，若启用了午夜重置，也可能更早失效。

**启动延迟**会推迟暂缓生效，等待期间仍执行屏蔽。**冷却时间**是一次暂缓结束后，再次请求暂缓前必须等待的时间。**所需确认次数**设置确认步骤的数量。冻结组只有在冻结前允许暂缓，才能使用暂缓。

### 冻结和 PIN

**冻结**会阻止常规修改。解冻需要进行十次确认，每次间隔五秒，并满足已设置的等待时长和六位 PIN 条件。**解冻前等待**接受 0–72 小时；0 表示不增加等待时间。

冻结期间可以延长等待时间，也可以在尚未设置 PIN 时添加 PIN。解冻前不能减弱这些条件。删除同样受剩余等待时间和 PIN 限制。

### 关联组

使用**关联**连接其他 Vault 程序中明确选定的组。关联组共享名称、受支持的策略设置、目标、使用量和冻结条件。每个程序编辑并执行它支持的目标类型；其他目标条目仍保留供关联程序使用。解除关联后，各组及其设置都会保留。

若关联成员离线，可能无法编辑。打开桌面 Vault 应用和关联的浏览器以重新连接。成员离线时，本地已保存的策略仍可能继续执行。

## 获取帮助

点击字段旁的小 **i** 查看说明。点击外部或按 Escape 关闭说明。列表位于可滚动的区域中；滚动列表可查看其他条目。搜索只筛选显示的条目，不会删除条目。

自定义规则有单独的[代码手册](../code-manual/zh.md)，介绍编辑器、规则启用、日志、文件访问和受支持的 API。

## 网站和平台内容

添加域名或完整 URL，每个地址作为独立条目。域名匹配包括其子域名。带路径的地址只匹配该路径及其下级路径。**屏蔽除此之外的所有网站**将列表用作允许列表。

同一网站可以添加多次。每个条目有自己的筛选条件和页面控制；例如，一个 YouTube 条目屏蔽 Shorts，另一个屏蔽某位创作者。组内匹配条目共同生效，并共用时间安排、可用时长和暂缓设置。

目标可以直接覆盖匹配页面，也可以先暂停，在倒计时结束后提供“继续”按钮。同一组中，直接屏蔽的目标优先于暂停目标。**屏蔽时：重定向地址或消息**接受网页地址或覆盖消息；留空时就地覆盖页面。暂停模式不会重定向。

视频平台的目标使用**创作者**，Twitter / X 使用**账号**，Reddit 使用**社区**，Discord 使用服务器或频道 ID。控制项在 Vault 能识别来源和内容类型的位置生效。内容控制可以隐藏受支持的页面元素，例如广告或视频卡片。浏览器权限和网站改版可能影响这些控制。

### 内容标签筛选

分类器连接和标签纠正适用于受支持的 Chromium 浏览器（例如 Chrome 和 Edge），以及 macOS 上的 Safari Vault。

连接 Mac Vault 或 Windows Vault，并配置其分类器以获得标签。屏蔽组的标签筛选决定覆盖或隐藏哪些内容，不负责启动或暂停打标；请使用桌面应用的分类器设置，或单个分类器组的暂停控制。

每个网站条目只有一个**应用于**筛选：所有内容、所选创作者、所选创作者以外的内容、所选标签，或所选标签以外的内容。需要不同筛选条件时，为同一网站添加另一个条目。

可选择某些标签，或除这些标签之外的所有内容。规则可以组合标签（**游戏 + 剧情**）、要求置信度（**游戏 @3**），或添加例外（**!教程**）。**覆盖内容**仍允许纠正标签；**隐藏内容**会移除匹配的条目。

**也屏蔽没有可信标签的内容**包括已完成但在默认置信度阈值下没有标签的结果，也包括低置信度结果。明确列出的规则会先被检查。**未标记**表示打标已完成但没有标签；**正在打标**表示仍在等待结果。独立的待处理内容选项决定是否在打标完成前覆盖内容。

### 纠正标签

点击内容标签旁的 **+ 标签**打开纠正选择器。搜索分类器中已有的标签，并选择要添加的标签。点击已选标签的移除控件，或选中它后按一次 Delete，即可移除。纠正结果会发送到已连接的桌面应用，并用于后续打标。查询不可用时显示**未标记**，之后可自动重试；这个显示不会在分类器中创建标签。

## 设置和连接

**显示快速添加 +**会在受支持的页面上显示一个小按钮。在列表中选择目标组；Vault 下次打开时会记住该选择。使用页面按钮将当前页面添加到该组的网站列表。若该组使用允许列表，添加即允许访问该页面。冻结组不接受快速添加。

分类器连接状态反映本地桌面 Vault 服务的连接情况。在已连接的桌面应用中配置分类器组、模型下载、知识、研究授权和 API 提供商。

若没有显示标签，请检查桌面 Vault 应用是否已打开、是否已连接、是否启用了打标、相关分类器组是否已恢复，以及是否记录了该平台的内容。模型下载状态可在桌面应用中查看。若屏蔽未生效，请检查组的启用状态、目标、时间安排、可用时长和暂缓状态。
