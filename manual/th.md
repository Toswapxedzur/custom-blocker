# การอ้างอิงฟังก์ชันส่วนขยายของห้องนิรภัย

## วัตถุประสงค์และสถานะ

นี่คือข้อกำหนดการทำงานที่เชื่อถือได้สำหรับส่วนขยายเบราว์เซอร์ห้องนิรภัย โดยจะบันทึกสัญญาผลิตภัณฑ์: ข้อมูลที่ผู้ใช้สามารถกำหนดค่าได้ ลักษณะการทำงานที่แน่นอนที่การกำหนดค่าสร้างขึ้น ภาษาของกฎที่กำหนดเองแบบสาธารณะ และขีดจำกัดที่ใช้กับสัญญาดังกล่าว

นี่ไม่ใช่คู่มือเริ่มต้นใช้งานโดยเจตนา บทช่วยสอนเว็บไซต์เป็นเส้นทางการเรียนรู้ เอกสารนี้มีไว้สำหรับผู้ที่ต้องการกำหนดค่า ทดสอบ บำรุงรักษา ตรวจสอบ หรือจำลองลักษณะการทำงานที่ผู้ใช้มองเห็นได้ของห้องนิรภัย

รหัสถือเป็นความจริงที่ยอมรับได้เมื่อเอกสารนี้และผลิตภัณฑ์ไม่ตรงกัน ชื่อในเอกสารนี้ใช้คำศัพท์ที่จัดเก็บ/สาธารณะของผลิตภัณฑ์ในกรณีที่ใช้งานได้จริง คำว่า "returns" หมายถึงค่าที่ส่งคืนที่มีให้กับกฎที่กำหนดเอง จะไม่รับประกันผลลัพธ์ระดับเบราว์เซอร์หากเบราว์เซอร์หรือเพจปฏิเสธการดำเนินการที่ร้องขอ

## 1.ขอบเขตสินค้า

ห้องนิรภัยเป็น WebExtension ที่ควบคุมโฟกัส หน่วยของการกำหนดค่าคือ **กลุ่มบล็อก** กลุ่มสามารถ:

- ตัดสินใจว่าควรบล็อกเว็บไซต์ ระดับบนสุด หน้าแพลตฟอร์ม ผู้สร้าง ชุมชน เซิร์ฟเวอร์ ช่อง หรือบัญชี
- ซ่อนพื้นผิวแพลตฟอร์มที่กำหนดค่าไว้หรือการ์ดฟีดที่ตรงกัน
- วัดเวลาที่ใช้ในขอบเขตที่ตรงกัน
- ใช้ตารางเวลา การป้องกันการหยุดนิ่ง หรือการเลื่อนชั่วคราวในกรณีที่กลุ่มประเภทนั้นรองรับ
- รันกฎ JavaScript แบบกำหนดเองด้วย Event API
- แสดงตัวจับเวลาบนเพจ แผง ข้อความ หรือบันทึกเพจ
- เปลี่ยนเส้นทาง นำทาง ปิดแท็บเบราว์เซอร์ หรือรักษารายการบล็อกไซต์ที่สร้างกฎเฉพาะเซสชัน
- เลือกที่จะเข้าร่วมในคลัสเตอร์ Vault Bridge ที่เชื่อมต่อภายในเครื่อง

ห้องนิรภัยจะดำเนินการเฉพาะภายในโปรไฟล์เบราว์เซอร์ที่ติดตั้งและเฉพาะในกรณีที่เบราว์เซอร์อนุญาตให้สคริปต์เนื้อหาทำงานเท่านั้น มันไม่ได้:

- ติดตั้งแอปพลิเคชันเนทิฟหรือส่วนขยายเบราว์เซอร์
- บล็อกแอปพลิเคชันระบบปฏิบัติการ
- ข้ามการแจ้งเตือนการอนุญาตเบราว์เซอร์ ข้อจำกัดการท่องเว็บแบบส่วนตัว หรือรูปแบบความปลอดภัยของเว็บไซต์เอง
- รับประกันการซ่อนตามตัวเลือกเมื่อแพลตฟอร์มบุคคลที่สามเปลี่ยน DOM
- ทำให้สถานะกฎที่กำหนดเองสามารถพกพาข้ามโปรไฟล์ได้ เว้นแต่ผู้ใช้จะส่งออก/กำหนดค่าแยกกัน
- จัดเตรียมไฟร์วอลล์เครือข่าย พร็อกซี การควบคุมบัญชี หรือบริการตรวจสอบโดยผู้ปกครอง

คำศัพท์ต่อไปนี้ใช้ตลอด:

| ระยะเวลา | ความหมาย |
| --- | --- |
| กลุ่ม | ออบเจ็กต์การกำหนดค่าที่มีชื่ออย่างอิสระหนึ่งรายการ ชื่อจะต้องไม่ซ้ำกันภายในส่วนขยาย โดยไม่สนใจตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ |
| กลุ่มไซต์ | กลุ่มปกติที่มีรายการโดเมนเป็นเงื่อนไขการจับคู่หลัก |
| กลุ่มแพลตฟอร์ม | กลุ่มปกติสำหรับ YouTube, TikTok, Facebook, Instagram, Twitch, Reddit, Discord หรือ Twitter/X โดยเฉพาะ |
| กลุ่มที่กำหนดเอง | กลุ่มที่เป็นเจ้าของกฎ JavaScript และการลงทะเบียนกิจกรรม กฎของมันตัดสินพฤติกรรมของมัน |
| แมตช์ | หน้า รายการฟีด หรือพื้นผิวแพลตฟอร์มเป็นไปตามเงื่อนไขที่กำหนดค่าไว้ของกลุ่ม |
| ใช้งานอยู่ | เปิดใช้งานกลุ่มแล้ว มีสิทธิ์ตามกำหนดการ และไม่ได้ปิดเสียงเตือนชั่วคราว กลุ่มที่กำหนดเองไม่ได้อยู่ภายใต้ UI กำหนดการปกติ |
| บล็อก | ป้องกันไม่ให้เพจระดับบนสุดปัจจุบันใช้งานได้ตามปกติโดยการเปลี่ยนเส้นทางไปยังเป้าหมายสำรอง |
| ซ่อน | ลบหรือปกปิดองค์ประกอบ/การ์ดในหน้าที่แสดงผลในปัจจุบัน การซ่อนไม่ใช่การบล็อกเครือข่าย |
| URL ทางเลือก | เป้าหมายการเปลี่ยนเส้นทางเฉพาะกลุ่ม หากเว้นว่างไว้ ระบบจะใช้ทางเลือกส่วนกลาง |
| อนุญาต/ข้อยกเว้น | คำตัดสินของการ์ดแพลตฟอร์มที่ช่วยจับคู่เนื้อหาจากกฎการซ่อนที่มีลำดับความสำคัญต่ำกว่า ไม่ใช่รายการที่อนุญาตของเว็บไซต์ทั่วไป |

## 2. รูปแบบกลุ่มและวงจรชีวิตทั่วไป

ทุกกลุ่มที่จัดเก็บจะมีรหัสคงที่ ชื่อ ประเภท ธงที่เปิดใช้งาน และช่องนโยบายทั่วไป กลุ่มปกติใหม่จะถูกเปิดใช้งานตามค่าเริ่มต้น สามารถเลือกกลุ่ม บันทึกตามพฤติกรรมการบันทึกอัตโนมัติของตัวแก้ไข เรียงลำดับใหม่ ส่งออก นำเข้า แช่แข็ง เลิกแช่แข็ง เลื่อน ปิดใช้งาน หรือลบได้

### 2.1 การเรียงลำดับและการทับซ้อนกัน

มากกว่าหนึ่งกลุ่มสามารถจับคู่หน้าเดียวกันได้ ห้องนิรภัยจะประเมินกลุ่มที่จัดเก็บตั้งแต่ส่วนท้ายของรายการที่แสดงไปจนถึงจุดเริ่มต้น ถือว่ารายการที่ต่ำกว่าในรายการเป็นแบบที่มีลำดับความสำคัญภายหลัง/สูงกว่าเมื่อออกแบบกฎที่ทับซ้อนกัน

สำหรับการบล็อกไซต์ระดับบนสุดทั่วไป กลุ่มการบล็อกที่เกี่ยวข้องสามารถทำให้เพจใช้งานไม่ได้ สำหรับการกรองการ์ดฟีด แพลตฟอร์มคาสเคดจะใช้ลำดับและเอฟเฟกต์ของแต่ละกลุ่มที่ตรงกัน: การอนุญาต/ข้อยกเว้นในการจับคู่ในภายหลังสามารถช่วยรายการจากเพรดิเคตการบล็อกที่มีลำดับความสำคัญต่ำกว่าได้ พฤติกรรมข้อยกเว้นนี้จำกัดอยู่ที่พื้นผิวการกรองการ์ดแพลตฟอร์ม มันไม่ได้เลิกทำการบล็อกไซต์ทั้งหน้าตามปกติ

### 2.2 สถานะเปิดใช้งาน

กลุ่มที่พิการจะยังคงอยู่ แต่จะไม่เข้าร่วมในการจับคู่ปกติ ตัวจับเวลา ตารางเวลา หรือการเลื่อนการปลุกตามปกติ การปิดใช้งานกลุ่มแบบกำหนดเองจะเป็นการยกเลิกการโหลดการลงทะเบียนที่ใช้งานอยู่ด้วย การเปิดใช้งานใหม่จะไม่เปลี่ยนข้อความที่ไม่ได้บันทึกให้เป็นกฎแบบกำหนดเองที่ใช้งานอยู่ เรียกใช้กฎเพื่อโหลดแหล่งที่บันทึกไว้

### 2.3 ช่องทั่วไป

| สนาม | ความหมายและข้อจำกัด |
| --- | --- |
| ชื่อ | ไม่ว่างเปล่า ตัดขอบ และไม่คำนึงถึงตัวพิมพ์เล็กและตัวพิมพ์ใหญ่ภายในจุดสิ้นสุดนี้ บริดจ์ยังระบุกลุ่มที่ลิงก์ได้ตามชื่อและประเภท ดังนั้นชื่อที่เสถียรจึงมีความสำคัญ |
| เปิดใช้งาน | เปิดหรือปิดการจับคู่ปกติ |
| พฤติกรรม | บล็อกทันที บล็อกหลังจากอนุญาต หรือจับเวลา/นับถอยหลัง กลุ่มที่กำหนดเองใช้กฎของตัวเองแทนที่จะใช้ตัวเลือกการทำงานปกตินี้ |
| นาทีที่อนุญาต | จำนวนบวกที่ใช้โดยพฤติกรรมบล็อคหลังค่าเผื่อ กลุ่มใหม่เริ่มต้นที่ 15 นาที |
| รีเซ็ตช่วงเวลาเป็นชั่วโมง | จำนวนบวกที่ใช้โดยกลุ่มปกติแบบกำหนดเวลา กลุ่มใหม่จะมีค่าเริ่มต้นเป็น 24 ชั่วโมง |
| วันที่ใช้งาน | วันจันทร์ถึงวันอาทิตย์ กลุ่มปกติจะไม่ใช้งานเมื่อไม่ได้เลือกวันทำงานในท้องถิ่นปัจจุบัน |
| หน้าต่างเวลา | กรอบเวลาท้องถิ่นเป็นศูนย์หรือมากกว่า หนึ่งกรอบเวลาต่อบรรทัด เขียนเป็น HHMM-HHMM |
| โหมดหยุดนิ่ง | ไม่มี, แช่แข็ง, แช่แข็งแบบเข้มงวด หรือ แช่แข็งโดยผู้ปกครอง |
| นโยบายการเลื่อนการแจ้งเตือน | ไม่ว่ากลุ่มจะอนุญาตให้เลื่อนปลุกหรือไม่ โดยมีการควบคุมระยะเวลา/ดีเลย์/คูลดาวน์/ยืนยันสำหรับกลุ่มปกติ |
| URL ทางเลือก | ปลายทางที่ใช้หากกลุ่มบล็อกเพจ |
| ข้ามไปถัดไป | เมื่อระบุไว้ในโปรแกรมแก้ไข ให้ขอให้โฟลว์การบล็อกปกติเคลื่อนผ่านเป้าหมายที่ถูกบล็อก แทนที่จะคงอยู่บนเป้าหมายนั้น |

### 2.4 พฤติกรรมกลุ่มปกติ

โปรแกรมแก้ไขปกติเสนอลักษณะการทำงานสามประการ:

| พฤติกรรม | ผลลัพธ์การทำงาน |
| --- | --- |
| บล็อกทันที | เมื่อกลุ่มเปิดใช้งานและตรงกัน การตัดสินใจบล็อกหน้าปกติจะเกิดขึ้นทันที |
| บล็อกหลังจากผ่านไปหลายนาที | การจับคู่เวลาหน้าที่มองเห็นได้จะสะสมตามค่าเผื่อที่กำหนดไว้ เมื่อค่าเผื่อหมดลง กลุ่มปกติจะบล็อกจนกว่าจะรีเซ็ตระยะเวลาการใช้งาน หรือกลุ่มไม่ได้ใช้งาน/เลื่อนปลุก |
| จับเวลา (นับถอยหลัง ไม่มีการบล็อก) | เวลาหน้าที่มองเห็นตรงกันจะถูกบันทึกและสามารถแสดงได้ โหมดนี้จะไม่บล็อกเพียงเพราะตัวจับเวลาถึงค่า |

การใช้งานแบบกำหนดเวลาจะขึ้นอยู่กับเวลาหน้าที่มองเห็นได้ ไม่ได้มีไว้เพื่อชาร์จเวลาในขณะที่เพจถูกซ่อนอยู่ในแท็บพื้นหลัง ช่วงเวลาการรีเซ็ตคือช่วงนโยบายแบบต่อเนื่องสำหรับกลุ่มที่ตั้งเวลาตามปกติ ตัวจับเวลาปกติจะเป็นอิสระจากกลุ่ม

### 2.5 กำหนดการ

กำหนดการใช้กับกลุ่มปกติ กลุ่มที่กำหนดเองไม่มี UI กำหนดการปกติ และถือว่าใช้งานอยู่ตามวัตถุประสงค์ของ JavaScript กฎจะต้องกำหนดเงื่อนไขเวลาที่ต้องการเอง

นโยบายวันใช้งานได้รับการประเมินโดยใช้เวลาท้องถิ่น:

1. หากไม่ได้เลือกวันทำงานปัจจุบัน กลุ่มปกติจะไม่ใช้งาน
2. หากไม่มีการระบุกรอบเวลาที่ถูกต้อง วันที่ใช้งานอยู่หมายถึงเต็มวัน
3. หากมีการระบุหน้าต่างที่ถูกต้อง เวลาท้องถิ่นปัจจุบันจะต้องอยู่ในหน้าต่างอย่างน้อยหนึ่งหน้าต่าง

แต่ละหน้าต่างจะมีรูปแบบ HHMM-HHMM เหมือนกัน เช่น 0900-1200 ชั่วโมงต้องเป็น 00 ถึง 23 นาที 00 ถึง 59 และการเริ่มต้นจะต้องอยู่ก่อนสิ้นสุดในวันเดียวกัน หน้าต่างรวมจุดเริ่มต้นและไม่รวมจุดสิ้นสุด กรอบเวลาข้ามเวลาเที่ยงคืน เช่น 2300-0100 ไม่ถูกต้อง บรรทัดว่างจะถูกละเว้น และหน้าต่างที่ซ้ำกันจะถูกยุบ

| เฟส | ผลลัพธ์ |
| --- | --- |
| รอดำเนินการ | มีการเลื่อนการปลุกตามที่ร้องขอแต่ยังไม่ได้เริ่มเนื่องจากความล่าช้าในการเปิดใช้งาน กลุ่มยังคงใช้งานอยู่ |
| ใช้งานอยู่ | กลุ่มนี้ไม่ได้ใช้งานชั่วคราวเนื่องจากมีการเลื่อนการเตือน |
| คูลดาวน์ | การงีบหลับสิ้นสุดลง กลุ่มกลับมาทำงานอีกครั้ง และการเลื่อนอีกครั้งไม่สามารถเริ่มได้จนกว่าคูลดาวน์จะหมดลง |

ฟิลด์การกำหนดค่ากลุ่มปกติคือ:

| สนาม | กฎ |
| --- | --- |
| อนุญาตให้เลื่อน | หากปิด จะไม่สามารถเริ่มการเลื่อนปลุกแบบปกติได้ |
| ระยะเวลาเลื่อน | นาทีที่เป็นบวก กลุ่ม New Normal ใช้ค่าเริ่มต้นทั่วโลก เริ่มแรก 30. |
| การเปิดใช้งานล่าช้า | ศูนย์หรือมากกว่านาที ว่างเปล่าหมายถึงศูนย์ |
| คูลดาวน์ | เป็นศูนย์ถึงห้านาที ว่างเปล่าหมายถึงศูนย์ |
| การยืนยัน | จำนวนเต็มที่ไม่เป็นลบ ผลิตภัณฑ์ต้องมีการโต้ตอบการยืนยันหลายครั้งก่อนที่จะอนุมัติคำขอ |

กลุ่มแบบกำหนดเองจะถือว่าปุ่มเลื่อนเป็นเหตุการณ์อินพุตเท่านั้น ห้องนิรภัยจะปล่อยเหตุการณ์แบบกำหนดเองชื่อ snoozePress สำหรับกลุ่มนั้น โดยจะไม่ใช้ระยะเวลา/ดีเลย์/คูลดาวน์ปกติในนามของกฎ กฎที่กำหนดเองสามารถใช้เหตุการณ์ ความคงอยู่ของมันเอง แผง ตัวจับเวลา หรือไม่ดำเนินการใดๆ เลย

### 2.7 หยุดนิ่ง

การแช่แข็งจะปกป้องกลุ่มจากการเปลี่ยนแปลงการกำหนดค่าตามปกติและจากการเปลี่ยนแปลงการเลื่อนซ้ำตามปกติ การเลือกโหมดหยุดในตัวเลือกจะไม่หยุดกลุ่มด้วยตัวเอง การดำเนินการหยุดจะใช้โหมดที่เลือก

| โหมด | สัญญาการทำงาน |
| --- | --- |
| แช่แข็ง | กลุ่มจะถูกล็อคจนกว่าขั้นตอนการยืนยันการละลายปกติของผลิตภัณฑ์จะเสร็จสิ้น |
| แช่แข็งอย่างเข้มงวด | ไม่สามารถยกเลิกการตรึงกลุ่มได้จนกว่าระยะเวลาการตรึงแบบเข้มงวดจะหมดลง ระยะเวลาต้องมากกว่าศูนย์และไม่เกิน 72 ชั่วโมง กลุ่มใหม่จะมีค่าเริ่มต้นเป็น 24 ชั่วโมง |
| ผู้ปกครองถูกระงับ | ต้องใช้รหัสผ่านผู้ปกครองสำหรับการจัดการการแช่แข็ง/ยกเลิกการตรึง กล่องโต้ตอบการกำหนดค่าใช้รหัสผ่านหกหลัก |

กลุ่มที่ตรึงไว้ไม่สามารถแก้ไขได้ผ่านช่องธรรมดา คลัสเตอร์ที่เชื่อมโยงกับบริดจ์ที่มีสมาชิกออฟไลน์อาจล็อกการควบคุมการหยุดการทำงานเนื่องจากห้องนิรภัยไม่สามารถประสานสถานะที่หยุดการทำงานทั่วทั้งคลัสเตอร์ได้อย่างปลอดภัย การตรึงคือการป้องกันการทำงานของ UI ปกติ มันไม่ได้เปลี่ยนโปรไฟล์เบราว์เซอร์ให้เป็นขอบเขตความปลอดภัยที่ไม่เปลี่ยนรูป

### 2.8 นำเข้า ส่งออก ล้าง และรีเซ็ต

การส่งออกจะสร้างการแสดงที่เข้ากันได้ของกลุ่มที่เลือก นำเข้าตรวจสอบและปรับข้อมูลกลุ่มที่เข้ากันได้ให้เป็นมาตรฐานก่อนที่จะเพิ่ม ชื่อกลุ่มที่นำเข้าจะต้องไม่ซ้ำกัน กลุ่มลบจะลบกลุ่มนั้นและสถานะการใช้งาน/การเลื่อนตามปกติออก ล้างลบกลุ่มทั้งหมดหลังจากการยืนยัน

การรีเซ็ตเป็นค่าเริ่มต้นคือการดำเนินการ **การตั้งค่าส่วนกลาง** มันจะละทิ้งการตั้งค่าส่วนขยายทั้ง ไม่ใช่สิ่งทดแทนการนำเข้า/ส่งออก และควรถือเป็นการทำลายล้าง

## 3. ประเภทกลุ่มและสัญญาที่ตรงกัน

### 3.1 กลุ่มเว็บไซต์เริ่มต้น

กลุ่มไซต์เป็นเจ้าของรายการเว็บไซต์ที่แยกบรรทัด รายการจะถูกทำให้เป็นมาตรฐานในรูปแบบโฮสต์/โดเมน รายการโฮสต์ตรงกับโฮสต์นั้นและโดเมนย่อยทั้งหมด

| การตั้งค่า | ผลลัพธ์ |
| --- | --- |
| บล็อกทุกอย่างยกเว้นไซต์เหล่านี้ปิด | รายการนี้เป็นรายการบล็อก โฮสต์ที่ตรงกันถูกบล็อก |
| บล็อกทุกอย่างยกเว้นไซต์เหล่านี้บน | รายการนี้เป็นรายการที่อนุญาต ทุกโฮสต์ที่ไม่อยู่ในรายการจะถูกบล็อก รายการที่อนุญาตที่ว่างเปล่าจึงถือเป็นการปิดเว็บโดยเจตนา |
| บล็อกหน้าแรก | ใช้นโยบายของกลุ่มกับพื้นผิวเริ่มต้น/หน้าแรกของเบราว์เซอร์ที่กำหนดค่าซึ่งมีการควบคุมนั้น |
| URL ทางเลือก | เปลี่ยนเส้นทางปลายทางสำหรับบล็อก ค่ากลุ่มว่างจะกลับไปเป็นค่าเริ่มต้นส่วนกลาง |

รายการโดเมนกลุ่มไซต์ปกติเป็นเพียงรายการเดียวที่ประกาศทั้งไซต์ที่เปิดเผยโดยผู้แก้ไข กลุ่มแพลตฟอร์มจะตรงกับแพลตฟอร์มของตนเองและเงื่อนไขของแพลตฟอร์มที่กำหนดค่าไว้แทน

### 3.2 กลุ่มแพลตฟอร์มวิดีโอ

YouTube, TikTok, Facebook, Instagram และ Twitch เป็นกลุ่มแพลตฟอร์มวิดีโอ แต่ละอันถูกจำกัดไว้สำหรับโฮสต์แพลตฟอร์มของตัวเอง กลุ่มสามารถกำหนดเป้าหมายรูปแบบเนื้อหา ขอบเขตผู้เขียน/บัญชี ฟีดหลักของแพลตฟอร์ม และตัวเลือกการควบคุมองค์ประกอบซ่อน

โหมดผู้เขียนทั่วไปคือ:

| โหมด | ผลลัพธ์ |
| --- | --- |
| ทั้งหมด | อย่าจำกัดโดยผู้เขียน แกนที่กำหนดค่าไว้อื่นจะตัดสินการแข่งขัน |
| รวม | จับคู่เฉพาะผู้สร้าง/บัญชีมาตรฐานที่ระบุไว้เท่านั้น |
| ไม่รวม | จับคู่ผู้สร้าง/บัญชีที่ตรวจพบทั้งหมด ยกเว้นรายการที่อยู่ในรายการ |
| ไม่มีใคร | ไม่ตรงกับผู้แต่ง นี่เป็นแกนผู้เขียนที่ไม่ตรงกันโดยเจตนา |
| แท็กรวม | จับคู่ผู้สร้างกับแท็กที่อยู่ในรายการเมื่อห้องนิรภัยสามารถจัดประเภทพวกเขาได้ ผู้สร้างที่ไม่รู้จัก/ไม่จำแนกประเภทไม่สามารถเปิดได้ |
| แท็กไม่รวม | จับคู่ผู้สร้างที่ไม่มีแท็กที่กำหนดค่าไว้เมื่อห้องนิรภัยสามารถจัดหมวดหมู่ได้ ผู้สร้างที่ไม่รู้จัก/ไม่จำแนกประเภทไม่สามารถเปิดได้ |

ตัวเลือกรูปแบบเนื้อหาเป็นแบบเฉพาะแพลตฟอร์ม:

| แพลตฟอร์ม | แบบฟอร์มเนื้อหา |
| --- | --- |
| ยูทูป | ทุกหน้า, สั้น, วีดีโอยาว, โพสต์ |
| ติ๊กต๊อก | ทุกหน้าวิดีโอสั้น ๆ |
| เฟสบุ๊ค | ทุกเพจ ม้วน วิดีโอ โพสต์ |
| อินสตาแกรม | ทุกเพจ ม้วน วิดีโอ โพสต์ |
| กระตุก | ทุกหน้า คลิป สตรีม/VOD หน้าช่อง |

ห้องนิรภัยทำให้การป้อนข้อมูลของผู้เขียนเป็นมาตรฐาน ผู้แก้ไขยอมรับรูปแบบการจัดการ/ช่อง/หน้าธรรมดาของแพลตฟอร์ม และ URL โปรไฟล์ที่รองรับ อาจปฏิเสธรายการที่มีรูปแบบไม่ถูกต้องหรือแสดงว่าไม่ถูกต้อง แทนที่จะเปลี่ยนรายการเหล่านั้นให้กลายเป็นเป้าหมายอื่นโดยไม่แจ้งให้ทราบ

ตัวเลือกการซ่อนพื้นผิวไม่ขึ้นอยู่กับการบล็อกระดับบนสุด สิ่งเหล่านี้มีผลเฉพาะกับ UI แพลตฟอร์มปัจจุบันและสามารถหยุดทำงานเมื่อแพลตฟอร์มเปลี่ยนมาร์กอัป

| แพลตฟอร์ม | จัดส่งตัวเลือกองค์ประกอบซ่อนแล้ว |
| --- | --- |
| ยูทูป | การไปยังส่วนต่างๆ ของ Shorts/ชั้นวาง/การ์ด การโปรโมตฟีดหน้าแรก/ส่วนแสดงโฆษณา และความคิดเห็น ตัวเลือกที่เกี่ยวข้องกับโฆษณาจะแสดงคำเตือนเนื่องจากการซ่อนโฆษณาอาจขัดแย้งกับข้อกำหนดของแพลตฟอร์ม |
| ติ๊กต๊อก | สำรวจการนำทาง |
| เฟสบุ๊ค | การนำทางวงล้อและพื้นผิววงล้อ |
| อินสตาแกรม | ม้วนและสำรวจการนำทาง/พื้นผิว |
| กระตุก | เรียกดูการนำทาง |

การจับคู่แท็กผู้สร้างของ YouTube ใช้การจัดหมวดหมู่ช่องในท้องถิ่น/ที่มีอยู่ การจำแนกประเภทที่ขาดหายไปไม่ได้กลายเป็นบล็อกเพียงเพราะว่าโหมดแท็กถูกเลือก

### 3.3 เรดดิท

กลุ่ม Reddit ใช้กับ Reddit เท่านั้น เอนทิตีของมันคือ subreddit ข้อมูล Subreddit ยอมรับรูปแบบชุมชนทั่วไปและทำให้เป็นมาตรฐานก่อนการจับคู่

โหมดย่อยของ Reddit คือ:

| โหมด | ผลลัพธ์ |
| --- | --- |
| ทั้งหมด | นำไปใช้กับ Reddit โดยไม่มีข้อจำกัดรายการ subreddit |
| รวม | นำไปใช้กับ subreddits ที่ระบุไว้ |
| ไม่รวม | นำไปใช้กับทั้งหมดยกเว้น subreddits ที่ระบุไว้ |
| ไม่มีใคร | นำไปใช้กับไม่มี subreddit |

ตัวเลือกซ่อนพื้นผิวที่จัดส่งจะซ่อนการนำทางยอดนิยม/ทั้งหมด พฤติกรรมของฟีดการ์ดขึ้นอยู่กับโครงสร้างการ์ดที่ตรวจพบได้ในปัจจุบันของ Reddit

### 3.4 ความไม่ลงรอยกัน

กลุ่ม Discord ใช้กับหน้า Discord/Discordapp เท่านั้น เป้าหมายคือรหัสเซิร์ฟเวอร์หรือคู่เซิร์ฟเวอร์/ช่องสัญญาณ เครื่องมือแก้ไขเป้าหมายยอมรับค่าเส้นทางช่องสัญญาณ Discord ที่เป็นมาตรฐาน

| โหมด | ผลลัพธ์ |
| --- | --- |
| ทั้งหมด | นำไปใช้กับ Discord โดยไม่มีข้อจำกัดรายการเป้าหมาย |
| รวม | ใช้กับเซิร์ฟเวอร์ที่ระบุไว้หรือเป้าหมายเซิร์ฟเวอร์/ช่องเท่านั้น |
| ไม่รวม | ใช้กับทั้งหมดยกเว้นเป้าหมายที่ระบุไว้ |
| ไม่มีใคร | ใช้กับไม่มีเป้าหมาย |

ขณะนี้ Discord ไม่มีตัวเลือกองค์ประกอบซ่อนที่จัดส่งในโปรไฟล์แพลตฟอร์มปกติ

### 3.5 ทวิตเตอร์ / X

กลุ่ม Twitter/X ใช้กับ X/Twitter สามารถใช้กับทุกบัญชีหรือใช้โหมดบัญชีทั่วไปที่อธิบายไว้สำหรับแพลตฟอร์มวิดีโอ โดยมีอินพุตแฮนเดิล/ลิงก์โปรไฟล์แบบมาตรฐาน

ตัวเลือกองค์ประกอบซ่อนที่จัดส่งได้แก่ Explore, Messages, Grok, Trends และรายการฟีดที่โปรโมต เช่นเดียวกับการควบคุมพื้นผิวตามตัวเลือกทั้งหมด การเปลี่ยนแปลงมาร์กอัป X อาจส่งผลต่อการทำงานของตัวควบคุมเหล่านั้น

### 3.6 ช่องประกาศกลุ่มที่กำหนดเอง

กลุ่มแบบกำหนดเองจะเรียกใช้ซอร์ส JavaScript เป็นหลัก ไม่ได้ใช้ตัวเลือกพฤติกรรมปกติหรือ UI กำหนดการปกติ อย่างไรก็ตาม ยังสามารถพกพารายการโดเมนได้เมื่อนำเข้าหรือกำหนดค่าผ่านข้อมูลที่เข้ากันได้:

- รายการบล็อกที่กำหนดเองที่ไม่ว่างเปล่าสามารถมีส่วนร่วมในการตัดสินใจเกี่ยวกับเว็บไซต์ทั้งหน้าตามปกติได้
- รายการที่อนุญาตแบบกำหนดเองสามารถเข้าร่วมได้แม้ว่าจะว่างเปล่า ทำให้เกิดการล็อคการประกาศทางเว็บแบบเต็ม
- กลุ่มแบบกำหนดเองที่ไม่ได้กำหนดค่าไม่ได้บล็อกเพจโดยไม่ได้ตั้งใจเพียงเพราะมีกฎ
- ตัวจับเวลาแบบกำหนดเองจะไม่บล็อกด้วยตัวเอง กฎจะตัดสินใจอย่างชัดเจนว่าจะบล็อกเมื่อตัวจับเวลาหมดอายุหรือไม่

### 4.1 อินเทอร์เฟซตัวแก้ไขและพื้นผิวคำติชม

ตัวแก้ไขส่วนขยายมีรายการกลุ่มถาวรและตัวแก้ไขกลุ่มที่เลือก รายการกลุ่มมีเครื่องมือเลือกประเภทกลุ่ม เพิ่ม ล้าง การเลือก เปิดใช้งานสลับ และลากลำดับ ตัวแบ่งสามารถปรับขนาดได้ ตัวแก้ไขกลุ่มที่เลือกจะระบุฟิลด์เฉพาะกลุ่มและการดำเนินการส่งออก/นำเข้าของกลุ่ม

ตัวแก้ไขจะบันทึกการเปลี่ยนแปลงฟิลด์ปกติโดยอัตโนมัติหลังจากช่วง debounce ทั่วโลก ข้อผิดพลาดในการตรวจสอบความถูกต้องจะถูกรายงานเป็นสถานะ/ข้อเสนอแนะแบบขนมปังปิ้ง ค่าปกติที่ไม่ถูกต้องจะไม่ถูกแปลงเป็นการตั้งค่าที่ไม่เกี่ยวข้องอย่างเงียบๆ กลุ่มที่ถูกแช่แข็งจะปิดใช้งานการควบคุมการแก้ไขแบบปกติ

ส่วนขยายยังมีส่วนตอบรับที่ผู้ใช้มองเห็นได้เหล่านี้:

| พื้นผิว | วัตถุประสงค์การใช้งาน |
| --- | --- |
| คู่มือการใช้งาน | เปิดการอ้างอิงนี้ในส่วนขยาย |
| เครื่องมือเลือกภาษา | เลือกภาษาอินเทอร์เฟซส่วนขยาย |
| การตั้งค่า | เปิดการตั้งค่าส่วนกลางที่อธิบายไว้ข้างต้น |
| สถานะ/คำติชมของขนมปังปิ้ง | รายงานผลการบันทึก นำเข้า การตรวจสอบ และการดำเนินการ |
| การซ้อนทับตัวจับเวลาบนหน้า | แสดงรายการตัวจับเวลา/นับถอยหลังปกติที่ใช้งานอยู่ และตัวจับเวลาแบบกำหนดเองที่อยู่ในขอบเขตการแสดงผล สามารถอยู่ร่วมกันได้หลายรายการ |
| พื้นผิวบันทึกบนหน้า | รับบันทึกที่กำหนดเอง คำเตือน และการเรียกข้อผิดพลาดเมื่อได้รับอนุญาตจากการตั้งค่าส่วนกลาง |
| บันทึกที่กำหนดเอง | บันทึกกิจกรรมสดสำหรับรายการป๊อปอัปที่สร้างโดยกฎ สามารถเคลียร์และดาวน์โหลดได้ |

สำหรับกลุ่มแบบกำหนดเอง ช่องกฎจะจัดเก็บข้อความต้นฉบับ เรียกใช้ก่อน ดำเนินการ preflight ไวยากรณ์ของกฎ และโหลดแหล่งที่มาเมื่อดำเนินการสำเร็จเท่านั้น ตัวแก้ไขยังดำเนินการ Lining ต้นฉบับในเครื่องเมื่อมีการเปลี่ยนแปลงข้อความ การควบคุม **ให้ AI Code** ที่มองเห็นได้จะเปิดช่องพร้อมต์และคัดลอกชุดการสร้างโค้ดที่มีคำขอของผู้ใช้ กฎปัจจุบัน และการอ้างอิงที่สร้างขึ้นไปยัง API กฎที่กำหนดเองปัจจุบัน ไม่ติดต่อกับบริการ AI หรือเปลี่ยนกฎโดยอัตโนมัติ

ตัวควบคุมเทมเพลตจะเปิดเบราว์เซอร์เทมเพลต เมื่อมีการจัดส่งเทมเพลต จะมีชื่อ คำอธิบาย แท็ก พารามิเตอร์ และการแสดงตัวอย่างที่สร้างขึ้น การใช้จะแทนที่ข้อความกฎปัจจุบันหลังจากการยืนยัน แค็ตตาล็อกเทมเพลตที่จัดส่งในปัจจุบันว่างเปล่า เบราว์เซอร์จะยังคงใช้งานได้สำหรับเทมเพลตที่ได้รับการดูแลจัดการในอนาคต และจะต้องไม่ถือเป็นแหล่งที่มาของกฎที่ใช้งานอยู่

## 5. ภาษากฎที่กำหนดเอง

### 5.1 แบบฟอร์มแหล่งที่มาของกฎ

แหล่งที่มาของกลุ่มที่กำหนดเองคือ JavaScript ใน **เรียกใช้** ห้องนิรภัยจะลบการลงทะเบียนก่อนหน้าของกลุ่มและสถานะที่สร้างโดยแหล่งที่มาที่ใช้งานอยู่ก่อนหน้า จากนั้นจึงโหลดแหล่งที่มาใหม่

แหล่งที่มาอาจเป็น:

1. a function expression accepting events and helpers; or
2. คำสั่งเปล่าที่ใช้เหตุการณ์ที่ให้มา (หรือเหตุการณ์เดิม) และตัวแปรตัวช่วย

```js
// Function-expression form
(events, helpers) => {
  events.on("openWebEvent", "welcome", (event, h) => {
    h.log("Opened", event.url);
  });
}
```

```js
// Bare-statement form
events.on("openWebEvent", "welcome", (event, h) => {
  h.log("Opened", event.url);
});
```

Run ดำเนินการตรวจสอบไวยากรณ์ JavaScript/preflight และเมื่อดำเนินการสำเร็จเท่านั้น จะทำให้แหล่งที่มาปัจจุบันแอ็คทีฟ การบันทึกข้อความและข้อความที่กำลังรันอยู่นั้นแตกต่างกันโดยเจตนา กล่าวคือ สามารถบันทึกกฎได้โดยไม่ต้องกลายเป็นแหล่งที่มาของเหตุการณ์ที่ใช้งานอยู่

แหล่งที่มาที่ใช้งานอยู่จะถูกยกเลิกการโหลดเมื่อมีการเรียกใช้กลุ่มแบบกำหนดเองอีกครั้ง ปิดใช้งาน ลบ หรือหยุดทำงานอย่างชัดเจน การรันซ้ำจะล้างตัวจัดการกฎ ตัวจับเวลา แผง บัคเก็ตการคงอยู่ และเพรดิเคตแพลตฟอร์มที่สร้างกฎก่อนที่จะเริ่มการลงทะเบียน การกู้คืนแซนด์บ็อกซ์สามารถรีโหลดซอร์สที่ใช้งานอยู่ได้ ผู้เขียนกฎจึงต้องทำการลงทะเบียน idempotent

### 5.2 รูปแบบการดำเนินการและสมมติฐานที่ปลอดภัย

Custom rules are event registrations, not a continuous script loop. Register handlers during rule initialization, then respond to events.

ตัวจัดการแต่ละคนจะได้รับ:

```js
(event, helpers) => {
  // event: the currently dispatched event object
  // helpers: the public Vault Custom-rule API
}
```

ตัวจัดการสำหรับเหตุการณ์ที่รันโดยลำดับความสำคัญเป็นตัวเลขจากมากไปหาน้อย ลำดับความสำคัญเท่ากันใช้ลำดับการลงทะเบียน คุณสามารถแทนที่ตัวจัดการได้โดยการลงทะเบียนประเภทเหตุการณ์และรหัสเดียวกันอีกครั้ง มีตัวจัดการที่ลงทะเบียนไว้สูงสุด 1,000 ตัวสำหรับกลุ่มแบบกำหนดเองหนึ่งกลุ่ม

ห้องนิรภัยจะจำกัดงานที่ใช้งานอยู่ของตัวจัดการหนึ่งรายไว้ประมาณหนึ่งวินาที กลุ่มเดียวกันเกินกำหนดเวลาสามครั้งภายในหนึ่งนาทีเพื่อกักกันกฎ: ห้องนิรภัยจะปิดใช้กฎแทนที่จะเรียกใช้ตัวจัดการที่มีปัญหาซ้ำๆ อย่าใช้การรอที่ไม่ว่าง การวนซ้ำที่ไม่จำกัด การโพลแบบซิงโครนัส หรือการเปลี่ยนแปลง/บันทึกจำนวนมากต่อเหตุการณ์

ต่อการจัดส่ง ห้องนิรภัยจะยอมรับสิ่งต่อไปนี้สูงสุด:

| รายการ | สูงสุด |
| --- | --- |
| รายการบันทึกกฎ | 200 |
| กิจกรรมที่โพสต์ | 64 |
| การดำเนินงาน DOM | 256 |
| การกระทำ/เจตนา | 256 |
| แผงต่อกลุ่ม | 24 |
| การควบคุมในแผงเดียว | 32 |
| ตัวเลือกในการเลือก/การควบคุมด้วยวิทยุ | 64 |

บันทึกส่วนเกิน เหตุการณ์ที่โพสต์ การดำเนินการ DOM และรายการเจตนาอาจถูกละทิ้ง กฎที่กำหนดเองต้องไม่ขึ้นอยู่กับรายการส่วนเกินที่ถูกส่ง

### 5.3 ประเภทเหตุการณ์ในตัว

สตริงประเภทเหตุการณ์ต่อไปนี้ถูกสร้างขึ้น กฎอาจใช้สตริงประเภทที่ไม่ว่างเปล่าของตัวเอง ตราบใดที่ไม่ได้ขึ้นต้นด้วยขีดล่าง

| ประเภทเหตุการณ์ | เมื่อมีการส่ง | ข้อมูลสำคัญ |
| --- | --- | --- |
| ติ๊กเหตุการณ์ | แชร์เห็บเป็นระยะที่การตั้งค่าอัตราเห็บทั่วโลก | บริบทของหน้า/แท็บปัจจุบันหากมี ใช้ตัวเลือกการลงทะเบียน IntervalMs เพื่อจำกัดอัตราตัวจัดการแต่ละรายการ |
| openWebEvent | เพจระดับบนสุดจะพร้อมใช้งานสำหรับกฎ | URL, ชื่อโฮสต์, รหัสแท็บ/เพจ, เวลา |
| closeWebEvent | หน้า/แท็บระดับบนสุดจะปิดลง | บริบท URL/ชื่อโฮสต์ หากมี |
| webChangedEvent | การนำทางระดับบนสุดที่มุ่งมั่น รวมถึงการโหลด URL เดียวกันซ้ำ | ข้อมูลมี URL/ชื่อโฮสต์ก่อนหน้าและแฟล็กการนำทาง เช่น isFirstLoad, isReload และ SameDomain |
| ตัวจับเวลาสิ้นสุด | ตัวจับเวลาแบบกำหนดเองจะเปลี่ยนเป็นสถานะหมดอายุ | ข้อมูล: timerId, displayName, ทิศทาง, currentMs จะถูกส่งไปยังกลุ่มเจ้าของตัวจับเวลาเท่านั้น |
| งีบหลับกด | ผู้ใช้กดเริ่มเลื่อนสำหรับกลุ่มแบบกำหนดเองนี้ | กฎเป็นเจ้าของการตอบสนอง ไม่มีการดำเนินการสำรองการเลื่อนตามปกติ |
| แผงเหตุการณ์ | แผงแบบกำหนดเองที่แสดงผลมีการโต้ตอบ | ฟิลด์ข้อมูลและความสะดวกรวมถึงข้อมูลแผงควบคุม/การควบคุม/เหตุการณ์/ค่า |
| localFileEvent | การดำเนินการไฟล์ในเครื่องที่ร้องขอเสร็จสมบูรณ์ | ฟิลด์ข้อมูลและความสะดวกประกอบด้วย requestId, เส้นทาง, ผลลัพธ์, ไบต์, รายการ และข้อผิดพลาด |
| เพจ HeartbeatEvent | ฮาร์ทบีทของหน้าที่มองเห็นได้ ประมาณทุกๆ 250 มิลลิวินาที ขณะที่แท็บปรากฏให้เห็น | elapsedMs คือเวลาที่ผ่านไปที่มองเห็นได้ ตัวจับเวลาแบบกำหนดเองที่กำหนดขอบเขตจะใช้โดยอัตโนมัติแม้ไม่มีตัวจัดการที่ลงทะเบียนไว้ก็ตาม |

### 5.4 API รีจิสทรีเหตุการณ์

อาร์กิวเมนต์แรกของแหล่งที่มาสไตล์ฟังก์ชันคือรีจิสทรีเหตุการณ์ ในแหล่งที่มาของคำสั่งเปล่า ทั้งเหตุการณ์และเหตุการณ์อ้างถึงรีจิสทรีนี้

| วิธีการ | สัญญา |
| --- | --- |
| events.on(type, id, handler, options) | Register a handler. Returns true when accepted, false for invalid/capped registrations. |
| events.register(type, id, handler, options) | Alias of on. |
| events.off(type, id) | Unregister a handler. Returns whether something was removed. |
| events.unregister(type, id) | Alias of off. |
| events.unregisterAll(type) | Remove all handlers owned by this group for that event type. Returns the number removed. |
| events.getEvent(type, id) | Return the registered function for this group/id, or null. |
| events.getEvents(type) | Return an object mapping this group's handler ids to functions. |
| events.countRegistered(type) | Return this group's number of registrations for type. |
| events.emit(type, data, options) | Queue a synthetic event. |
| events.post(type, data, options) | Alias of emit. |

เหตุการณ์สังเคราะห์มีค่าเริ่มต้นเป็นขอบเขตของกลุ่ม: เฉพาะตัวจัดการที่อยู่ในกลุ่มที่เปล่งแสงเท่านั้นที่จะได้รับเหตุการณ์เหล่านั้น ใช้ { ขอบเขต: "global" } เพื่อส่งเหตุการณ์ไปยังทุกกฎที่ลงทะเบียนประเภทเดียวกัน อย่าใช้ขีดล่างนำหน้าในชื่อเหตุการณ์ มันถูกสงวนไว้

### 7.3 การควบคุม

ประเภทการควบคุมที่ใช้ได้ ได้แก่ ข้อความ กล่องกาเครื่องหมาย เลือก การป้อนข้อความ พื้นที่ข้อความ ปุ่ม ส่วน ตัวจับเวลา การป้อนตัวเลข ช่วง สลับ ตัวเลือก วันที่ เวลา สี พิน และ html อินพุตนามแฝง ดรอปดาวน์ กลุ่ม หมายเลข แถบเลื่อน สวิตช์ ดิบ และมาร์กอัปทำให้เป็นประเภทที่สอดคล้องกัน

## 8 สูตรการดำเนินการตามกฎที่กำหนดเอง

ตัวอย่างต่อไปนี้เป็นข้อกำหนดของการเรียบเรียงสาธารณะ ไม่ใช่บทช่วยสอน

### 8.1 เปลี่ยนเส้นทางหน้าเปิด

```js
(events, helpers) => {
  events.on("openWebEvent", "redirect-distracting-search", (event, h) => {
    const domain = h.getDomainHelper();
    if (!domain.isSearchPage(event.url)) return;
    event.setRedirectLink(h.getRedirectionHelper().createMessageUrl("Return to your planned task."));
    event.preventDefault();
  });
}
```

### 8.2 การนับถอยหลังเวลาที่มองเห็นได้พร้อมการบล็อกที่ชัดเจน

```js
(events, helpers) => {
  const timer = helpers.getTimerHelper();
  timer.create({
    id: "reading-budget",
    displayName: "Reading budget",
    direction: "backward",
    currentMs: 10 * 60 * 1000,
    scope: (url) => url.includes("example.com")
  });

  events.on("timerEnded", "stop-at-zero", (event) => {
    if (event.data?.timerId !== "reading-budget") return;
    event.setRedirectLink("about:blank");
    event.preventDefault();
  });
}
```

### 8.3 เปลี่ยนภาคแสดงฟีดจากแผงควบคุม

```js
(events, helpers) => {
  const panel = helpers.getPanelHelper();
  const youtube = helpers.platform("youtube");

  panel.create({
    id: "feed-filter",
    title: "Feed filter",
    controls: [{
      id: "hide-sponsored",
      type: "toggle",
      label: "Hide sponsored items",
      value: true,
      onChange: (event, h) => {
        const api = h.platform("youtube");
        if (event.value) {
          api.hide("videos", (item) => item?.sponsored === true);
        } else {
          api.show("videos");
        }
        api.rescan();
      }
    }]
  });

  youtube.hide("shorts", () => true);
}
```

เพรดิเคตต้องถูกเขียนสำหรับสแน็ปช็อตแพลตฟอร์ม/ค่าไอเท็มที่จัดทำโดยพื้นผิวแพลตฟอร์มที่ใช้งานอยู่ หากแพลตฟอร์มไม่สามารถระบุฟิลด์ได้อย่างน่าเชื่อถือ เพรดิเคตควรล้มเหลวในการเปิด แทนที่จะถือว่าค่าเป็นจริง

## 9. โปรโตคอลคำขอโฟลเดอร์ในเครื่อง

การดำเนินการของโฟลเดอร์ภายในเครื่องไม่ใช่ไฟล์ I/O ทันที ลำดับการทำงานที่สมบูรณ์คือ:

1. ผู้ใช้เลือกโฟลเดอร์ในการตั้งค่าส่วนกลาง
2. กฎจัดคิวคำขอและรับรหัสคำขอ
3. ห้องนิรภัยจะขอให้ความสามารถของโฟลเดอร์ที่ได้รับอนุญาตดำเนินการได้
4. ห้องนิรภัยส่ง localFileEvent ไปยังกลุ่มกำหนดเองเดียวกัน
5. ตัวจัดการเชื่อมโยง event.requestId กับรหัสคำขอดั้งเดิม

การอ่านที่สำเร็จจะเสร็จสิ้นด้วยข้อความสำหรับไฟล์ข้อความหรือค่าสำหรับ JSON รายการส่งคืนรายการ มีผลตอบแทนอยู่ การเขียน/ผนวกระบุไบต์ตามความเหมาะสม ความล้มเหลวแสดงว่าเป็นเท็จและข้อผิดพลาด กฎจะต้องไม่ถือว่าโฟลเดอร์ที่เลือกยังคงได้รับอนุญาตหลังจากโหลดซ้ำ รีสตาร์ทเบราว์เซอร์ หรือการเพิกถอนสิทธิ์

## 10. ความหมายความปลอดภัยและความล้มเหลวของกฎที่กำหนดเอง

### 10.1 รวบรวมและเรียกใช้ข้อผิดพลาด

ตรวจสอบความล้มเหลวในการรวบรวมรายงานไวยากรณ์ Run ยังสามารถรายงานข้อผิดพลาดรันไทม์ระหว่างการลงทะเบียนได้อีกด้วย หากแหล่งที่มาที่มีลักษณะคล้ายฟังก์ชันมีข้อผิดพลาดทางไวยากรณ์ ห้องนิรภัยจะไม่ถอยกลับโดยถือว่ามันเป็นข้อความเปล่าๆ ที่ไม่เป็นอันตราย

แหล่งว่างไม่มีตัวจัดการ ใช้ได้เป็นกฎแบบกำหนดเองที่ไม่ได้ใช้งาน แต่ไม่มีการดำเนินการแบบกำหนดเองที่กำหนดค่าไว้

### 10.2 ข้อผิดพลาดของตัวจัดการ

ข้อยกเว้นจากตัวจัดการหนึ่งตัวจะถูกแยกออกจากการจัดส่งเหตุการณ์โดยรวม เป็นเอาต์พุตการวินิจฉัย มันไม่ได้ทำให้ผู้จัดการในภายหลังประสบความสำเร็จอย่างน่าอัศจรรย์ ใช้ตัวจัดการแบบแคบและบันทึกข้อผิดพลาดที่ดำเนินการได้

### 10.3 การกักกัน

ห้องนิรภัยสามารถกักกันกลุ่มที่กำหนดเองได้หลังจากเกินกำหนดเวลาซ้ำๆ หรือเกินกำหนดระหว่างการลงทะเบียน การกักกันจะปิดใช้กลุ่มและบันทึกสาเหตุการยกเลิก แก้ไขแหล่งที่มา บันทึก และเรียกใช้อีกครั้งอย่างชัดเจนเพื่อคืนค่าการลงทะเบียนที่ใช้งานอยู่

### 10.4 การจำกัดเบราว์เซอร์/หน้า

ไม่มีกฎที่กำหนดเองได้รับ API ส่วนขยายที่ไม่จำกัด โดยเฉพาะ:

- ตัวเลือก DOM ไม่พบสิ่งใดบนแพลตฟอร์มที่เปลี่ยนแปลง
- การนำทาง การปิดแท็บ และการดำเนินการบนหน้าจอยังคงขึ้นอยู่กับความสามารถของเบราว์เซอร์
- ส่วนขยายไม่สามารถเปิดแอปพลิเคชันเนทิฟได้
- การดำเนินการโฟลเดอร์ในเครื่องจำเป็นต้องมีโฟลเดอร์ที่ผู้ใช้อนุญาตและประเภทไฟล์ที่รองรับ
- ตัวจัดการเหตุการณ์ไม่สามารถพึ่งพาเพจที่มองไม่เห็นซึ่งยังคงสร้างการเต้นของหัวใจเวลาที่มองเห็นได้
- เพจสามารถโหลดซ้ำ นำทาง ถูกละทิ้ง หรือทำให้สคริปต์เนื้อหาใช้ไม่ได้โดยไม่ขึ้นอยู่กับกฎ
- บล็อกไซต์ไดนามิกที่สร้างด้วยกฎคือการดำเนินการในสถานะเซสชัน ไม่ใช่การแก้ไขกลุ่มไซต์อย่างถาวร

## 11. บริดจ์เว็บแอป

สะพานเป็นทางเลือก เชื่อมต่อไคลเอนต์ส่วนขยายเบราว์เซอร์กับฮับ Vault ภายในที่เข้ากันได้ ส่วนขยายเบราว์เซอร์เป็นไคลเอนต์ แอพ Vault ดั้งเดิมมีฮับ จุดสิ้นสุดภายในเครื่องแบบคงที่คือ ws://127.0.0.1:8787 และจำเป็นต้องมีความเข้ากันได้ของโปรโตคอล

สถานะการเชื่อมต่อคือ ปิด กำลังเชื่อมต่อ ตัดการเชื่อมต่อ เชื่อมต่อแล้ว และเกิดข้อผิดพลาด เมื่อเปิดใช้งานไคลเอ็นต์ ห้องนิรภัยจะตรวจสอบอย่างรวดเร็วก่อน จากนั้นจึงพยายามเชื่อมต่อใหม่ช้าลงเรื่อยๆ จนกว่าจะเชื่อมต่อหรือผู้ใช้ปิดการทำงาน การเชื่อมต่อไม่ได้รวมทุกกลุ่มด้วยตัวเอง

### 11.1 การเชื่อมโยงกลุ่ม

กลุ่มจะลิงก์ได้ก็ต่อเมื่อชื่อและประเภทตรงกันและมีสิทธิ์ลิงก์ได้ ผู้ใช้เลือก/เชื่อมโยงโปรแกรมที่เข้าร่วมอย่างชัดเจน กลุ่มที่เชื่อมโยงกันจะก่อตัวเป็นคลัสเตอร์ การยกเลิกการเชื่อมต่อจะทำให้ข้อมูลกลุ่มโลคัลไม่เสียหาย มันหยุดการซิงโครไนซ์สด

บริดจ์ซิงโครไนซ์นโยบายสเกลาร์ที่ใช้ร่วมกันสำหรับกลุ่มที่เชื่อมโยงที่รองรับ รวมถึงโหมดการบล็อกปกติ ค่าเผื่อ/รีเซ็ต การตั้งค่าเลื่อน วันที่/หน้าต่างที่ใช้งาน สถานะ/ตัวเลือก/ระยะเวลาการแช่แข็ง นโยบายหน้าแรก การตั้งค่ารายการที่อนุญาต URL สำรอง และนโยบายข้ามไปยังถัดไป นอกจากนี้ยังประสานการใช้งานและสถานะการเลื่อนสำหรับสมาชิกคลัสเตอร์อีกด้วย

บริดจ์ไม่ได้รับประกันว่าฟิลด์เฉพาะผลิตภัณฑ์ ตัวเลือกแพลตฟอร์ม ข้อความต้นฉบับที่กำหนดเอง หรือความสามารถเฉพาะเบราว์เซอร์ทั้งหมดสามารถถ่ายโอนไปยังโปรแกรมอื่นได้ กลุ่มสามารถคงอยู่ในเครื่องและยกเลิกการเชื่อมโยงได้แม้ว่าบริดจ์จะเชื่อมต่ออยู่ก็ตาม

คลัสเตอร์บริดจ์ที่ค้างกำหนดให้สมาชิกที่เกี่ยวข้องทั้งหมดต้องออนไลน์เพื่อดำเนินการในสถานะหยุดซึ่งจำเป็นต้องมีการกลายพันธุ์ที่ประสานกัน การเชื่อมต่อเป็นการขนส่งในพื้นที่ ไม่ใช่การสำรองข้อมูลบนคลาวด์หรือช่องทางการควบคุมระยะไกล

## 12. รายการตรวจสอบการตรวจสอบสำหรับผู้ดูแล

ใช้รายการตรวจสอบนี้เมื่อตรวจสอบการเผยแพร่หรือพฤติกรรมการทำซ้ำ:

1. ยืนยันว่ากลุ่มมีชื่อเฉพาะที่ไม่ว่างเปล่า ประเภทที่ถูกต้อง สถานะเปิดใช้งาน และรายการ/คำสั่งซื้อที่ต้องการ
2. สำหรับกลุ่มปกติ ให้ยืนยันวันทำงานที่ใช้งาน กรอบเวลาท้องถิ่นที่ถูกต้อง ไม่มีการเลื่อนการทำงาน และสถานะการแก้ไขที่ไม่ถูกระงับ
3. สำหรับกลุ่มไซต์ ให้ทดสอบโฮสต์ โดเมนย่อย และ (สำหรับรายการที่อนุญาต) โฮสต์ที่อยู่นอกรายการ
4. สำหรับกลุ่มแพลตฟอร์ม ให้ทดสอบการจับคู่ระดับหน้า การจับคู่รายการ/การ์ดเป้าหมาย โหมดผู้เขียน โหมดรูปแบบเนื้อหา และการซ่อนพื้นผิวที่เปิดใช้งานแต่ละรายการแยกกัน
5. สำหรับกลุ่มปกติที่มีการกำหนดเวลา ให้ตรวจสอบการคงค้างของหน้าที่มองเห็นได้ การหมดอายุของเบี้ยเลี้ยงหรือการนับพฤติกรรมที่ไม่ปิดกั้น และรีเซ็ตช่วงเวลา
6. สำหรับกฎแบบกำหนดเอง ให้รันการตรวจสอบไวยากรณ์ รัน ตรวจสอบจำนวน/บันทึกของตัวจัดการ ทดสอบทุกเหตุการณ์ในตัวที่ลงทะเบียนไว้ จากนั้นทดสอบการโหลดซ้ำ/การนำทาง
7. ทดสอบตัวจับเวลาแบบกำหนดเองแต่ละตัวที่ขอบเขตขอบเขตและที่ศูนย์ ตรวจสอบว่าการบล็อกใดๆ มีความชัดเจนในกฎ
8. ทดสอบแผงด้วยค่าควบคุมแต่ละค่า สถานะปิดใช้งาน การดำเนินการส่ง/ยกเลิก/ปิด และตัวจัดการเหตุการณ์แผง
9. ทดสอบความล้มเหลวของโฟลเดอร์ในเครื่องก่อนที่จะสำเร็จ: ไม่ได้เลือกโฟลเดอร์, การอนุญาตที่ถูกเพิกถอน, เส้นทางที่ไม่ถูกต้อง, ส่วนขยายที่ไม่รองรับ, จากนั้นจึงอนุญาตให้อ่าน/เขียน
10. ทดสอบการปิดการเชื่อมต่อบริดจ์ การเปิดการเชื่อมต่อ กลุ่มที่เชื่อมโยง/ไม่เชื่อมโยง และสมาชิกคลัสเตอร์ออฟไลน์ ก่อนที่จะอาศัยการซิงโครไนซ์หรือการหยุดการประสานงาน

## 13. กฎการกำหนดเวอร์ชัน

ไฟล์ภาษาอังกฤษนี้เป็นคู่มือต้นฉบับที่ได้รับการปรับปรุง คู่มือที่แปลเป็นภาษาท้องถิ่นเป็นคำแปลและอาจต้องมีการสร้างใหม่หลังจากการอัปเดตเอกสารการทำงาน แหล่งที่มาของผลิตภัณฑ์ยังคงเป็นความจริงที่เป็นที่ยอมรับสำหรับความคลุมเครือในระดับการใช้งาน
