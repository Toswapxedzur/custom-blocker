# คู่มือผู้ใช้ส่วนขยายเบราว์เซอร์ Vault

Vault ควบคุมเว็บไซต์และเนื้อหาบนแพลตฟอร์มที่รองรับในโปรไฟล์เบราว์เซอร์ที่ติดตั้งส่วนขยายนี้ เปิดตัวแก้ไขจากปุ่มส่วนขยายบนแถบเครื่องมือ เมื่อเชื่อมต่อกับ Mac Vault หรือ Windows Vault จะมีการติดแท็กในเครื่องและ Activity ส่วนส่วนขยายจะบังคับใช้นโยบายกับเป้าหมายในเบราว์เซอร์

## กลุ่มการบล็อก

**กลุ่มการบล็อก** ใช้นโยบายการบล็อก ส่วน **กลุ่มตัวจัดประเภท** กำหนดแท็กให้เนื้อหา แต่ไม่ได้บล็อกสิ่งใดด้วยตัวเอง

1. เพิ่มกลุ่มการบล็อกและตั้งชื่อ
2. เลือกเป้าหมายใน **ใช้กับ**
3. เลือกเวลาที่จะใช้การบล็อก แล้วกำหนดตารางเวลาหรือเวลาที่อนุญาต
4. เปิดใช้กลุ่ม เป้าหมายทั้งหมดจะใช้นโยบายของกลุ่มร่วมกัน

การแก้ไขทั่วไปจะบันทึกโดยอัตโนมัติ หากมีข้อผิดพลาด แสดงว่าระบบไม่ยอมรับการแก้ไขนั้น ให้แก้ช่องดังกล่าวแล้วลองอีกครั้ง ปิดใช้กลุ่มเพื่อหยุดนโยบายโดยยังเก็บการตั้งค่าไว้ **ลบกลุ่ม** จะนำกลุ่มออก ลากกลุ่มเพื่อจัดลำดับใหม่ได้ หลายกลุ่มอาจมีผลกับเป้าหมายเดียวกัน การเลื่อนเวลาของกลุ่มหนึ่งไม่ได้ยกเลิกการบล็อกจากกลุ่มอื่น

**ส่งออก** จะคัดลอกการตั้งค่ากลุ่ม **นำเข้า** จะแทนที่การตั้งค่าของกลุ่มที่เลือกหลังจากยืนยัน

### เวลาที่อนุญาตและตารางเวลา

**บล็อกทันที** จะบล็อกเมื่อกลุ่มที่เปิดใช้อยู่ตรงกับเป้าหมายและอยู่ในช่วงตารางเวลาที่กำหนด **บล็อกเมื่อใช้เวลาที่อนุญาตหมดแล้ว** อนุญาตให้ใช้งานที่ตรงเงื่อนไขได้จนกว่าเวลาที่กำหนดจะหมด

กำหนดเวลาที่อนุญาตเป็นนาที และช่วงรีเซ็ตเป็นชั่วโมง ขีดจำกัดแบบเลื่อนนับการใช้งานภายในช่วงเวลาก่อนหน้าที่กำหนด การรีเซ็ตตอนเที่ยงคืนจะเริ่มรอบใหม่ ณ เที่ยงคืนตามเวลาท้องถิ่น รวมถึงขีดจำกัดแบบเลื่อนด้วย

เลือกวันในสัปดาห์ที่ต้องการให้ทำงาน และระบุช่วงเวลาท้องถิ่น (ไม่บังคับ) บรรทัดละหนึ่งช่วง เช่น **09:00-12:00** หากไม่ระบุช่วงเวลา จะใช้ตลอดวันที่เลือก ช่วงเวลาต้องสิ้นสุดหลังเวลาเริ่มในวันเดียวกัน หากต้องการคร่อมคืน ให้แยกกำหนดเป็นคนละวัน

### เลื่อนเวลา

ตั้งค่าการเลื่อนเวลาแยกกันในแต่ละกลุ่มการบล็อก **หยุดการบล็อกชั่วคราว** จะพักนโยบายของกลุ่มนั้นตามระยะเวลาที่กำหนด **เพิ่มเวลาที่อนุญาต** จะเพิ่มนาทีที่ใช้งานได้ให้กลุ่มที่จำกัดด้วยเวลา นับเฉพาะเวลาที่ใช้จากส่วนที่เพิ่มเป็นเวลาเลื่อน เวลาที่เพิ่มแต่ยังไม่ได้ใช้จะหมดอายุเมื่อรีเซ็ตครั้งถัดไป ส่วนขีดจำกัดแบบเลื่อนจะหมดอายุหลังครบหนึ่งช่วง หรือเร็วกว่านั้นตอนเที่ยงคืนหากเปิดตัวเลือกนี้

**ระยะหน่วงก่อนเริ่ม** จะเลื่อนการใช้การเลื่อนเวลาออกไป โดยการบล็อกยังดำเนินต่อ **ช่วงพักก่อนขอซ้ำ** คือเวลารอหลังการเลื่อนเวลาสิ้นสุดก่อนจะขอได้อีก **จำนวนครั้งที่ต้องยืนยัน** กำหนดจำนวนขั้นตอนยืนยัน จะใช้การเลื่อนเวลาในกลุ่มที่ตรึงไว้ได้ก็ต่อเมื่ออนุญาตไว้ก่อนตรึง

### ตรึงและ PIN

**ตรึง** จะป้องกันการแก้ไขทั่วไป การเลิกตรึงต้องยืนยันสิบครั้ง ห่างกันครั้งละห้าวินาที และต้องรอให้ครบเวลาที่ตั้งไว้พร้อมป้อน PIN หกหลัก **รอก่อนเลิกตรึง** ตั้งได้ตั้งแต่ 0–72 ชั่วโมง ค่า 0 คือไม่ต้องรอเพิ่ม

ขณะตรึงอยู่ สามารถเพิ่มเวลารอและเพิ่ม PIN ได้หากยังไม่มี จะลดความเข้มงวดของเงื่อนไขเหล่านี้ไม่ได้จนกว่าจะเลิกตรึงกลุ่ม การลบกลุ่มยังต้องรอให้พ้นเวลาที่เหลือและผ่าน PIN ด้วย

### กลุ่มที่เชื่อมโยงกัน

ใช้ **เชื่อมโยง** เพื่อเชื่อมกลุ่มที่เลือกไว้อย่างชัดเจนในโปรแกรม Vault อื่น กลุ่มที่เชื่อมโยงกันใช้ชื่อ การตั้งค่านโยบายที่รองรับ เป้าหมาย ปริมาณการใช้งาน และเงื่อนไขการตรึงร่วมกัน แต่ละโปรแกรมแก้ไขและบังคับใช้ประเภทเป้าหมายที่รองรับ ส่วนรายการเป้าหมายประเภทอื่นยังคงให้โปรแกรมที่เชื่อมโยงใช้งานได้ เมื่อยกเลิกการเชื่อมโยง กลุ่มและการตั้งค่าของแต่ละกลุ่มจะยังอยู่

หากสมาชิกที่เชื่อมโยงอยู่ในสถานะออฟไลน์ การแก้ไขอาจใช้ไม่ได้ ให้เปิดแอป Vault บนเดสก์ท็อปและเบราว์เซอร์ที่เชื่อมโยงเพื่อเชื่อมต่ออีกครั้ง นโยบายที่บันทึกไว้ในเครื่องอาจยังทำงานต่อแม้สมาชิกจะออฟไลน์

## ขอความช่วยเหลือ

คลิก **i** ขนาดเล็กข้างช่องเพื่อดูคำอธิบาย คลิกด้านนอกหรือกด Escape เพื่อปิด รายการจะแสดงอยู่ในกรอบที่เลื่อนได้ ให้เลื่อนในกรอบเพื่อดูรายการเพิ่มเติม การค้นหาจะกรองรายการที่มองเห็นโดยไม่ลบรายการใด

กฎแบบกำหนดเองมี [คู่มือโค้ด](../code-manual/th.md) แยกต่างหาก ซึ่งอธิบายตัวแก้ไข การเปิดใช้ บันทึก การเข้าถึงไฟล์ และ API ที่รองรับ

## เว็บไซต์และเนื้อหาบนแพลตฟอร์ม

เพิ่มโดเมนหรือ URL แบบเต็ม บรรทัดละหนึ่งรายการ โดเมนจะรวมโดเมนย่อยด้วย การระบุเส้นทางจะจำกัดการจับคู่ไว้ที่เส้นทางนั้นและรายการย่อย **บล็อกทุกอย่างยกเว้นเว็บไซต์เหล่านี้** จะเปลี่ยนรายการให้เป็นรายการอนุญาต

เพิ่มเว็บไซต์เดิมซ้ำได้ แต่ละรายการมีตัวกรองและตัวควบคุมหน้าแยกกัน เช่น รายการ YouTube หนึ่งรายการอาจบล็อก Shorts ขณะที่อีกรายการบล็อกครีเอเตอร์ รายการที่ตรงกันจะทำงานร่วมกันภายในกลุ่ม และใช้ตารางเวลา เวลาที่อนุญาต และการเลื่อนเวลาของกลุ่มเดียวกัน

เป้าหมายอาจปิดทับหน้าที่ตรงกัน หรือหยุดชั่วคราวก่อนแล้วเสนอให้ดำเนินการต่อหลังนับถอยหลัง เป้าหมายที่บล็อกจะมีผลเหนือเป้าหมายที่หยุดชั่วคราวในกลุ่มเดียวกัน **เมื่อถูกบล็อก: เปลี่ยนเส้นทางหรือแสดงข้อความ** รับที่อยู่เว็บหรือข้อความปิดทับ หากเว้นว่างไว้ หน้าจะถูกปิดทับอยู่ที่เดิม การหยุดชั่วคราวจะไม่เปลี่ยนเส้นทาง

เป้าหมายตามแพลตฟอร์มใช้ **ครีเอเตอร์** สำหรับแพลตฟอร์มวิดีโอ, **บัญชี** สำหรับ Twitter / X, **ชุมชน** สำหรับ Reddit และ ID เซิร์ฟเวอร์/ช่องสำหรับ Discord ตัวควบคุมจะมีผลเมื่อ Vault ระบุแหล่งที่มาและประเภทเนื้อหาได้ การควบคุมเนื้อหาจะซ่อนองค์ประกอบของหน้าที่รองรับ เช่น โฆษณาหรือการ์ดวิดีโอ สิทธิ์ของเบราว์เซอร์และการเปลี่ยนแปลงเว็บไซต์อาจส่งผลต่อการควบคุมเหล่านี้

### ตัวกรองแท็กเนื้อหา

การเชื่อมต่อกับตัวจัดประเภทและการแก้ไขแท็กใช้ได้ในเบราว์เซอร์ Chromium ที่รองรับ เช่น Chrome และ Edge รวมถึง Safari Vault บน macOS

เชื่อมต่อ Mac Vault หรือ Windows Vault และตั้งค่าตัวจัดประเภทเพื่อรับแท็ก ตัวกรองแท็กในกลุ่มการบล็อกจะเลือกเนื้อหาที่ต้องการปิดทับหรือซ่อน ตัวกรองไม่ได้เริ่มหรือหยุดการติดแท็ก ให้ใช้การตั้งค่าตัวจัดประเภทในแอปเดสก์ท็อป หรือปุ่มพักของกลุ่มตัวจัดประเภทนั้น

แต่ละรายการเว็บไซต์มีตัวกรอง **ใช้กับ** หนึ่งรายการ ได้แก่ เนื้อหาทั้งหมด, ครีเอเตอร์ที่เลือก, ทั้งหมดยกเว้นครีเอเตอร์ที่เลือก, แท็กที่เลือก หรือทั้งหมดยกเว้นแท็กที่เลือก หากต้องการตัวกรองอื่น ให้เพิ่มเว็บไซต์เดิมเป็นอีกรายการ

เลือกแท็กที่ต้องการ หรือเลือกทุกอย่างยกเว้นแท็กเหล่านั้น กฎรวมแท็กได้ (**Gaming + Drama**), กำหนดระดับความเชื่อมั่น (**Gaming @3**) หรือระบุข้อยกเว้น (**!Tutorial**) **ปิดทับเนื้อหา** จะยังเปิดให้แก้ไขแท็กได้ **ซ่อนเนื้อหา** จะนำรายการที่ตรงกันออก

**บล็อกเนื้อหาที่ไม่มีแท็กที่เชื่อถือได้ด้วย** จะรวมผลลัพธ์ที่เสร็จแล้วแต่ไม่มีแท็กที่เกณฑ์ความเชื่อมั่นเริ่มต้น รวมถึงผลที่มีความเชื่อมั่นต่ำ ระบบจะตรวจสอบกฎที่ระบุไว้ก่อน **ไม่มีแท็ก** หมายถึงการติดแท็กเสร็จแล้วแต่ไม่พบแท็ก ส่วน **กำลังติดแท็ก** หมายถึงผลลัพธ์ยังอยู่ระหว่างดำเนินการ ตัวเลือกเนื้อหาที่รอดำเนินการแยกต่างหากจะควบคุมการปิดทับระหว่างรอการติดแท็ก

### แก้ไขแท็ก

คลิก **+ แท็ก** ข้างแท็กของรายการเพื่อเปิดตัวเลือกแก้ไข ค้นหาแท็กที่มีอยู่ในตัวจัดประเภท แล้วเลือกแท็กเพื่อเพิ่ม คลิกตัวควบคุมลบของแท็กที่เลือก หรือเลือกแท็กแล้วกด Delete หนึ่งครั้งเพื่อลบ การแก้ไขจะส่งไปยังแอปเดสก์ท็อปที่เชื่อมต่อ และนำไปใช้กับการติดแท็กในอนาคต หากค้นหาไม่ได้ จะแสดง **ไม่มีแท็ก** และอาจลองใหม่โดยอัตโนมัติ ข้อความนี้ไม่ได้สร้างแท็กในตัวจัดประเภท

## การตั้งค่าและการเชื่อมต่อ

**แสดงปุ่มเพิ่มด่วน +** จะเพิ่มปุ่มขนาดเล็กในหน้าที่รองรับ เลือกกลุ่มปลายทางจากรายการ การเลือกจะยังจำอยู่เมื่อเปิด Vault อีกครั้ง ใช้ปุ่มบนหน้าเพื่อเพิ่มหน้านั้นในรายการเว็บไซต์ กลุ่มที่ตั้งเป็นรายการอนุญาตจะอนุญาตหน้านั้น กลุ่มที่ตรึงไว้จะไม่รับรายการเพิ่มด่วน

ตั้งค่าพจนานุกรมอย่างเป็นทางการและนำเข้า/ส่งออกพจนานุกรมส่วนตัวได้ในแอปเดสก์ท็อปที่ **การตั้งค่า → ตัวจัดประเภท → พจนานุกรมอย่างเป็นทางการ** บริการพจนานุกรมอาจได้รับการติดต่อเมื่อไม่พบครีเอเตอร์ในแคชหรือเปิดการส่งข้อมูลแบบเลือกได้ ส่วนการวิจัยบนเว็บมีความยินยอมและการตั้งค่าผู้ให้บริการแยกต่างหาก ดูคู่มือเดสก์ท็อปและรายละเอียดการเปิดเผยข้อมูล

การเชื่อมต่อตัวจัดประเภทจะแสดงสถานะบริการ Vault บนเดสก์ท็อปในเครื่อง ตั้งค่ากลุ่มตัวจัดประเภท การดาวน์โหลดโมเดล Knowledge ความยินยอมในการวิจัย และผู้ให้บริการ API ในแอปเดสก์ท็อปที่เชื่อมต่อ

หากไม่มีแท็ก ให้ตรวจว่าแอป Vault บนเดสก์ท็อปเปิดอยู่ การเชื่อมต่อสำเร็จ เปิดใช้การติดแท็ก กลุ่มตัวจัดประเภทที่เกี่ยวข้องทำงานต่อ และมีการบันทึกฟีดของแพลตฟอร์มนั้น ตรวจสอบสถานะดาวน์โหลดโมเดลในแอปเดสก์ท็อป หากการบล็อกไม่มีผล ให้ตรวจสถานะเปิดใช้ เป้าหมาย ตารางเวลา เวลาที่อนุญาต และสถานะการเลื่อนเวลาของกลุ่ม
