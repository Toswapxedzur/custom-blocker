# دليل برمجة إضافة Vault للمتصفح

[دليل المستخدم](../manual/ar.md)

## مواصفات القاعدة

المصدر: تعبير دالة واحد `(on, v) => { ... }`. لا يُدعم سوى JavaScript المتزامن وواجهة API أدناه؛ لا توجد دوال رد نداء JavaScript مجدولة أو شبكة أو واجهات الإضافة أو وصول مباشر إلى DOM. تستخدم القواعد المعتمدة على الوقت المؤقتات ومتعقبات الاستخدام المُدارة أدناه، أو `ev.now` والأحداث.

- يحفظ التحرير مسودة؛ ويُفعّل **تشغيل** القاعدة ويمكّن المجموعة. لا يمكن تشغيل مجموعة مقفلة. يؤدي المصدر الفارغ إلى إلغاء تحميل القاعدة.
- يستبدل التشغيل الناجح معالجات الأحداث واللوحات مع الإبقاء على `v.state`. يبقي فشل التحويل البرمجي أو التسجيل القاعدة السابقة؛ وقد يوقفها انتهاء المهلة. يعيد تحميل المحرك تسجيل آخر مصدر تم تفعيله؛ وتُعاد متغيرات الإغلاق إلى قيمها الأولية.
- قد يهيئ التسجيل الحالة ويسجل المعالجات ويعرض اللوحات ويسجل رسائل. يجب وضع إجراءات الصفحة/الملف وإرسال الأحداث في المعالجات؛ ويُهمل طابورها عند التسجيل.
- يمنع التعطيل المعالجات ويرفع اللوحات والأوراق والتغطيات وقرارات العناصر المُدارة. يعيد التمكين اللوحات/الأوراق المحتفظ بها ويطلب العناصر مجددًا. لا يمسح التشغيل الأوراق أو التغطيات أو قرارات العناصر الموجودة. يحذف الإجراء **حذف** القاعدة وحالتها وآثارها. لا يُتراجع عن التنقل أو تغييرات DOM أو كتابة الملفات.
- لا تقتصر الأحداث على أهداف المجموعة العادية؛ رشّح عناوين URL والعناصر داخل القاعدة. تُصف الإجراءات ثم تطبق بعد إرسال الحدث. يوقف الاستثناء ذلك المعالج دون التراجع عن حالته أو إجراءاته؛ وقد تواصل المعالجات اللاحقة. لا يوجد إقرار بالإجراء إلا لأحداث الملفات والاستعلامات.

## واجهة API المشتركة

- `on(type, handler)` ← قيمة منطقية. يسجل `handler(ev)`؛ وتعمل عدة معالجات حسب ترتيب التسجيل. تشير القيمة false إلى وسيطات غير صالحة أو بلوغ حد المعالجات. `ev = { type: string, now: number, origin: "host" | "user" | "rule", data }`؛ و`now` هو وقت Unix بالمللي ثانية. أحداث عناصر التحكم المعروضة فعلياً لها `origin: "user"`؛ وأحداث `v.emit` لها `origin: "rule"`.
- `v.state`: كائن JSON قابل للتغيير، يُحفظ بعد إرسال الحدث. هيّئ الحقول المفقودة بدل الكتابة فوق الحالة الموجودة. تعيين قيمة ليست كائنًا أو كانت مصفوفة يعيدها إلى `{}`؛ ولا تُحفظ التحديثات غير القابلة للتسلسل أو الكبيرة جدًا.
- `v.log(...values)`: يكتب في سجل هذه المجموعة. تظهر هنا أيضًا أخطاء المعالجات وأخطاء إجراءات الصفحة المُبلّغ عنها؛ ولا تؤدي الإبلاغات إلى إعادة تنفيذ الإجراءات. السجلات/المسح مستقلة لكل مجموعة. تظهر أخطاء التحميل في حالة التشغيل.
- `v.emit(type, data)`: يضع نسخة JSON من `data` في طابور معالجات المجموعة بعد الحدث الحالي، مع `now` جديد؛ وليس استدعاءً متزامنًا.
- `v.panel(id, spec, tabId?)`: يستبدل لوحة المجموعة المسماة؛ احذف `tabId` لاستخدام كل صفحة ويب متاحة، أو استخدم معرّف تبويب صحيحًا. تزيل قيمة `spec` الفارغة اللوحة. راجع قسم اللوحات.
- `v.file(op, path, payload?)` ← سلسلة معرّف طلب. راجع قسم الملفات.
- يُرجع `v.store(request)` معرّف الطلب؛ راجع سجلات المجموعة.

تعيد الاستدعاءات المشتركة الأخرى `undefined`، باستثناء دوال إنشاء كائنات الوقت المُدارة المسماة أدناه. تنتمي المعرّفات والحالة إلى مجموعة واحدة، لا إلى اسم عرضها.

## المؤقتات المُدارة والاستخدام ضمن نافذة متحركة

`v.timer(id, {direction:"down", durationMs:300000})` ينشئ عدًا تنازليًا مسمى أو يعيد الموجود، ويكون متوقفًا مؤقتًا في البداية. استخدم `{direction:"up"}` لمؤقت يعد تصاعديًا. يوفّر المقبض `start()` و`pause()` و`resume()` و`reset()` و`snapshot()`. تكرار البدء/الاستئناف لا يغيّر النتيجة؛ وتعيد إعادة الضبط المؤقت إلى حالة متوقفة مؤقتًا مع زمن منقضٍ يساوي صفرًا. تتضمن حقول اللقطة `ready` و`error` و`elapsedMs` و`remainingMs` (null للعد التصاعدي) و`running` و`completed`.

تتقدم المؤقتات العاملة وفق وقت الساعة الفعلي حتى عندما يكون التطبيق/المتصفح مغلقًا أو القاعدة معطلة. يسلّم العد التنازلي المكتمل الحدث `timerEnded` مع `{id, direction, durationMs, generation, incarnation}` مرة واحدة لكل نسخة وجيل من المؤقت، لكل عضو عند تشغيل قاعدته لاحقًا؛ ولا يعيد التشغيل تسليمه. يعتمد التسليم على أحداث المضيف؛ وليس هذا منبهًا آنيًا. ضع `{type:"timer", timerId:"focus", label:"Focus"}` في لوحة لعرضه عبر عنصر التحكم النصي الموجود.

`v.rolling(id, {windowMs:3600000, limitMs:600000})` ينشئ متعقب استخدام نشط مسمى أو يعيد الموجود. يستبدل `assign({websites:["youtube.com","reddit.com"], apps:[]})` تعيينات أهداف هذا العضو. يمكن للقواعد الأصلية تعيين معرّفات تطبيقات المنصة بدلًا منها. تشمل النطاقات النطاقات الفرعية. يجمع المتعقب استخدام أهدافه؛ وللمعرّفات الأخرى حصص مستقلة. تعيد `snapshot()` الحقول `ready` و`error` و`usedMs` و`remainingMs` و`available` و`nextReturnAtMs` (أقرب مللي ثانية تنتهي فيه صلاحية أي استخدام مسجل). تتحقق `available(target?)` أيضًا من التعيين عند تحديد هدف. تمسح `reset()` سجل هذا الكائن.

يُحتسب كل استخدام مؤهل تمت ملاحظته، بما فيه الاستخدام الذي يتجاوز الحصة؛ ولا يحظر المتعقب نفسه صفحة أو تطبيقًا. تُحتسب فترات ظهور الصفحات المتداخلة مرة واحدة، وتحتسب التطبيقات الأصلية الاستخدام المرصود في المقدمة. لا تضيف القواعد المعطلة استخدامًا؛ لكن السجل يظل ينتهي عند حدود الفترات الدقيقة. لا تعود الإتاحة إلا عندما يقل الاستخدام المتبقي في السجل عن الحد. عينات نبض المتابعة محدودة بخمس ثوانٍ؛ ولا تولّد فجوات الإغلاق/التعطيل نشاطًا وهميًا. لا تضيف الأحداث التي يرسلها المستخدم استخدامًا.

تتشارك معرّفات الكائنات المتطابقة في المجموعات المخصصة المرتبطة جهةً مرجعية واحدة في الموزّع الأصلي المحلي. يجمع الربط سجل المتعقب وتعييناته ويحتفظ بحالة المؤقت الذي بدأ الربط؛ وتمنع الإعدادات غير المتوافقة الربط. يتلقى كل عضو حدث الاكتمال الخاص به. يجعل انقطاع الاتصال المتعقبات المشتركة غير متاحة ويرفض التحكم بالمؤقتات حتى عودة بيانات مرجعية حديثة. عند إلغاء الربط، يحتفظ كل عضو بالاستخدام المشترك النهائي وحالة المؤقت، ويستعيد أهدافه الخاصة ويتجاهل أوامر الربط القديم. يحتفظ الموزّع باللقطة النهائية حتى يحفظها العضو العائد ويؤكد استلامها؛ وتكتمل عمليات التسليم المعلقة قبل إتاحة ربط جديد.

تبقى الكائنات المسماة بعد التشغيل وإعادة البدء في الحقل المحجوز `v.state.$vaultTime`؛ لا تعدّله مباشرة. احذف الكائن صراحةً باستخدام `v.removeTime(id)`. تتكون المعرّفات من 1–80 حرف ASCII أو رقم أو `_` أو `-`؛ وتُرفض أسماء الخصائص المحجوزة. يتشارك ما يصل إلى 32 كائنًا حد حالة القاعدة البالغ 64KiB بترميز UTF-8. المدد أعداد صحيحة بالمللي ثانية لا تتجاوز 365 يومًا. يقتصر السجل المتحرك على 1024 حاوية دقيقة و2048 فترة مدمجة. تجعل أخطاء سعة السجل المتعقب غير متاح حتى إعادة ضبطه صراحةً؛ وتُبلغ الإعدادات غير الصالحة وعمليات الحفظ الكبيرة جدًا عن أخطاء دون مسح البيانات المحفوظة.

```js
(on, v) => {
  const timer = v.timer("focus", {durationMs: 300000});
  v.panel("focus", {controls: [
    {type: "timer", timerId: "focus", label: "Focus"},
    {id: "start", type: "button", label: "Start"},
    {id: "pause", type: "button", label: "Pause"},
    {id: "reset", type: "button", label: "Reset"}
  ]});
  on("panel", ev => {
    if (ev.data.eventName !== "click") return;
    if (ev.data.controlId === "start") timer.start();
    if (ev.data.controlId === "pause") timer.pause();
    if (ev.data.controlId === "reset") timer.reset();
  });
  on("timerEnded", ev => v.log("Finished", ev.data.id));
}
```

## أحداث المتصفح

توضح صياغة الحمولة أدناه الأنواع؛ وليست شيفرة قابلة للتنفيذ. تشير `?` إلى حقول اختيارية.

```text
tick (~1 second): { tabs: { tabId: number, url: string, active: boolean }[] }
tab: { kind: "open" | "navigate" | "close", tabId: number,
       url: string, previousUrl: string | null }
visible: { tabId: number, url: string, elapsedMs: number }
items: { tabId: number, platform: string, items: Item[] }
attachment: { eventName: "click" | "input" | "change", tabId: number,
              attachmentId: string, controlId: string, value: unknown,
              values: { [controlId: string]: unknown }, item: Item, text: string }
record: { requestId: string, ok: boolean, op?: string, key?: string,
          record?: Record | null, entries?: Header[], next?: string | null,
          deleted?: number, error?: string }
snooze: {}
panel: { panelId: string, controlId: string, eventName: string,
         value: string | number | boolean | null,
         values: { [controlId: string]: string | number | boolean } }
query: { requestId: string, tabId: number, url: string, selector: string,
         matches: Match[], error: string }
file: see Files

Item = { ref: string, contentId: string, instanceId: string, attachments: { [id: string]: Attachment },
         url: string, title: string, authors: string[],
         videoForm: "short" | "long" | "post" | "unknown",
         tags: { name: string, confidence: number }[],
         tagsSettled: boolean, isPage: boolean }
Match = { tag: string, text: string, href: string, src: string,
          title: string, label: string, value: string }
```

- حدث `tick` تقريبي؛ استخدم الطوابع الزمنية لا عدد النبضات. تعني `active` أن الصفحة محددة في نافذة متصفح، لا أن المستخدم ينظر إليها. قد تكون عناوين URL فارغة أو محظورة.
- يأتي `visible` من الصفحات المتاحة وغير المخفية؛ ويمثل `elapsedMs` الوقت منذ آخر نبضة لها، ويكون صفرًا عند التغطية. لا يمثل استخدامًا متراكمًا أو وقت تشغيل فيديو.
- يبلغ `items` (`platform: "web"` خارج المواقع المعروفة) عن عناصر موجز جديدة أو متغيرة، ويعيد إرسالها بعد التشغيل/إعادة التمكين. يحدد `ref` بطاقة في تلك الصفحة، وليس معرّف محتوى دائمًا؛ وتشير `ref === "page"` إلى الصفحة نفسها. قد تكون العناوين أو الروابط أو المؤلفون فارغة. يحتوي `authors` على معرّفات مصدر خاصة بالمنصة.
- معرّفات المنصات: `youtube`, `tiktok`, `facebook`, `instagram`, `twitch`, `reddit`, `discord`, `twitter`, `bluesky`, `threads`, `substack`, `bilibili`, `rumble`, `pinterest`, `kick`, `tumblr`, `peertube`, `pixelfed`, `kuaishou`. يعتمد توفر العناصر على ترميز الصفحة المدعوم.
- تتطلب الوسوم مصنّف سطح المكتب المتصل وإصدارًا/منصة تدعم التصنيف (Chromium وSafari: YouTube وReddit وBilibili وX/`twitter`). مستوى الثقة من 1 إلى 5. تعني `tagsSettled === false` أن النتيجة معلقة أو غير متاحة، لا أنها بلا وسم؛ أما `tags: []` بعد اكتمالها فتعني بلا وسوم.
- يعني `snooze` أن زر التأجيل في المجموعة ضُغط. لا يطبق إيقافًا مؤقتًا من تلقاء نفسه.
- تستهدف ردود الاستعلام/الملفات المجموعة الطالبة. طابق `requestId` وتحقق من `error`/`ok` وحدد مهلة باستخدام النبضات: قد تضيع الردود عند إغلاق الصفحة أو إعادة تحميل المحرك أو تعطيل المجموعة. قد تتكرر معرّفات الطلبات بعد التشغيل؛ والطلبات المعلقة ليست أعمالًا دائمة.

## إجراءات المتصفح

يجب أن يأتي العدد الصحيح `tabId` من حدث. تتطلب إجراءات الصفحة صفحة يستطيع Vault الوصول إليها؛ وصفحات المتصفح الداخلية غير متاحة. لا تؤدي المدخلات غير الصالحة أو الأهداف غير المتاحة عادةً إلى أي أثر.

- `v.item(tabId, ref, verdict)`: تخفي القيمة `"hide"` بطاقة موجز، وتغطي `"dim"` الوسائط، وتعفي `"allow"` العنصر من المجموعات الأدنى، وتمسح `null` قرار هذه المجموعة. لا تفعل المراجع المجهولة شيئًا؛ استخدم `v.cover` مع `isPage`. تتبع القرارات ترتيب قائمة المجموعات: يتغلب الإخفاء الأعلى على الأدنى؛ ويظل التعتيم الأعلى بعد سماح أدنى؛ ويمنع السماح القرارات الأدنى. تحتاج البطاقة المعاد استخدامها أو المحذوفة إلى قرار جديد.
- `v.cover(tabId, on, message?)`: تغطي true الصفحة وترفع false غطاءها المخصص؛ والرسالة فارغة افتراضيًا (حدها 500 حرف). توجد خانة غطاء مخصص واحدة لكل صفحة؛ وآخر استدعاء للغطاء هو المعتمد بصرف النظر عن ترتيب المجموعة. تزيل تغييرات العنوان الغطاء؛ وقد يستمر الحظر العادي في تغطية الصفحة.
- `v.go(tabId, target)`: عنوان HTTP(S) أو إحدى القيم `"back"` أو `"forward"` أو `"reload"` (حد target هو 4096 حرفًا).
- `v.close(tabId)`: يغلق علامة التبويب.
- `v.css(tabIdOrStar, id, css)`: معرّف تبويب صحيح أو `"*"`؛ يستبدل ورقة المجموعة ذات المعرّف نفسه، أو يزيلها بقيمة null. تنتهي أوراق التبويب عند تغيير العنوان؛ وتصل أوراق `"*"` إلى الصفحات المستقبلية. الحد الأقصى للمعرّف 80 حرفًا ولـ CSS هو 100000 حرف.
- `v.dom(tabId, selector, op, arg?)`: محدد CSS (حده 1000 حرف)؛ كل التطابقات باستثناء `scrollTo` الذي يستخدم الأول. العمليات: `hide` يضبط `display:none!important` مضمنًا؛ و`show` يزيل display المضمن؛ و`click`؛ و`setText` يستبدل النص بـ `arg`؛ و`addClass`/`removeClass` تستخدمان اسم صنف واحدًا؛ و`scrollTo` تمرر العنصر إلى مجال الرؤية. حد arg هو 2000. تستمر التغييرات حتى عكسها صراحةً أو استبدال الصفحة.
- `v.query(tabId, selector)` ← سلسلة معرّف طلب أو null للوسائط غير الصالحة. النتيجة حدث `query` لاحق: حتى 50 تطابقًا، و`tag` بحروف صغيرة، ونص مطبّع لا يتجاوز 1000 حرف، وسمات لا تتجاوز 2000، وقيمة لا تتجاوز 1000. عدم وجود تطابق يعيد `[]` بنجاح؛ ويعيد CSS غير الصالح `error: "invalid-selector"`. قد لا ترد صفحة بلا مستقبل Vault أبدًا.

## اللوحات

```text
spec = { title?: string, description?: string, controls?: Control[],
         position?: "top-left" | "top-right" | "bottom-left" | "bottom-right" | "center",
         width?: "small" | "medium" | "large" | number,
         layout?: Layout, align?: "left" | "center" | "right", role?: Role }
Control = { id?: string, type?: string, label?: string, value?, disabled?: boolean,
            ariaLabel?: string, autoFocus?: boolean,
            align?: "left" | "center" | "right", layout?: Layout,
            width?: "full" | "auto" | number, height?: "auto" | number,
            ...type-specific fields below }
Layout = "vertical" | "compact" | "comfortable" | "spacious" | "inline" | "row"
       | "wrap" | "twoColumn" | "grid" | "split" | "form" | "toolbar" | "stack"
Role = "region" | "dialog" | "alert" | "status" | "form" | "group"
```

الإعدادات الافتراضية: الموضع أسفل اليمين؛ التخطيط عمودي؛ المحاذاة لليسار؛ الدور region؛ والعرض وفق المحتوى. عروض الإعدادات المسبقة 220/280/360px؛ ويتراوح العرض الرقمي للوحة بين 180 و520px. يتراوح عرض عنصر التحكم بين 32 و520px وارتفاعه بين 20 و360px. تقبل الأحجام الرقمية سلاسل بالبكسل أيضًا. تغيّر الأنماط العمودية التباعد؛ ولا يلتف inline/row؛ ويلتف wrap/toolbar؛ وتستخدم twoColumn/grid/split/form شبكات؛ ويقلل stack التباعد. يوفر الدور دلالات إتاحة، ولا يمنع التفاعل كنافذة حوارية.

تُطبّع المعرّفات إلى أحرف/أرقام ASCII و`_`/`-` (حتى 80)؛ اختر معرّفات فريدة وثابتة. يصبح معرّف عنصر التحكم المحذوف `control-N`، ويصبح النوع المحذوف/المجهول text. تكون النصوص والقوائم المحذوفة فارغة؛ وdisabled يساوي false. يستبدل استدعاء `v.panel` المواصفات كاملة. تعيد `value` المحذوفة استخدام آخر قيمة حدث للعنصر ثم تطبق تطبيع النوع؛ وتتقدم `value` الصريحة عليها. يكون autofocus معطلًا افتراضيًا. تُهمل الحقول المجهولة؛ وألوان اللوحة وخطوطها وCSS المقدم من القاعدة غير مدعوم.

حقول عناصر التحكم وقيمها:

- `text`: سلسلة `text`، وتكون label افتراضيًا. `html`: سلسلة `html`؛ وتزال منها البرامج النصية وسمات الأحداث وعناوين URL الخطرة والتنسيقات.
- `button`: `label`، واختياريًا `action: "submit" | "cancel" | "close"`؛ والقيمة سلسلة (فارغة افتراضيًا). ترسل الإجراءات أحداثًا؛ ولا تنفذ إرسالًا/إغلاقًا تلقائيًا.
- `checkbox`, `toggle`: قيمة `value` منطقية (false افتراضيًا).
- `select`, `radio`: `options: (string | { value: string, label?: string })[]`؛ وقيمة نصية (فارغة افتراضيًا). تزال قيم الخيارات الفارغة؛ وتساوي label قيمة الخيار افتراضيًا.
- `textInput`, `textarea`: قيمة نصية (فارغة افتراضيًا)، و`placeholder`؛ و`rows` في textarea من 1 إلى 12 (3 افتراضيًا).
- `numberInput`, `range`: قيمة رقمية (0 افتراضيًا)، و`min` و`max` و`step` موجب. تُحصر القيم ضمن الحدود؛ وحدود التطبيع الافتراضية −1000000…1000000. نطاقات range الافتراضية 0…100؛ عيّن الحدود صراحةً.
- `date`: سلسلة `YYYY-MM-DD`؛ و`time`: سلسلة `HH:MM` أو `HH:MM:SS`؛ تصبح الصيغ الأولية غير الصالحة فارغة. تحقّق من التعديلات بنفسك. `color`: `#RRGGBB` (`#000000` افتراضيًا).
- `pin`: سلسلة أرقام؛ و`length` من 3 إلى 12 (6 افتراضيًا)، و`masked` مفعّل افتراضيًا، و`autoSubmit` معطل. `section`: `text` و`controls`، وتكون الأقسام الفرعية عند العمق 3 بلا أبناء (عناصر التحكم الجذرية في العمق 0).

ترسل عناصر الإدخال العادية أحداث `input`/`change` (يتغير إدخال النص عند فقد التركيز/Enter؛ وtextarea عند فقد التركيز/Ctrl أو Cmd+Enter). وترسل عناصر التحكم العادية أيضًا `focus` و`blur` و`key`؛ ولا تُمرر بيانات المفتاح إلى القاعدة. ترسل الأزرار `click` **والإجراء المضبوط** كحدثين منفصلين؛ عالج أحدهما فقط. يرسل PIN `change` ثم `submit` عند اكتماله إذا كان autoSubmit مفعّلًا. يستخدم mount/unmount `controlId: ""` و`value: true`. تحتوي `values` على قيم الإدخال الحالية حسب المعرّف؛ ولا تشمل الأزرار/النص/HTML. لا تتضمن الأحداث معرّف علامة التبويب الأصلية؛ استخدم معرّفات لوحات منفصلة للتفاعل الخاص بكل علامة تبويب.

حدود النص: title/label/ariaLabel 240؛ description/text 1000؛ HTML 20000؛ placeholder 500؛ نص الإدخال 2000؛ سلاسل القيم الأخرى 512؛ قيمة/label الخيار 256. تُقتطع الزيادة.

## الملفات

`op`: إحدى القيم `"read"` و`"write"` و`"append"` و`"list"` و`"exists"`. يتطلب **مجلد القواعد المخصصة** في الإعدادات وإذنه. يستخدم Safari منتقي مجلداته الأصلي ومنحًا أمنيًا محتفظًا به؛ ولا يتاح إلا المجلد المختار.

- `path` نسبي؛ ويفصل `/` المجلدات. تسمح الأجزاء بحروف/أرقام ASCII والمسافات و`_.,@()-`؛ ولا تسمح بنقطة بادئة أو `.`/`..` أو مسار مطلق أو URL. لواحق الملفات `.txt` و`.csv` و`.json` (بلا حساسية لحالة الأحرف). يجب أن يكون مسار list مجلدًا؛ وتعرض `""` الجذر المختار.
- يعيد Read نص UTF-8. يستبدل Write الملف أو ينشئه؛ ويضيف append المحتوى أو ينشئه دون سطر جديد تلقائي. تُنشأ المجلدات الأب عند الكتابة. تكتب حمولة السلسلة كما هي؛ وتُسلسل حمولات JSON الأخرى؛ وتعني null/المحذوف نصًا فارغًا. تتولى القاعدة تحليل JSON/CSV. الحد الأقصى للملف 1048576 بايت UTF-8.
- يعيد List المجلدات الفرعية الظاهرة مباشرةً والملفات المدعومة. الإدخالات: `{ name: string, path: string, kind: "directory" | "file", extension?: string }`؛ ويتضمن extension النقطة للملفات. يعيد Exists قيمة منطقية لمسار ملف مدعوم.

```text
file.data = { requestId: string, op: string, path: string, ok: boolean,
              text: string | null, entries: Entry[] | null,
              exists: boolean | null, error: string }
```

تكون حقول النتيجة غير المستخدمة null؛ والنجاح له error فارغ. تشمل الإخفاقات invalid-path وunsupported-file-type وعدم توفر المجلد/الإذن والملف المفقود والملف الكبير جدًا. تعامل مع error كسلسلة، لا كتعداد ثابت شامل. لا توجد واجهة معاملات؛ نفّذ عمليات القراءة والتعديل والكتابة بالتتابع لكل مسار.

## الحدود

لكل حدث ومجموعة: 256 إجراءً في الطابور و200 استدعاء سجل و64 emit؛ وما زاد يُسقط. لكل قاعدة: 1000 معالج و24 لوحة؛ ولكل قائمة عناصر تحكم 32 إدخالًا ولكل خيار 64 خيارًا؛ وما زاد يُهمل أو يُقتطع. تتوقف سلاسل emit بعد 16 جيلًا. حد الحالة المتسلسلة 65536 بايت بترميز UTF-8. أبقِ التسجيل ومجموع معالجات كل حدث دون ثانية؛ وتوقف التجاوزات المتكررة أو انتهاء المهلة الصارمة المجموعة حتى الضغط على تشغيل. يحتفظ السجل بـ200 إدخال، ويقبل 50 في الثانية لكل مجموعة، ويقتطع الرسائل الطويلة قرب 4096 حرفًا. المؤقتات والردود أفضل جهد وليست ضمانات آنية.

## قاعدة كاملة

إيقاف لمدة خمس دقائق يفعّله زر التأجيل أو زر اللوحة:

```javascript
(on, v) => {
  v.state.pauseUntil ??= 0;
  const pause = ev => { v.state.pauseUntil = ev.now + 300000; };
  v.panel("pause", { controls: [{ id: "pause", type: "button", label: "Pause 5 min" }] });
  on("snooze", pause);
  on("panel", ev => {
    if (ev.data.panelId === "pause" && ev.data.controlId === "pause" && ev.data.eventName === "click") pause(ev);
  });
  on("tick", ev => {
    for (const tab of ev.data.tabs) {
      if (/^https?:\/\/(www\.)?youtube\.com(?:\/|$)/i.test(tab.url)) v.cover(tab.tabId, ev.now >= v.state.pauseUntil);
    }
  });
}
```


## استدعاءات الذكاء الاصطناعي من قاعدة قيد التشغيل

تختار كل مجموعة اتصالًا/نموذجًا وجهد استدلال ضمن **AI calls**. الواجهة نفسها لقواعد Mac والمتصفح؛ طلب المتصفح يتطلب اتصال Mac Vault، وتبقى بيانات اعتماد المزود فيه. تتشارك المجموعات المرتبطة الاختيار وحدًا يوميًا اختياريًا. الفراغ يعني بلا حد للمجموعة، وتظل حدود الحساب سارية. يحسب الحد يوم UTC، ويستمر بعد إعادة التشغيل، ويعد كل محاولة مرسلة بما فيها الفاشلة. يجمع الربط الاستخدام الموجود؛ والفصل يبقي الاستخدام السابق.

تعيد يُشارك الموجّه والسياق المحفوظان بين المجموعات المرتبطة، ويتاحان في handlers عبر `v.context.ai.prompt` و`v.context.ai.context`. لا يرسلهما Vault تلقائياً؛ تختار القاعدة ما تضيفه إلى كل استدعاء `v.ai`.

`v.ai({ prompt, input? })` معرّف طلب فورًا. استدعها داخل معالج لا عند تسجيل القاعدة. `input` أي قيمة JSON؛ حد كل من prompt/input هو20KB. تصل الردود كأحداث `ai` events: `. Success text is at most48KB; citations are ` `ask` `note`: {requestId, ok, text, citations, error}. حد نص النجاح48KB؛ والاستشهادات {url,title}. أظهر روابط المصادر قابلة للنقر عند عرض إجابات بحث الويب. البحث متاح دائمًا للنموذج. لا مهلة ثابتة للطلب، مع تزامن محدود؛ لا تبديل مزود أو إعادة تلقائية. الردود بيانات ولا تنفذ JavaScript؛ وتقرر القاعدة الإجراءات القائمة التي تتخذها.

```javascript
(on, v) => {
  let pending = null;
  on("panel", ({ data }) => {
    if (data.controlId !== "ask" || pending) return;
    pending = v.ai({ prompt: v.context.ai.prompt || "Summarize this text.", input: {context:v.context.ai.context, note:data.values?.note ?? ""} });
  });
  on("ai", ({ data }) => {
    if (data.requestId !== pending) return;
    pending = null;
    if (!data.ok) { v.log("AI request failed:", data.error); return; }
    v.log(data.text, data.citations);
  });
}
```

لا تعاد الطلبات قيد التنفيذ بعد إعادة التشغيل. Run أو التعطيل/إعادة التفعيل أو الحذف يسقط الردود القديمة؛ والمتصفح غير المتصل يبلغ `ai-unavailable`. تشمل الأخطاء `ai-not-configured`, `ai-invalid-input`, `ai-busy`, `ai-daily-limit`, `ai-request-failed`, `ai-usage-storage-unavailable`. لا تمحو المكالمات الفاشلة نتيجة سابقة احتفظت بها القاعدة؛ وحد حالة القاعدة ما زال64KB.

اكتشف الخيارات الخالية من بيانات الاعتماد عبر `rule_ai_models` على Mac أو `settings-rule-ai-models` في المتصفح، واضبط `ruleAI` عبر مسار set-group الحالي. الحقول `providerModel`, `accountID`, `reasoningEffort` (`default`, `low`, `medium`, `high`) و`dailyRequestLimit` (null أو1–100000). استخدم خيارًا معادًا؛ لا تضع مفتاحًا أو عنوان مزود في مصدر القاعدة.
الحقول المحفوظة الاختيارية هي `prompt` و`context`؛ وكل منهما نص حتى 16KB.

## سجلات المجموعة

تبدأ `v.store(request)` عملية سجل JSON غير متزامنة داخل معالج. السجلات خاصة بالمجموعة وتستمر بعد Run وإعادة التشغيل وتحذف مع المجموعة؛ ولكل مجموعة مرتبطة سجلات مستقلة. تختار القاعدة المفاتيح والقيم والإصدارات وإبطال الذاكرة المؤقتة وأولوية الملاحظات. تستخدم قواعد Mac والمتصفح الواجهة نفسها، لكن تخزين كل تطبيق/متصفح مستقل.

| الطلب | النتيجة |
|---|---|
| `{op:"get", key}` | `record` أو `null` |
| `{op:"put", key, value, version?, ifRevision?}` | `record` محفوظ |
| `{op:"delete", key, ifRevision?}` | `record: null` |
| `{op:"list", prefix?, after?, limit?}` | `entries` مرتبة و`next` |
| `{op:"clear", prefix?}` | عدد `deleted` |

يحوي السجل `{value, revision, version, updatedAt}`. يتغير revision المعتم عند كتابة حقيقية؛ و`version` بيانات وصفية يحددها المستدعي. يعيد `list` الرؤوس دون القيم؛ استخدم `get` للقراءة و`after: next` `put` `delete` للصفحة التالية. حذف/كتابة دون `ifRevision` غير مشروط؛ و`null` يشترط غياب المفتاح، أما سلسلة المراجعة فتشترط تطابقها. عند التعارض يعاد `ok:false` و`error:"store-conflict"` `record` والسجل الحالي؛ استخدم ذلك لمنع رد آلي متأخر من استبدال ملاحظات المستخدم. `v.context.revision` علامة معتمة لتكوين القاعدة يمكن إدراجها في إصدارها؛ لا تفرض المنظومة سياسة ذاكرة مؤقتة.

الحدود: المفتاح 1–2048 حرفًا، الإصدار ≤128، قيمة JSON ≤64KiB وعمق ≤32، 10000 مفتاح للمجموعة، والوثيقة كلها 16MiB. تعيد `list` حتى100 رأس و96KiB في الصفحة. الحد 32 طلبًا للمجموعة و128 بدءًا في الثانية إجمالًا؛ عند الضغط يصدر خطأ `store-busy` واحد للمجموعة في الثانية وتسقط الطلبات الزائدة. أخطاء التخزين تعيد `ok:false`؛ وتحفظ الوثيقة المستقبلية أو المشوهة وتبلغ `store-unavailable`. لا إعادة محاولة أو إخلاء تلقائي. استخدم ticks للمهل.

## المرفقات المحفوظة للمحتوى

تُحفظ الحبة أو واجهة HTML/CSS الساكنة لعنصر محتوى مرصود باستخدام `v.attach(tabId, item, id, spec)`. مرّر `item` كاملة من حدث `items` أو `attachment`؛ فالمرجع `ref` وحده ليس معرّف مرفق. يعرّف `contentId` المحتوى المحفوظ، ويعرّف `instanceId` ظهوره الحالي. احتفظ بالمعرّف الأصلي أثناء انتظار AI. يرفض Vault الإرفاق المتأخر لهدف أزيل أو أعيد استخدامه أو انتقل؛ ويظل سلوك `v.item(tabId, ref, verdict)` مستقلاً.

للحبة، استخدم `spec` بالشكل `{type:"pill", text, tone?, tooltip?}`؛ والنغمات `blue` و`cyan` و`gold` و`pink` و`red`. النص عادي حتى 240 حرفاً والتلميح حتى 1000. للعرض استخدم spec بالشكل `{type:"html", html, css?, label?}`. حد HTML هو 32000 حرف وCSS ‏16000 وlabel ‏200. يعاد بناء العرض من HTML/SVG ساكن مسموح داخل shadow root مغلق وبـCSS محصور؛ وتحذف البرامج النصية وسمات الأحداث والموارد البعيدة والتضمينات وCSS غير الآمن. يقتصر العرض المرئي على بطاقة المحتوى ويمكن تمريره عند ارتفاع 480px. تتكون المعرفات من 1–80 حرفاً/رقماً ASCII أو _ أو -. إزالة spec تحذف حبة المجموعة. استدعها من handler؛ وتظهر أخطاء الحفظ أو التسليم في Log بلا إعادة تلقائية.

يعرض كل عنصر مرفقات هذه المجموعة عبر `item.attachments` كلقطة للقراءة فقط. لا تشمل المرفقات الخاصة بالمجموعات الأخرى. إذا تعذر جلب البيانات المحفوظة، تكون `attachments` بقيمة null ويُعيّن `attachmentError`؛ وهذا لا يعني أن الذاكرة المؤقتة فارغة. تستمر المعالجات الأخرى. فعّل الحبة في المثال أدناه لتجنب طلب AI لعنصر له نتيجة محفوظة.

تؤدي إيماءة المؤشر أو Enter أو Space إلى حدث `attachment` للمجموعة. ترسل الحبوب `click`. تستخدم عناصر العرض `data-control` أو `id` كـ`controlId`، وترسل `click` أو `input` أو `change` مع `value` الحالي و`values` المحدودة لعناصر الإدخال المسماة. أحداث الواجهة الفعلية لها `ev.origin === "user"`، وأحداث القاعدة `origin === "rule"`. تتضمن الأحداث `tabId` و`attachmentId` و`item` الحالية. لا ينفذ العرض شيفرة القاعدة؛ كما تمنع الحبوب والعروض التفاعل من التنقل ببطاقة المحتوى. لا تحتوي البيانات المحفوظة على callbacks أو شيفرة قابلة للتنفيذ، ولا يستطيع إصدار قديم استدعاء مرفق حالي. أحداث emit من القاعدة منطق عادي؛ ويتحقق المتصفح من رسائل النقر الحقيقية بشكل مستقل.

تحفظ المرفقات في ملف المتصفح الشخصي لكل مجموعة/محتوى/ID، وتعود في مرات الظهور اللاحقة والتنقل وإعادة التشغيل وRun. يعطلها Disable مع الاحتفاظ بالبيانات، ويعيدها Enable. يحذف حذف المجموعة مرفقاتها. المجموعات المرتبطة مستقلة، ولا توجد مزامنة تلقائية بين المتصفحات أو الأجهزة. تستخدم محتويات YouTube وReddit وX وBilibili المعروفة معرفات المنصة؛ ويستخدم المحتوى الآخر عنوان URL مطبّعاً بتحفظ، لذلك يعتمد التوفر على ترميز الصفحة المدعوم.

الحدود: 8 مرفقات لكل مجموعة/محتوى، و32 لكل عنصر عبر المجموعات، و10000 إدخال محتوى لكل مجموعة، ووثيقة مرفقات بحجم 8MB. يرفض تجاوز الحد التغيير الجديد مع `attachment-item-limit` أو `attachment-storage-limit` في Log ويحفظ البيانات الحالية. تجمع عملية dispatch عمليات الكتابة، ولا تعيد كتابة التخزين عند تطابق spec. المرفقات واجهة لمحتوى المتصفح بما فيها محرك Safari الأصلي؛ أما قواعد تطبيق Mac فلا تملك مقابض محتوى المتصفح أو شاشة مرفقات داخل التطبيق.

```javascript
(on, v) => {
  on("items", ({data}) => {
    for (const item of data.items) {
      if (item.attachments && !item.attachments.note) {
        v.attach(data.tabId, item, "note", {
          type: "pill", text: "Review this", tone: "blue"
        });
      }
    }
  });
  on("attachment", ({data}) => {
    if (data.attachmentId === "note") {
      v.log("Review clicked", data.item.contentId);
    }
  });
}
```
