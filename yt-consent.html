Custom Web Blocker

Help classify the creators you watch?

To block YouTube content by topic, the blocker needs to know which topics each channel covers. You can optionally help build that public map.

  • ↗ What's shared: only the channel id (e.g. UC…) of channels that appear while you browse YouTube — the feed, watch pages, search, and the sidebar. Capture is automatic once enabled: any channel id the page shows gets sent.
  • ⦸ What's never shared: video titles, your watch history, search terms, timestamps, or anything that identifies you.
  • ⏻ You're in control: it's off by default, and you can switch it on or off anytime in Settings.

Anonymous channel ids feed a shared tag database so everyone's blocking gets smarter. You can change your mind in Settings → “Help classify creators”.
